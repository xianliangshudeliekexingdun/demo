# 法术试炼 · 遗迹庭院

PC横屏单机游戏，Godot 4.7.2／GDScript；开发根目录为D:/demo。
玩家控制移动，法术自动吟唱；当前主要入口是60房六系混搭路线，包含四Boss、法术／宝物奖励、五间商店与局外养成。最新实现与待测范围见[功能模块](docs/功能模块.md)。

## 运行

导入[project.godot](project.godot)，运行主场景；也可在PowerShell执行：

~~~powershell
Set-Location D:/demo
& ./Godot_v4.7.2-stable_win64.exe --path D:/demo
~~~

主菜单“出发”→准备页确认触媒／四槽宝石与本局属性总览→“出发”。开局三选一由已装备触媒决定学派；未装备触媒时为全系列基础术随机三张。WASD／方向键移动，自动施法；清场后触碰门前书／箱选奖，再走北门。Esc或失焦暂停，恢复后先松开移动键。

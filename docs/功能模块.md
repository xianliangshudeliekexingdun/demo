## 2. 真实试玩方法

1. 主菜单底栏“出发”进入准备页，确认触媒、四槽宝石与八项属性；触媒决定本局开局学派（未装备则六系基础术随机三张），新档触媒可免费选一件，核心免费自选一枚，另可自选三枚起始绿Ⅰ属性石，也可不装备。
2. 选择起始法术，移动时自动施法。清场补盾后触碰北门前书／箱打开选择，再走门换房；Boss按书→金箱完成两项领取，60房同样。
3. 满八槽抽到新术，选旧槽确认一级替换；取消保留原三卡。满槽全新三卡可放弃保留构筑，八术满级也不会自动跳书。
4. 商店可绕过柜台直接走门；首次靠近柜台才补给并显示固定商品，单店最多买一件。关闭／重开不重复补给或刷新，金币只在本局使用。
5. 选卡用鼠标整卡点击或键盘导航确认；替换页Esc返回原三卡，可用“暂停选择”暂停。其他页面Esc／失焦暂停，恢复／换房后先松开移动键。
6. 死亡、完成或主动结束按真实已清账本结算；强退不续关或补发收益。

### 局外成长与存档

meta拥有账号事务，core只提交真实清房，main不接受任意收益；出发锁定实例快照，结算幂等，保存失败不提交。四个宝石槽不限品质；金色宝石＝一个特殊效果＋三条不分主副的属性；金2%／50抽硬保底，紫10抽保底；同名效果可同时装备，但只有槽位最靠前的一枚生效。精粹重洗全洗20、每锁定一项+15、最多锁3项。战斗层按效果集合配置，最多四个效果同时生效，四个学派各持独立状态机。当前存档v7／宝石schema4不兼容旧档，启动时隔离为带版本与时间戳的备份并新建。规则见[局外养成](游戏设计/局外养成.md)，技术契约见[架构](项目架构.md#局外事务)。

火系本轮已由用户确认完成，当前按授权整理项目、删除旧预览并提交本地Git；十术认可现版及原规则／数值保持。保留必要自动回归与旧证据，实机、自然整局、性能和新交付包仍按原范围处理。

## 2. 真实试玩方法

1. 主菜单“开始冒险”进入准备页，选择火／冰／雷／风／岩／灵契起手后进入60房路线；新档触媒可免费选一件，核心免费自选一枚，另可自选三枚起始绿Ⅰ属性石，也可不装备。触媒已覆盖六系，起手可独立选择，不要求解锁或装备同系触媒。
2. 选择起始法术，移动时自动施法。清场补盾后触碰北门前书／箱打开选择，再走门换房；Boss按书→金箱完成两项领取，60房同样。
3. 满八槽抽到新术，选旧槽确认一级替换；取消保留原三卡。满槽全新三卡可放弃保留构筑，八术满级也不会自动跳书。
4. 商店可绕过柜台直接走门；首次靠近柜台才补给并显示固定商品，单店最多买一件。关闭／重开不重复补给或刷新，金币只在本局使用。
5. 选卡用鼠标整卡点击或键盘导航确认；替换页Esc返回原三卡，可用“暂停选择”暂停。其他页面Esc／失焦暂停，恢复／换房后先松开移动键。
6. 死亡、完成或主动结束按真实已清账本结算；强退不续关或补发收益。独立首房与无收益预览的边界见相应入口提示。

### 局外成长与存档

meta拥有账号事务，core只提交真实清房，main不接受任意收益；出发锁定实例快照，结算幂等，保存失败不提交。四个宝石槽不限品质；金色宝石＝一个特殊效果＋三条不分主副的属性；金2%／50抽硬保底，紫10抽保底；同名效果可同时装备，但只有槽位最靠前的一枚生效。精粹重洗全洗20、每锁定一项+15、最多锁3项。战斗层按效果集合配置，最多四个效果同时生效，四个学派各持独立状态机。当前存档v7／宝石schema4不兼容旧档，启动时隔离为带版本与时间戳的备份并新建。规则见[局外养成](游戏设计/局外养成.md)，技术契约见[架构](项目架构.md#局外事务)。

## 4. 图标与攻击特效制作

正式火冰、通用宝物／庭印、触媒／宝石、卡牌框与火舌已按ID接入，32职业原图保留归档但撤出现行预加载／导出。四Boss采用程序轮廓与只读血条，既有莉奈动作不因新素材自动扩充。

雷风岩灵契40术与MC06—MC09继续使用程序图标，本轮补充逐ID主体轮廓、暗边、高光与尺寸适配；32／44／64／96尺寸的解析几何检查修复了R04／R07／S02底弧越框，但没有渲染像素。

新四系只读几何特效已细化：雷矢／雷枪／实际连锁与网络边、空心云与真实落雷、裁决／雷环／护幕；风刃／回环／追矢／双翼、实际短风径与矩形风幕；三种岩构装、碎片／裂隙与波前；三类契灵、召唤／号令／链环及对应攻击。导电到期不再隐藏仍有效的雷易伤，W10一级／二级真实生效及三级宽限均有提示。雷维持768线段批次，风岩灵契共用1536线段批次，契灵外形不改变碰撞或索敌。只画已发生的实际放电边，不常亮潜在网络；减动态选项只改变显示。真实像素／遮挡可读性及高弹量性能待统一实机。
来源、提示词、许可证与哈希见[assets.json](assets.json)；历轮素材清单和像素记录集中[验证与素材归档](历史决策/归档/20261020-历轮验证与素材索引.md)。旧截图不作为本版新弹幕可读性证明。

十核心与八种属性另有独立程序图标；工坊分核心目录／属性背包／制作，HUD读真实库存与层数。核心只读特效统一有限批次，旧宝石事件入口排除以免双画；暂停冻结、清场清理与减少动态仅改变显示。

## 6. 实现边界与下一步

新版宝石已按用户确认实施，唯一下一步是并入后续统一实机：检查十核反馈／小尺寸图标、控制消费与兑现、三属性石培养操作、短局收入／核心与触媒竞争；根据真实反馈再调参数。继续暂缓实机、截图、自然整局与性能，不自动启动游戏。

1. 六系法术与统一抽取首版已完成，后续按用户安排统一试玩：检查实际书奖升级／新学／替换体验、主副系选择与触媒取舍，结合真实选择再调参数，不把受控模型当成真人成型率。
2. 按用户安排统一试玩本版60房：四段转换、快慢弹可读性／多源缺口、身体接触与贴近反打、六系混搭／回盾／强构筑；检查本轮40术／四触媒图标小尺寸实读、雷状态与实际连锁、风径／风幕、构装终止、三类契灵与号令，重点核新友方特效与敌弹／预警的遮挡；再核四Boss与召援、末房领奖／结算、整体约30分钟目标和高弹量性能。
3. 后续统一设计强力专属道具，不恢复旧逐系职业配额。统一命中取值、敌方防御与固定附伤未来承伤规则仍待讨论，本轮未实施。
4. 地刺、声音、新角色动作、Windows新包与最终平衡仍未完成，按后续授权推进。当前继续暂缓实机／自然整局／性能；本轮不导出、不远端构建／提交／上传。

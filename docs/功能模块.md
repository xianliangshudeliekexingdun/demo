## 2. 真实试玩方法

1. 主菜单底栏“出发”进入准备页，确认触媒、四槽宝石与八项属性；触媒决定本局开局学派（未装备则六系基础术随机三张），新档触媒可免费选一件，核心免费自选一枚，另可自选三枚起始绿Ⅰ属性石，也可不装备。
2. 选择起始法术，移动时自动施法。清场补盾后触碰北门前书／箱打开选择，再走门换房；Boss按书→金箱完成两项领取，60房同样。
3. 满八槽抽到新术，选旧槽确认一级替换；取消保留原三卡。满槽全新三卡可放弃保留构筑，八术满级也不会自动跳书。
4. 商店可绕过柜台直接走门；首次靠近柜台才补给并显示固定商品，单店最多买一件。关闭／重开不重复补给或刷新，金币只在本局使用。
5. 选卡用鼠标整卡点击或键盘导航确认；替换页Esc返回原三卡，可用“暂停选择”暂停。其他页面Esc／失焦暂停，恢复／换房后先松开移动键。
6. 死亡、完成或主动结束按真实已清账本结算；强退不续关或补发收益。

### 局外成长与存档

meta拥有账号事务，core只提交真实清房，main不接受任意收益；出发锁定实例快照，结算幂等，保存失败不提交。四个宝石槽不限品质；金色宝石＝一个特殊效果＋三条不分主副的属性；金2%／50抽硬保底，紫10抽保底；同名效果可同时装备，但只有槽位最靠前的一枚生效。精粹重洗全洗20、每锁定一项+15、最多锁3项。战斗层按效果集合配置，最多四个效果同时生效，四个学派各持独立状态机。当前存档v7／宝石schema4不兼容旧档，启动时隔离为带版本与时间戳的备份并新建。规则见[局外养成](游戏设计/局外养成.md)，技术契约见[架构](项目架构.md#局外事务)。

## 4. 图标与攻击特效制作

六系60术与四个新触媒的图标、分学派只读特效均已接入；火冰保留批准图片，雷风岩灵契使用程序图标。十核心／八属性图标与宝石VFX独立读取真实快照。正式资源与来源记录见[assets.json](assets.json)；已退场职业图及旧动作探索已外置，兼容ID和完整定义保留。

敌方魔法飞弹能量版v2与F01焰弹术v2均保留用户认可现版。飞弹由[只读模块](../scripts/presentation/route_magic_missile_vfx.gd)读取真实路径和终止事实；焰弹的慢速侧出、短弧转向与加速由core推进，表现沿实际曲线重建尾迹，伤害、碰撞半径及爆炸成长范围保持。飞行参数唯一在[route_spell_runtime](../data/route_spell_runtime.json)，纯表现参数在[magic_missile_vfx](../data/magic_missile_vfx.json)与[fire_bolt_vfx](../data/fire_bolt_vfx.json)。

F01保留为已通过的第一个火系样板。[F03完整链路](游戏设计/法术体系.md#流火之雨完整特效链路)与[F08完整链路](游戏设计/法术体系.md#贯焰光束完整特效链路)已接入独立只读模块，用户分别明确“可以通过”／“很好通过”，认可本次预览。2026-10-27用户随后授权自行确定并制作F07；[熔核爆弹完整链路](游戏设计/法术体系.md#熔核爆弹完整特效链路)现已由[独立只读模块](../scripts/presentation/route_fire_bomb_vfx.gd)和[纯表现参数](../data/fire_bomb_vfx.json)接入：聚熔、重火核抛物线／连续火尾、中心爆燃／外围火浪、三级原位余震与真实目标局部燃料兑现／成功复燃。原锁点、结算／时序、伤害context／事件／RNG保持，F07实机待用户测试。其余六术仍按[十术方案](游戏设计/法术体系.md#火系特效优化)待逐项提升，顺序未定。既有认可分别限本次飞弹观感、F01单术及F03／F08本次预览，不扩为60房体验、最终平衡、性能、F07视觉认可或自动启动授权。原始反馈、返修与确认见[历史34](<../../demo 精简/20261026-项目精简/docs/历史决策/归档/34-战斗画面第一轮渲染与表现改造.md>)／[35](<../../demo 精简/20261026-项目精简/docs/历史决策/归档/35-火系法术特效优化.md>)。[近期参考图](游戏设计/参考图/20261026-战斗特效)及[可选预览场景](../tests/previews)保留；代理不自动互动启动。

## 6. 实现边界与下一步

当前唯一下一步是由用户手动测试第四术F07熔核爆弹，反馈主爆分区／火核重量、三级余震及真实燃料兑现／延迟复燃的观感与遮挡。[九情境预览](../tests/previews/fire_bomb_preview.tscn)已备妥，代理不自动启动。已认可魔法飞弹v2、F01焰弹v2及F03／F08本次预览保持，其余六术等待后续选择；统一实机由用户负责，代理继续暂缓实机、截图、自然整局与性能。

后续统一试玩须覆盖60房四阶段、快慢弹与多源缺口、接触反打、四Boss／有限召援与末房领奖结算；六系混搭、书奖升级／新学／替换及触媒取舍；四槽宝石与十效果反馈、八项属性和准备页可读性、短局养成收入；新图标／友方特效与敌弹／预警遮挡、1280×720点击舒适度、约30分钟目标及高弹量性能。按真实反馈调参，模型不替代真人体验。

未来专属道具、统一命中取值、敌方防御与固定附伤承伤规则仍待讨论；地刺、声音、新角色动作、新Windows包与最终平衡尚未完成。原职业数量不恢复为制作配额，无独立法术专属升级系统。

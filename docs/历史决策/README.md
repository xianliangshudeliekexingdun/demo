## 记录方法

同一大任务的改变直接追加归档原文，新大任务在归档内另编号并更新本索引；保留原决定、否决和证据，不用后来的状态改写旧结论。正文“已决定／已实施／规则通过／像素通过／用户认可／待测试”分别表述。实现变化更新功能模块与所属设计主题，不把各轮故事搬回入口。

文档整理不产生新的玩法验收。07全文及历轮素材／验证继续保留；本地链接已修复，旧来源路径可通过迁移表定位，原锚点保持。原始JSON、日志、截图、提示词和许可证未删。当前下一步只在功能模块维护，历史只解释当时选择。

# 02 战斗外观与阴影

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

任务日期：2026-10-08；整理日期：2026-10-16。状态：本轮外观获用户认可。

## 背景与范围

用户以会话中的2D战斗概念示意为方向：Q版莉奈、手绘石砖庭院、残墙植被、蓝色门、脚底阴影和明亮魔法效果。概念图是参考，不是实机证据，也不自动授予全部元素正式资格。

用户要求慢慢制作，本轮只做血条、技能框、脚底阴影，暂不做大场景；PC手动玩法留待后续任务。

## 决定及理由

| 选择 | 理由 |
|---|---|
| 左上头像配细长红色血条、暗内槽和金属倒角边框 | 接近参考构图，提高生命识别，替换大块面板 |
| 底部三个方形图标：火焰、闪电、法球 | 统一轮廓、明暗与框体；本轮仅显示原试炼选项 |
| 当前图标突出，其余弱化，忽略鼠标 | 避免将显示更新误认为已经增加装备/切换 |
| 脚底多层低透明度灰褐椭圆 | 轻量改善贴地，不加实时投影 |
| 真实尺寸、生命状态与窗口比例检查 | 概念效果、素材大图和运行像素分别评估 |

图标裁掉不同透明边距以统一实际大小；头像依据莉奈身份参考单独生成，修正夹带法杖和贴顶。阴影保持脚底锚点、镜像与死亡淡出，显示不写生命或伤害。

## 交付与验证

交付在battle_hud、game_ui、battle_view与assets/ui；来源和提示词保留在docs/assets.json、docs/hud-image-prompts.json。

当时原Godot解析通过，规则和环境摘要无变化，未为纯外观重复规则测试。visual_qa真实输出33张viewport截图，覆盖三能力、100/50/0生命、死亡、镜像、暂停/结算、重试与多窗口，最终failures=0。证据目录build/qa/hud-v1。

1600×1000窗口内容截图为1600×900，viewport不含系统边框/留边；同步存PNG造成的低帧率不是游戏性能结论。

## 用户认可与后续

用户明确回复“外观验收通过可以”。认可头像血条、技能框和脚底阴影，不包含新玩法、大场景、角色动作或独立包；本轮未导出新Windows包。

后来五法术扩展为五槽和冷却显示，其验收随五法术阶段，不由本轮三图标认可自动覆盖。

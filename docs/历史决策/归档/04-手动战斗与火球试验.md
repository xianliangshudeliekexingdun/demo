# 04 手动战斗与火球试验

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

任务日期：2026-10-09；整理日期：2026-10-16。状态：自动接续和六项火球升级体验获明确认可；整体平衡及所有组合不自动验收。

## 背景和决定

用户希望让玩家在吟唱输出与闪避保命之间作选择。先用有法力、吟唱和专属升级的火球验证风险与操作，保留自动战斗作为对照。

| 决定 | 理由 / 行为 |
|---|---|
| 按住左键吟唱，就绪后松键释放 | 实时显示落点并跟随鼠标，完成后仍可瞄准，释放由玩家决定 |
| 右键闪避，保留进度 | 保命不必损失全部输出准备；受击仍清未释放状态 |
| 接续窗口较宽松 | 降低原型操作门槛，先验证决策，再评估技巧要求 |
| 抛物线、固定飞行时间、范围伤害 | 可预判的延迟要求判断落地时敌人位置 |
| 成功释放才扣法力 | 提前取消损失时间不损资源，吟唱/就绪不回蓝 |
| 可调CSV与纯属性计算 | 调参不改源码，升级跟随基础值，快照支持比较 |

首测火球18法力、0.8秒吟唱、0.45秒飞行、30伤害/1.4米半径；闪避2.4米、0.18秒动作、前0.12秒免伤、1.2秒冷却、0.6秒手动窗口。初值不是平衡结论。

## 操作修订

首版要求闪避后松开再按左键。用户反馈“这个操作较为困难，+不适应”，批准改为持续按住，闪避结束自动接回；已松键保留手动窗口。

自动接续在同一步实际受击和松键处理后执行，不自动释放或扣蓝；基础吟唱、普通就绪和熔核蓄力都支持。受击、暂停、窗口超时仍清未释放状态。用户明确回复“可以，测试通过”，认可这项操作。

## 六项升级与用户确认

3普通：熟练吟唱、节能施法、扩散火焰；2稀有：余烬之地、二重爆破；1传说：熔核火球。用户明确表示六项“这些我都测试了，可以”。当前公式合并在[功能模块](../../功能模块.md#4-30项专属升级)。

每次从基础值与集合重算，先减基础消耗、加半径，再套熔核；熟练同时作用附加吟唱。次爆不递归，地表不叠同敌频率。

## 交付与验证边界

独立入口提供0—3敌人自由配置及3场/2次成长；58项参数在data/fireball_trial.csv原子加载。日志在build/qa/fireball-trial/sessions，保留快照、取消原因、接续和主火球命中/伤害。

修订后的历史规则为246火球＋1490原基线，0失败，真实视觉failures=0；覆盖64集合、固定步、边界、命中/燃烧、受击/接续、配置与流程。2026-10-10阶段B时旧入口又做回归。

不把认可扩大为所有组合人工验证、三场流程完全平衡、声音舒适度或新Windows包已验收。该入口仍是无独立法术冷却的比较基线。

调参一次优先改一个相关参数组，记录旧值→新值、理由与实际结果；以相同敌群、种子和快照比较，不只看成功率。

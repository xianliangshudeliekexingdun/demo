# 05 五法术构筑与成长

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

任务时间：2026-10-09—10；整理日期：2026-10-16。状态：基础操作与冷却认可，升级/预设/成长已实现，阶段B实际试玩待验收。

## 先构筑，再关卡

用户否定助手提出的“15—20分钟、3区域、每区3普通战＋1首领、共12场”，认为区域和成长机会不足。决定先建立完整构筑，再根据起步、成形、完善和检验需要设计节点、敌人和数值。

正式区域数与局时长未定案，9场是可调试验。核心原则是局外解锁法术、升级可能性和起始配置，局内选择本次成长；永久属性、渠道和存档另议。

## 五槽与职责

携带五个不同法术，局内固定，不强制每槽职责。首套火球常规输出、陨火爆发、新星控场/减益、回春恢复、灯灵持续辅助，共用法力和一个吟唱状态。

希望集中培养2—3主力，其余承担基础辅助，不要求凑齐30项；区别要体现在使用条件和行动，而不只是倍率。真正局外搭配要扩充法术库，当前五选五只验证排序和局内配合。

## 阶段A：无冷却基础试验

2026-10-09接入自由模式、切换、五基础效果和来源记录。沿用自动接续，切换清未释放进度，已生效法术继续。

用户最初要求暂不加法术冷却，以吟唱、法力和效果规则先看节奏。无冷却是试验变量，不是永久承诺。初版2356规则、36视觉检查通过，是当时证据。

## 2026-10-10：独立冷却修订

用户反馈“目前测试可以，但是感觉还是需要技能冷却时间来限制玩家”，批准加入独立冷却：火球0.25秒、陨火4、新星6、回春10、灯灵12；没有全局冷却。

成功释放才计时，取消/受击/接续不启动；按法术绑定，切换不清、暂停冻结，未结束不能吟唱，按住不自动排队。保留原伤害、吟唱和消耗，避免多变量混淆。

理由是火球维持行动，强力法术择机、控制和治疗留空档。风险是等待过多或固定轮转，要观察玩家为何出手以及等待时在做什么。

真实核心的31组60秒无敌人模型：默认蓝量火球21次不变，陨火12→11、新星21→10、回春17→6、灯灵15→5；充足法力间隔约1.067/5.417/6.467/10.817/13.017秒。含吟唱和固定步输入，模型不能预测趣味、命中或生存。工具在tools/balance/spell_cooldowns.gd，结果在build/qa/build-trial/cooldown-balance.json。

冷却版2420规则、41视觉检查通过。用户随后“有冷却就好多了”并要求阶段B，据此认可基础操作和冷却，不推断数值最终平衡。

## 阶段B：升级与成长

2026-10-10实施每法术3普通/2稀有/1传说，共30项，火球公式复用，24新项可调。有限来源树防止天火反复复制碎星/地表、领域续冻结、治疗双预算、护盾无限积累、双生同步递归。现行详细行为见[功能模块](../../功能模块.md)。

自由任意勾选，频繁施法/控场爆破/持续压制各8项；全30是压力组。明确重置才应用，继续保留会话。

成长从零开始，9战8选，生命保留、初值间场不回血、法力恢复满；清旧效果、重置冷却和每场资格。重试从第1场零升级，种子/配置保留。

奖励兼顾已培养和横向补足，品质权重70/25/5再抽项，不是固定出现率；候选唯一、排已持有、池不足/耗尽/零权重都有分支。只有core生成候选消耗随机数，UI不重抽。

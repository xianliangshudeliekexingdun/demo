# 09 通用与职业道具设计

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

任务开始：2026-10-18。用户认可45房当前节奏，要求先编写详细通用道具文档供审查，方向包括攻击、防御、血量、冷却及类似模拟宇宙的机制；以后道具分通用／职业两类。用户进一步明确，允许强构筑明显输出跃升，最终完整60房及Boss约30分钟即可，不要求现45房继续维持30分钟。

## 2026-10-18 范围与已确认方向

已确认的是两类分工、强构筑成长方向和完整路线时长目标；本轮先交设计文档。法术决定玩法、道具强化机制和支持强构筑的原则沿用[历史08](08-四十五房扩展与宝物定位.md)。本文道具指局内宝物，局外触媒／宝石仍按原装备体系管理；保留“宝物”作为界面总称是草案建议。

用户未要求本轮立即实现新增道具、防御、治疗、受伤触发、分类抽取或节点改变。当前运行仍为3件generic＋18件fire，共21件；当前无防御属性，清房只补盾、不回血。新增内容不据文档存在就记为已实装或全库获准。

## 2026-10-18 设计交付

[通用道具设计草案](../../游戏设计/历史方案/10-通用道具设计.md)提出24件完整候选：3件沿用通用、2件现有P04／P05拟整体迁类、19件新增，分蓝10／紫10／金4。若全案采用，则通用24件、原火系剩16件，总40件；迁类不新增同效果副本。

推荐首批12件，其中沿用3件、新增9件；金色复杂触发和P04／P05迁类留待后续。首批范围旨在降低实施复杂度，不限制强构筑收益。品质、数值、箱内1通用＋2职业、四个末段替代节点、提前金色保证及取消末箱均供审查，未写运行data。

候选机制和参数保存在设计稿／设计预算中；模块只记待审入口与当前运行边界。README和设计导航关联新稿，原21件制作基线保留。

## 2026-10-18 数值与事实核对

使用game-balance-analysis做静态预算，write-page规范组织审查文档；依据当前基础、21件与真实core核对，官方模拟宇宙相关资料只提供机制结构参考，名称／数值／实时规则为本项目原创。参考索引见[记录](../../../build/qa/generic-items-design-20261018/reference_notes.json)。

[预算工具](../../../tools/balance/generic_items/README.md)与独立proposal输入保留；[结果](../../../build/qa/generic-items-design-20261018/budget.md)通过41项手算／边界检查，覆盖216个指定场景、400个合法六件组合边界和16个首批输出场景。四件混合理论伤害约提高22.15%—22.28%；指定六件满条件约77.87%—85.09%，首批五个输出项全开约72.17%—75.91%；精英、半血、完璧与狩猎同时生效的六件组合最高121.32%。

初稿曾把90%作为六件输出参考线，用户随后明确输出跃升可以接受。最终预算保留所有数值，取消参考线的通过门槛含义，不将121.32%视为必须削弱或阻断完整候选库的警告，也不增设总增伤上限。静态工具仍检查暴击、冷却、减伤、单位与公式；不递归是后续实施约束，不能冒充已测试动态触发链。语义更新与数值不变记录见[核对](../../../build/qa/generic-items-design-20261018/semantic-update-audit.json)。

预算不模拟实际条件覆盖、出牌顺序、P04／P05动态、完整60房及Boss或真人时长。后15房与Boss需共同承接成长和最终约30分钟目标；不通过先削弱成型收益或加厚现有所有敌人来固守旧45房时长。

本轮只核文档引用、分类／数量／状态和预算公式。运行脚本、data、场景、素材、存档、Godot引擎及导出清单保持；不重复无关玩法测试，不导出、提交、上传或启动互动游戏。具体交付核对见[文档审计](../../../build/qa/generic-items-design-20261018/documentation_audit.json)。

下一步由用户审查清单、规则与奖励方案，再确定实施范围；对输出跃升的认可不等同于批准全部条目或节点改动。

同一消息要求先系统整理角色属性、伤害乘区等战斗底层，以支持后续敌人和内容拓展。当前继续讨论而不立即实装道具；新任务见[历史10](10-战斗系统整理.md)。设计认可、运行实现与新增底层建议分别记录，不重复要求用户审核已经通过的24件。

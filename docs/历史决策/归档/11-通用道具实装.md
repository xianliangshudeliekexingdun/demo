# 11 通用道具实装

任务开始：2026-10-18。用户明确“暴击率不设置上限，冷却缩减最高上限为60%”，要求先整理游戏设计文档，再实施已确定普通道具及图标，交给用户测试。结合前文24件全部通过，“普通道具”按通用道具解释，本轮不缩成此前建议的12件。

## 已确认的范围

24件通用全部接入：沿用U01／U02／U03，P04／P05保留ID和机制迁类，新增GU04—GU18与GT01—GT04，共24通用＋16职业＝40件。使用现有9个宝物箱与图鉴，保留品质抽样、唯一性和金色保底；额外奖励节点及分类配额没有确认，本轮不实施。

暴击率按百分点增加且不额外封顶，100%及以上的合格伤害必暴，超出数值保留，不派生超暴击。冷却缩减同桶相加最高60%，不缩吟唱、召唤物攻击或宝物内置间隔，最终法术CD仍不低于0.2秒。

通用道具的防御、增伤、恢复、破盾、击杀、站定与固定蓄能按[设计10](../../游戏设计/历史方案/10-通用道具设计.md)接入；攻击／法阵的既有混合取值时机继续保留。敌人防御、统一命中取值、其他新易伤以及46—60房／正式Boss仍是后续设计。

图标使用imagegen Skill生成19件新素材，5件沿用原图。用户授权素材接入；技术验证不替代用户美术与体验审查。不自动启动持续互动试玩、不导出。

## 实现与验证

运行层新增route_generic_items.gd及独立参数源generic_artifacts_v1.json，由route_artifacts.gd合并40件。Route负责承伤前减伤、真实盾／血损失快照、死亡优先、击杀与清房事件；法术回盾统一接入实际恢复接口，只有敌方飞行弹带projectile标签。通用条件增伤同桶相加后乘现有职业伤害，GT01直接结算固定附伤，不重判暴击或触发命中链。基础源的crit_rate限制为null（无上限），实际暴击概率从100%起必定成立；仍消耗原有一次随机判定，避免无故改变随机调用次数。

原Godot执行[新增规则专项](../../../build/qa/generic-items-implementation-20261018/rules.json)333项／0失败，独立[40件宝物](../../../build/qa/generic-items-implementation-20261018/treasures.json)426项／0失败、十火361项／0失败、[45房专项](../../../build/qa/generic-items-implementation-20261018/route45-rules.json)843项／0失败。[主suite](../../../build/qa/generic-items-implementation-20261018/main/main_suite_results.json)9420项／0失败，包含真实四构筑路线成长1867项子范围，不重复加总。

主suite的四条自然路线均完成：三条起始进攻路线总时1561.14／1633.82／1639.80秒，防控优先样本2895.66秒、战斗2731.76秒，结束228／304生命。防控选择明显更慢，是后续节奏观察；不把这四条与下述两条偏好样本统称约30分钟，也不将自动通关当最终时长验收。本轮不据此反向加厚敌人、压制强构筑或改变已批准道具数值。

测试修正两个真实边界：GU16恰好3秒的浮点残余不再延长加速；GT04正常累计时保留59.x实际盾损，只在共享间隔内及触发后裁到59，不因防御造成的小数损失而漏掉本应达到60的触发。修正前正在运行的批次已停止并归档discarded标记，不作为最终通过证据；最终主suite与自然样本使用修正后核心。

[真实Route样本](../../../build/qa/generic-items-implementation-20261018/pressure/report.md)以同种子和移动策略、两种选择偏好各完成45房／466击杀／9次宝物领取，来源哈希稳定。通用优先实取9通用，旧偏好实取5通用／4职业；路线总时分别1701.14与1429.84秒，战斗1559.38与1306.09秒，承伤包含盾吸收。这是当前40件池中不同实际选择轨迹，不是原21件版本复刻，也不推断真人胜率、单件因果收益或最终60房含Boss时长。自然样本没有取得GT01，金色蓄能与复杂回复的规则证据来自明确夹具，不能冒充自然触发。

本轮[公式](../../../build/qa/generic-items-implementation-20261018/formulas/results.md)317项／0失败，含288项中性新项等价；[静态预算](../../../build/qa/generic-items-implementation-20261018/static-budget/budget.md)45项边界与216场景通过，读取新上限。旧315／41项报告保持原输入快照，不用静态公式代替动态core或未来Boss验证。

旧route45_tests首次复核沿用了原输出路径，原route45目录rules.json已被新版843项结果覆盖；后续输出改为本轮目录，原阶段的日志／来源记录保留，不能再把该旧路径JSON当原21件独立版本的证据。旧十火专项固定JSON同样属于重新运行的输出，本轮独立日志绑定当前范围。

# 其余五系详细设计

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

日期：2026-10-18。任务：依序细化冰、雷、风、岩、灵契法术与职业宝物文档。

## 授权与交付边界

正式火系实装交付后，用户明确“我接下来有点事情，可能不在，请你按照顺序细化其他5系法术及道具文档”。据此完整完成五系文档供其回来审查，不因用户暂时离开而停在提纲，也不把撰稿扩大为运行实施、素材生成、触媒／魔尘／存档迁移或新体验认可。正式火系本轮试玩仍按[历史13](13-正式火系实装.md)的技术交付范围阅读。

顺序沿[总纲12](../../游戏设计/未来方案/12-正式触媒与法术体系.md)为[冰14](../../游戏设计/历史方案/14-正式冰系法术与职业宝物.md)→[雷15](../../游戏设计/未来方案/15-正式雷系法术与职业宝物.md)→[风16](../../游戏设计/未来方案/16-正式风系法术与职业宝物.md)→[岩17](../../游戏设计/未来方案/17-正式岩系法术与职业宝物.md)→[灵契18](../../游戏设计/未来方案/18-正式灵契法术与职业宝物.md)。每系十术、三个独立起手、一个占槽被动、三级完整值，以及10蓝／3紫／3金共16职业宝物；伤害、时序、资格、无前置回退、对象容量、组合优先级和失败边界均写入。五系合计50法术／80职业条目，含F04与B04／P01／G02兼容条目，不把它们又记为新增ID。

## 推荐方向与明确取舍

- 冰采用单份寒霜与冻结／冰裂窗口，碎冰消费一次旧窗口；短硬控与3秒再次冻结免控分开，强敌可碎冰但不被硬冻。是否学习碎冰及自动节奏属于构筑取舍，不新增手动兑现键。
- 雷用单份导电与逐边距离／遮挡查询，有限连锁不重访。过载只强化有限既有边，不把空跳数压回孤立目标，也不复制火系燃料爆炸。
- 风读取真实自主路径，顶墙／受推／传送不发移动收益；风环转折时只锁一次归航点，风痕有长度、寿命和跨实例命中预算；窄风幕只减带内敌弹速度，不主动销毁／反弹。
- 岩采用三种各一、总三的非阻路构造；消费、替换、到期互斥，借源待办失去源即取消。坍岩会牺牲尚存输出／防御，回盾、减伤与盾上限不混算。
- 灵契保留兼容ID但明示正式候选改制：共享单契印、同名／总容量、有限续命；号令只组织当前契灵，不重置普攻。普通攻击、号令动作、协同伤害和旧G02跨系触发分别定义。

新五系释放固定等级／几何／系数，命中实时读进攻属性是本轮待审建议；不修改现火系部分快照或现F04。普通／精英／固定强敌控制系数、减速取最强及45%／25%／15%限幅也是新建议，不能写成当前敌人已有系统。[共通19](../../游戏设计/未来方案/19-五系共通规则与数值审查.md)集中处理乘区、死亡例外、自然动作与派生分量、旧24通用兼容及审查风险。

## 数值与证据

保留[离线工具](../../../tools/balance/five_schools/README.md)及五份可编辑候选JSON。它们放tools而非data，不成为第二套运行默认值；本轮没有复制整局战斗或据输出自动调当前数值。

十五起手按三级、30／60秒、CDR0／30／60%、1／6个合法目标、100／65%命中期望共1080条事件包络；一级180生命孤立沙包按无暴击全中离散命中计算，不用六敌总量或平均DPS倒推单敌TTK。另核吟唱／释放后CD、暴击含义、唯一状态／消费、到期末击、构造和召唤容量、滚动路径预算、过载边数与有限延寿，并比较回程失手、短程无奖励、波前内缘等退化。

模型1.1最终2425项／0失败，包含1080起手包络。初轮只有近处起手，审查补出最远合法瞄准与逐跳预算漏洞：风环／双翼选敌程限收至真实可达，WB05提高每跳限额以兑现既定总预算，未增加伤害补模型；最小旧冲突作为拒绝对照保留。SP02排除只有三级S08＋F04的永久旧印空转资格，S04把8米索敌与追至3米后扫掠分清；这些是候选文档修订，不改现行运行。详见共通19的跨域复核。

具体结果、候选输入哈希与场景见[评审](../../../build/qa/five-schools-design-20261018/report.md)、[机器结果](../../../build/qa/five-schools-design-20261018/results.json)及[逐场景表](../../../build/qa/five-schools-design-20261018/starter_scenarios.csv)。模型只证明所列数学假设与边界；不包含真实AI、近战追击、自然抽取、玩家生存、正式Boss或完整60房约30分钟，不将其标作平衡通过或新五系已可玩。

交叉设计审查覆盖体验／主题、规则与操作权、挑战／成长、空间／节奏、界面反馈及制作证据；以最小可测场景保留未解决体验风险，不用“技术检查通过”消除自动碎冰、自动消费或召唤读图的不确定性。现行脚本、data、场景、资源、登记／白名单和原引擎按任务前哈希核对保持；文档引用／条目计数另核，不为纯文档任务重跑Godot玩法或像素，不导出、提交、上传或启动游戏。

本地条目、引用、当前候选输入与175份受保护文件的结果见[文档及来源审计](../../../build/qa/five-schools-design-20261018/document_audit.json)。该记录只适用于本轮文档阶段，后续真正实施时不能拿旧“源保持”审计反对新的明确授权。

用户之后的审查才决定候选采用与逐系实施范围，本轮没有代为确认数值或开放学派。

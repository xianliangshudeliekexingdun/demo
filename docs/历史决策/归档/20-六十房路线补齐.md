# 六十房路线补齐

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

日期：2026-10-20。用户表示已经实验项目框架，认为可以，随后要求开始补齐基础框架，首先完成原定60房的剩余关卡，Boss先用精英房充当。这是46—60房的实施授权；正式Boss行为与美术仍留待后续制作。

制作期间用户追加：“这次制作完成后，你不用实机测试，我们后续统一测试，加快制作速度”。本轮因此只做数据完整性、来源保持与脚本解析检查，跳过实机试玩、截图、整局自动跑测和玩法测试套件。此前45房或宝石的通过记录不替代新增15房验证，后续统一测试再确认体验与平衡。

## 实施范围

保留1—45房的遭遇、书箱节点、容量、敌人分段属性与六模板，续接46—60房“遗迹终阵”。复用当前七类敌人和已有攻击，不新增怪物素材、地刺或角色动作。

| 房间 | 编排目的 |
|---|---|
| 46—50 | 阶段衔接先回落，再发展追击、直射与落印配合，精英前减量 |
| 51 | 双精英接力混编，提供宝物箱 |
| 52—54 | 精英后回落，再向最后补给前的混编压力推进 |
| 54房后 | 自动接通基础源既定的第五间独立商店，不占战斗房号 |
| 55—57 | 补给后推进普通房峰值，再以57房精英混编提供第二个宝物箱 |
| 58—59 | 分批收束、逐步减量，为最终精英留缓冲 |
| 60 | 强化守门精英混编占位；清场开门，走门完成全程，无后续法术或宝物选择 |

末段数值以45房现有档位为锚点，只温和提高普通／精英生命，沿用该档位的移速、弹速和攻击周期。敌人伤害、预警、锁向、形状与批次完整出生规则保持。新增段的密度与生命共同构成暂定压力，未用固定等待或强行拉长每房生命来承诺30分钟；最终约30分钟仍是后续统一试玩的观察目标，强构筑可以明显缩短战斗。

逐房组合、容量与压力参数唯一归[data/courtyard_route.json](../../../data/courtyard_route.json)与[data/route_enemy_runtime.json](../../../data/route_enemy_runtime.json)。现有60房空间映射和六种模板直接复用，不复制另一套几何。该编排按level-design与game-balance-analysis技能进行静态范围核对；遵从用户要求，不在本轮执行自然战斗或数值情境跑测。

## 奖励、商店和结算

新增51／57房箱节点；46—59其余房继续现有法术三选一，包括满槽一级替换、取消返回原卡和全新三卡可放弃。原45房的奖励全部保留。全程配置48本法术书、11个宝物箱，60房不再提供无后续用途的构筑选择。

54房后商店直接由现有基础源的shop_after开放，保留一次补给、固定合法库存与单店最多购买一件。后期金币与品质继续读取既有经济源，不改价格、保证或通用／职业资格；强化精英只获得现有精英收入，不套正式Boss奖金或首领回血。全程无消费金币726、最后店前606，只是配置派生核算，不是试玩账本。

宝石路线结算上限随开放范围延至60，前段与后段每房魔尘规则保持，完整60房为105魔尘。商店不记清房或额外魔尘。持久化reward_scope的英文route45保留兼容，语义仍为当前庭院路线；旧45房结算仍为75，不改已有实例、装备、待选候选、魔尘余额或存档版本。

准备页按真实路线读取房数，按宝石收入源计算通关魔尘；结算页读取summary.room_total。宝石规则文字也从收入源显示范围。顶部三节点沿用当前及后续真实房型，最终显示58／59／60；商店独立显示。UI不判断战斗、奖励资格或收入。

## 2026-10-20后续：数量确定、四阶段与非Boss难度优先

用户回复“好关卡数量定了”，确认总数60；随后提出新的分段：前15房为前期、其后至30为中期、其后至45为后期、其后至60为超高难度。记录时按1—15／16—30／31—45／46—60消除边界重叠，15／30／45／60分别作为各段Boss房。

用户明确四个Boss房通关后固定出现法术书与金色宝箱，宝箱必出金色道具，玩家显示继续称“宝物”。这更新了目标奖励规则，包括60房，替代本档前文末房无构筑奖励的设计约束；并非此前48书／11箱或现行书箱互斥流程已经实现。领取顺序、金色合法池耗尽与资格边界尚待细化，本轮不擅自改变宝物唯一持有、职业资格、满槽规则或定义新的兑换补偿。

用户认为现有整体难度偏低，归因为怪物数量／攻击方式少、远程多数单一弹道、普通身体碰撞伤害缺失，以及大地图提供较大回避空间。确定方向为参考东方弹幕游戏增加远程弹幕怪物，并增加碰撞伤害。此反馈不撤销此前对45房节奏和整体框架的认可，而是更新后续难度目标；没有据此授权所有基础数值全面上调或缩小地图。

代码只读核对确认：普通M02单发，精英EL02及守门变体已有五向扇射；扑击／冲锋已有攻击命中伤害，尚缺追击／站立阶段的通用身体接触伤害。出处见[enemy规则](../../../scripts/core/route_enemy_combat.gd)与[受击入口](../../../scripts/core/first_room_run.gd)。新增接触伤害应与现有短保护、冻结和一次攻击命中边界一起细化，不把一般接触与攻击伤害混写为全未实现。

用户确定先把非Boss关卡难度定下来，再据此设计Boss房。本轮以game-design-review技能进行聚焦设计核对，将已确定方向、建议与未决边界写入[设计09最新章节](../../游戏设计/历史方案/09-普通房配置与难度节奏.md#nonboss-difficulty-direction)。扇射、环形、旋转扫射、连射的分工及逐段递进是设计建议，没有冒充已通过的逐怪物／逐房数值。

本次只更新设计、当前边界与导航，不改运行data／脚本／场景，不实现Boss或双奖励，不做实机、玩法套件或整局跑测。下一步围绕非Boss弹型、怪物职责、接触规则和四段遭遇形成可讨论的具体方案；实际参数与Boss强度待该基线确定后推进。

随后用户要求把四阶段数量／组合、弹幕与接触规则细化成方案，Boss后做；该新设计任务与核算证据转入[历史21](21-非Boss难度方案细化.md)，详细待审方案见[设计21](../../游戏设计/历史方案/21-非Boss四阶段与弹幕碰撞方案.md)。

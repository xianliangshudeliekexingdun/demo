# 职业宝物退场与法术成长重构

> 档案状态：历史决策与阶段证据。文中“当前／未实施”按记载时点阅读；现行规则见[主题索引](../../游戏设计/README.md)，最新状态见[功能模块](../../功能模块.md)。

日期：2026-10-20。用户在四Boss制作后提出重新修正道具设计。首轮文档阶段含三层成长的误读；用户随后明确纠正并要求细化后直接实施，最新结果见本页后半段。

## 首轮文档阶段的背景

用户担心每职业继续增加大量道具，会形成过多内容和无效道具，提出先把现有专属道具效果转移到法术升级，再删除现有专属道具；制作完所有法术后，再统一制作相关法术的专属升级。法术升级要更厉害，未来专属道具应更加专精、强力。

该指令更新后续设计路线，取代原每系固定16职业／完整六系96职业的制作配额。六系法术方向及法术决定玩法的原则保留；不据此自动开发其余四系或现在创建新的专属升级入口。

## 本轮核对与设计交付

实际运行目前为十火／十冰三级、火冰各16职业，普通随机池56件，另4件Boss庭印和3归档灵契定义。不是各18件；现有候选已经过滤法术资格，但替换掉法术后旧职业宝物仍持有且可能失去收益。此处区分可由规则推导的边界与尚未取得的玩家统计。

新增[设计23](../../游戏设计/历史方案/23-职业宝物退场与法术成长重构.md)，完整登记32件旧物品的已有机制及建议归宿。二十件单术强化可以直接对应现有二十术；另外十二件紫／金涉及多术条件、共享计数、燃烧／冰裂窗口与真实回复，需要明确承载，不能全部塞进一个必选被动、重复发给每个法术或静默丢弃效果。

首轮整理误把现有三级常规成长、未来统一的法术专属升级、未来少量强力专属道具拆开。该三层拆分未经用户确认，随后被用户明确纠正，见后文。保留三级是迁移建议，具体等级分配、数值、跨术效果承载和未来专属升级形式尚未逐项确定；不冒充用户已通过每一行映射。

迁移后旧职业物品应退出箱、商店、现行图鉴和获取流程，效果只保留法术等级来源。24通用、4庭印与局外触媒／宝石不在这次删除范围；P04／P05已经迁类通用，不能按旧文件位置误删。旧ID和素材按兼容需要归档，历史批准与资源来源记录保留。Boss必金及现有节点继续，空池按已制作庭印规则处理。

特别记录资格联动：IG03回盾移入冰棺升级后，GT01等必须根据真实法术回盾能力判断；火系暴击门槛、自然／追加计数与替换后的状态同样需要一起切换，不只改图鉴和物品active。

## 首轮仅文档阶段的范围

本轮先整理设计与迁移清单，没有修改data、scripts、场景、资源、存档或导出配置，没有删除现行职业宝物，也没有声称新法术成长已生效。旧火／冰设计和其余四系职业表保留原阶段记录，后续制作服从本次新方向。功能模块保留真实运行状态并增加设计边界提示。

使用game-design-review检查决策复杂度、成长收益及制作范围；没有新幅度或输出预测，因此不另造数值模型。仅核32件清单、运行源哈希和本地引用，不运行Godot、实机、截图、自然通关或无关玩法测试；延续用户暂缓实机要求。

[本轮来源核对](../../../build/qa/spell-upgrade-direction-20261020/source_audit.json)确认32件清单完整，407个运行／资源／引擎及导出配置文件保持；所有新增本地引用有效。

后续先细化每术三级与十二个跨术机制，再按迁移结果切换已有火／冰；完成全部法术后统一设计专属升级和新专属道具。用户本次“好”是开启新问题的上下文，不扩大为刚完成Boss的实机、像素或最终平衡认可。

## 十火／十冰三级与职业退场实现

[设计23](../../游戏设计/历史方案/23-职业宝物退场与法术成长重构.md)现包含二十术完整三级表、32件归宿、作用域调整和结算边界。运行唯一覆盖源为[data/route_spell_growth.json](../../../data/route_spell_growth.json)，core和图鉴通过同一加载器应用；原一级主伤与职责保留，二级增强输出／覆盖／循环，三级承担更强机制。旧独立首房规则和对应卡牌仍读历史等级，避免现行路线改动造成旧入口文案与实际错配。

十火把暴击留火归F01、火伤／暴击归F02、首落归F03、首中减速归F05、重叠与成熟爆发归F06、自然强化引爆／复燃归F07、本术回响归F08、命中机动归F09、回盾归F10、传播与全局长燃归F11。十冰把单术增强并入对应等级，首段补霜给I02／I03、后续合格补霜给I06、邻片施霜／主冰裂留霜给I07、新窗口回盾给I08、受伤反霜给I09、普通霜保存给I10。

跨术收拢不是逐条件等价搬运：P02只由自然焰弹暴击生成；G03只由自然法阵成熟生成；G01拆为F02属性与F08本术回响，计数跟随当前法术实例；IP01不给已有相应三级职责的I01重复加层，IG01不给I05重复机制；I08回盾取消旧I09搭配前置。一级碎冰保留原主冰裂，旧IB07收益进入二、三级。全部范围变化均写进设计表，没有静默丢掉多效果项。

32件职业标为退场，箱／商店／图鉴／持有展示与残留持有均不可再激活；旧ID和原PNG作历史追溯，不重复叠加。普通池现在24通用，另4件Boss专用庭印；完整63定义含35归档。P04／P05保留，Boss书后必金、空金池庭印、52书／12箱、五店、房间编排、金币／魔尘、局外宝石／触媒与存档保持。GT01资格跟随I08真实回盾，GU07门槛跟随F02火系暴击。

火冰继续使用原自然／追加、逐cast／逐敌和共享间隔。燃烧只一份、下跳不重置，短刷新不截断已释放长燃；F07实际消费旧燃烧才可延迟复燃，自然附加2倍与复燃不供追加爆弹。碎冰仍消费唯一旧token，邻片不回填主目标、不递归；I08只在自然新窗口恢复实际缺盾，I09只在护体内实际受伤且存活后反霜。已释放几何与触发参数保留快照，清场／死亡清队列；派生留火与成熟爆发不复制游走核心本体倍率或法阵主段快照，保持原核心本体／派生边界。

卡牌、图鉴等级详情与提示已同步；宝物页按全部／通用／庭印显示。32张旧职业PNG撤出现行图标预加载与导出清单，原文件、来源和哈希保留，无新绘画／字体／角色动作。新core及JSON加入显式导出依赖，本次未导出包。

## 本次数值核算与规则证据

使用game-balance-analysis；本地工具保留于[tools/balance/spell_growth](../../../tools/balance/spell_growth/README.md)，`.gdignore`隔离且游戏无引用。使用实际Route／法术／状态core的固定目标，不另复制伤害公式；冻结旧法术／职业源，比较旧无职业、新无职业、强制旧全职业参照，另做主伤系数±10%扫描。手算已知案例按实际基础燃烧4秒8跳，100＋8×25＝300核时序；不沿用摘要误记的3秒6跳。

每版162场景，包含单术一至三级、单／三敌、火／冰／混搭八槽、三种子、高暴击与60%冷却边界；五版共810场景。二／三级单术定点伤害无回退，真实回盾和护体覆盖率单列。三级固定三敌的新／旧无职业均值约3.00／1.39／1.83倍，火系输出提升更明显；混搭没有复制全部全系旧职业的收益。允许构筑跃升，没有抬敌血抵消，也不把该模型当跨系最终平衡。三种子范围不是置信区间，模型不含敌人移动／死亡、自然选奖、生存、全路线用时或性能。

# 风岩灵契三级成长实装

日期：2026-10-21。当前规则与默认值看[法术体系](../../游戏设计/法术体系.md)及其指向的运行data；本文保存授权、选择及验证范围。

## 1. 用户授权与推进顺序

在雷云修复、雷系十术完成后，用户明确：“可以，接下来推进其他系列，请你一一制作完成，按照设计文档，制作推进。按抽取方案等六系完成后再统一调整。”本轮据此按风→岩→灵契制作，每系十术、三级与独立起手，对照原16／17／18及共通19。为缩短制作时间并行准备独立模块，逐系核规则并集成到同一运行链。

沿用历史23／26的宝物边界：旧职业来源按职责适配二／三级，逐项标明未迁入部分的未来归属；不恢复每系16件配额，不新增独立法术专属升级。既有24通用＋4庭印保持，F04／B04／P01／G02保留兼容归档。

## 2. 最终实现与兼容

- 风系十术：有限贯穿／回旋／推拉、真实移动记录风径、静态风幕减敌飞弹位移；不更改敌方预警或伤害时间。移动记录只取规则实际路径，不把顶墙输入或传送算作走位。
- 岩系十术：不阻挡／不受击构装、容量／到期／消费／替换的唯一终止、有限共振与硬控。冰岩防御走同一承伤入口和45%综合减伤上限。
- 灵契十术：S02承接正式远程召唤，近战和灵鹰遵守墙体路径、总攻击单位上限4与有限寿命；末次普攻先于同刻到期，号令不重置普通间隔，归灵只消费一次，法阵延寿有限。
- 三系均接入现有自然／追加、法术书、满槽一级替换、共鸣、图鉴、程序图标和只读表现。召唤普攻及明示派生使用独立伤害入口，不能回普通本体命中／自然释放链；原稿明确可暴击的风岩派生仍允许暴击。
- 已知前置：新R06需任一构装来源；新S05／S07需任一召唤来源。60是正式活跃定义数，未持有来源时初始可抽57；已持有术替掉来源后保留，释放看实际场上对象。

当前规则详见[风](../../游戏设计/风系法术成长.md)、[岩](../../游戏设计/岩系法术成长.md)、[灵契](../../游戏设计/灵契法术成长.md)。原编号方案、工具候选、引擎、素材与火冰雷源保留原始字节，不为后续事实重写旧证据。

## 3. 抽取安排

“抽取方案”继续指法术书三选一的合法池、每ID权重、已有升级／新学、触媒倾向与成本。制作阶段只补新法术合法资格及前置，沿用现行按ID加权、不放回三选一。六系完成后再统一讨论与实施概率、倾向及价格；没有把总纲12候选公式或费用当作已批准默认值。

本轮仍只有火／冰两触媒，其余四系可独立起手并以基础权重参与书奖；账号v4、存档键、抽取保底、费用和奖励节点未变。

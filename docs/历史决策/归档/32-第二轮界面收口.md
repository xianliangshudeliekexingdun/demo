# 32 第二轮界面收口：删除预览入口与准备页重排

日期：2026-10-25。当前实现与证据见[功能模块](../../功能模块.md)，界面分工见[项目架构](../../项目架构.md#2-模块职责)。

## 用户要求

用户在看过多轮截图后提出两项：一是界面存在大量开发期遗留，点名“首房试玩”“60房起手”这类文案；二是准备页布局需要第二轮优化。用户要求先讨论方案再执行，并在四个取舍点上直接选择：删除入口与预览页、主按钮写“出发”、宝石2×2＋属性4×2、范围限定准备页与全局页头页脚。

## 删除的内容

`scripts/ui/atelier_ui.gd` 删除 `PREVIEWS` 常量与七个预览页的全部构建代码：`preview`、`preview_navigation`、`spell_choices`、`artifact_choices`、`shop_preview`、`hud_preview`、`result_preview`、`mixed_opening_ids`，以及“查看界面预览”“进入首房试玩”两颗按钮和它们专用的 `choose_preview`、`artifact_detail`、`supply_preview` 请求。

`scripts/main.gd` 删除 `start_room` 请求、`start_first_room`、`FirstRoom` 预加载，以及进入预览页时 `meta.begin_run()`／离开时 `end_run()` 的装备锁定分支；`navigate` 回到普通页面栈。`_start_room(map_trial)` 收为 `_start_route()`，只创建 `CourtyardRoute`，run 标识仍写 `route45`。

保留：`scripts/core/first_room_run.gd` 与 `first_room_ui.gd` 的旧首房分支仍在，`first_room_tests` 继续直接驱动核心；玩家界面已不可达。背景 `atelier_art` 中只在面板上方露出柱头的两根柱子一并删除。

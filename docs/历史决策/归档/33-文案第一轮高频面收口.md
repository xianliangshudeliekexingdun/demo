# 33 文案第一轮：规范与高频面收口

日期：2026-10-25。现行写法见[文案规范](../../文案规范.md)，当前实现与证据见[功能模块](../../功能模块.md)。

## 用户要求

用户在第二轮界面收口之后提出文案要专业化，并要求参考相关 skill：范围包括图鉴介绍、法术效果描述、属性面板等玩家可见文字。

## Skill 检索结果

技能市场可搜到的文案技能全部是带货／投放向（种草、信息流、电商 Listing、商品文案），专家库也检索不到游戏文案角色；这类框架会把说明文案写成广告腔，因此不采用。改为自建项目级技能 `.workbuddy/skills/game-copywriting/SKILL.md`，把流程（判定层级 → 查术语表 → 写句子 → 去重 → 跑检查 → 更新证据）固化，规范正文放在 `docs/文案规范.md` 作为唯一事实源。

## 用户拍板的四项

1. 语气：无人称说明体，不写“你”“我们”。
2. 图鉴详情：四字段分条（定位／效果／消耗／限制），一行一条规则。
3. 等级提升：保留箭头对比（`0.8 → 1.15 米`），不做自然语句或三列表格。
4. 顺序：先高频面（准备页／属性／HUD／选卡／商店／结算），图鉴 60 术与宝物触媒留到 R2。

## 规范要点

- 三层结构：卡片一句定位＋一条机制；详情四字段；边界收极端条件与学派共用规则。
- 术语表：攻击力（数值）／攻击（动词）、法术书（不叫书奖）、起始法术（不叫起手）、清场（不叫清房）、本局；触媒／庭印／魔尘／精粹／核心／属性石保留。
- 数值格式：中文与数字之间空格，`25%`、`140% 攻击力`、`0.8 秒`、`8 米`、`×1.5`、`+15 攻击力`；箭头两侧空格。
- 禁词：书奖、空跳数、下跳、返还单体、历史职业宝物、无法术条件、全系列、清房、起手、存活敌人、不是必出、不保证必出、实际概率。

## 本轮改动

- 准备页：触媒副行改为「学派起始 · 法术书偏向 +X%」；宝石卡空态「无核心效果」；装备页 intro 去掉「起手」。
- 属性面板：`loadout_summary.gd` 新增 `HINTS` 与 `hint_for`，八项各配一句话规则说明并写入格内悬停；暂停页与图鉴装备页的重复图例已在上轮删掉。
- 战斗 HUD：目标行（击败所有敌人／清场 · 选择成长／走进传送门…）、剩余敌人数（原「存活敌人 X / 2」硬编码 2）、门与宝箱提示、暂停页（已暂停／结算按已清场的战斗房计算魔尘／继续）全部改写；生命护盾的巨型 tooltip 拆开。
- 选卡与替换：开局说明「全系列（未装备触媒）」→「未定（未装备触媒）」；副标题与按钮文案重排；等级一律「1 级」「2 级 → 3 级」。
- 商店：标题去字距空格，副标「第 N 房之后 · 每店限购一件」，补给、空态、状态行与购买按钮文案统一。
- 结算：清场数、金币收支、魔尘行改写；去掉「后续房间将在这个流程上继续制作」等开发表述。
- 触媒：六张同文改为分小节（术数／起始法术／倾向／卸下），概率说明保留在悬停的 `catalyst_reference_text`，只写一次。
- 同步：暂停按钮「继续试炼」→「继续」，15 个视觉脚本按文字点击处同步。

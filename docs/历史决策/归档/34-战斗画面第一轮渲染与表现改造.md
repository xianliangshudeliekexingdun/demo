# 34 战斗画面第一轮渲染与表现改造

更新：2026-10-26。本档只记录本轮画面改造的方向、授权与实施／验证范围；现行实现状态见[功能模块](../../功能模块.md)，规则仍以[六个系统主题](../../游戏设计/README.md)与data为准。

## 1. 用户确认与方向

2026-10-25 用户提出：接下来任务是优化游戏内战斗表现画面，包括 UI 布局、战斗场景、渲染风格、法术特效、角色模型，并明确“先做最明显的，如渲染这类”。据此本轮按下列顺序实施：

1. 渲染基线；
2. 法术与战斗反馈；
3. 战斗 HUD 层级；
4. 战斗场景模板；
5. 角色／敌人表现。

已决定方向：**月光遗迹 × 暖金魔导**。环境保持低饱和冷灰蓝石材，角色与关键物件偏暖，敌方危险继续用独立珊瑚红／玫红体系，UI 沿用深蓝／暖金／青色。该方向优先利用现有批准资源，不需要新增外部模型或字体。

## 2. 已实施

### 渲染基线

- 战斗环境改为 Filmic 色调映射与轻微远景雾；雾只用于压低外围遗迹，不覆盖战斗区、脚下和危险范围。
- 主光改为暖色并保留唯一投影方向光，补光为较弱的冷色方向光；相机、战斗几何、MSAA 与视口尺寸不变。
- 全局 Glow 仍关闭；此前 Compatibility 下的 A/B 已否决全局泛光，继续用局部光斑与真实灯光维持暗背景。
- 石材／泥土／布料／金属材质分层：石材保持高粗糙并降低镜面，金属包边与王冠加入金属度，进口金／黄铜等物件不再等同于粗糙石墙。

### 法术与战斗反馈

- 敌弹在覆盖层中增加深色分离底衬，火焰、金色包边和明亮命中都不应盖住敌方弹体。
- 友方持续区域特效、燃烧、吟唱火光降低亮度；命中类效果保留高亮并新增短促命中核心，形成“持续低、瞬发高”的层级。
- 玩家受伤环按真实字段区分：消耗生命用暖红，仅消耗护盾用青色；不改变伤害、护盾或事件。

### 战斗 HUD

- 生命条加厚、字号提高，护盾保持次级信息；低生命只改变 HUD 强调色，不代表新状态或新规则。
- 法术槽名称按被动／吟唱／冷却／就绪着色；宝物条在八个法术槽上方居中；路线模式在房间标题下方补回“剩余敌人”，Boss 血条占用该行时让位。
- 低频的出发属性摘要改为随“操作与流程提示”显示，减少常驻干扰；完整属性仍可在暂停页查看。

### 场景与模型表现

- 六类庭院模板保留几何差异，同时增加克制的色板差异：石材偏冷，trim 在暖金、青铜、绿调之间区分，且房号 10 后略作变化。
- 莉奈保留已批准模型与待机／跑动／分段施法动作，只调整材质响应；没有新增动作、没有整图晃动替代步行动画。
- 敌人与 Boss 程序材质区分金属／布料／石材，预警与受击覆盖透明度略微增强；不新增外部资源，不改变轮廓碰撞与索敌。

## 3. 规则与边界

本轮全部为表现层改动：不修改 core 规则、data 数值、生命／护盾、伤害、范围、寿命、预警时间、随机奖励或领取资格；不改相机视距与战斗几何；不新增或替换正式美术资源；不导出新版。

## 4. 验证范围

- 文案检查 18773 项／0 失败；六系特效边界 641 项／0 失败；商店控制器界面 21 项／0 失败；宝石界面 1684 项／0 失败。
- 旧显示偏好脚本仍调用已移除的“独立首房”入口，触媒界面旧脚本仍按旧菜单结构断言；两者未作为本轮证据，也未据其结论判定通过。
- 火／冰渲染像素脚本要求原生显示，headless 下无法运行；本轮没有实机、截图、自然整局、性能测量，也没有像素级可读性验收。

后续统一实机待检查：新色调与轻雾下的弹幕／预警遮挡、1280×720 下 HUD 字号与点击舒适度、新敌弹暗底在实际高亮场景中的可读性、六模板色板与敌人材质表现、高弹量性能；再决定是否继续调整参数。

## 5. 2026-10-26 攻击预览与法术槽二次收口

用户在统一实机前继续给出战斗画面反馈：法术名称下方和槽位右上角等级存在不喜欢的黑色底块；攻击预览当前重红色不佳，记忆中前一版颜色可以，同时首帧与末段都不够清晰并出现断层。

本轮按表现反馈收口，不改变任何规则：

- 法术名称与等级徽章移除深色 `StyleBox` 底框，改为透明底＋细字形描边，保留名称常驻、等级避让图标与原有字号／位置。
- 攻击预警从“前 70% 虚线轮廓、末 30% 才填充”改为首帧即有低透明完整足迹，轮廓和填充随时间连续增强；生效阶段继续加深。
- 方向型预览改用连续闭合轮廓，末端圆头与侧边一次连成路径；连续裁剪段合并为 `draw_polyline`，避免独立线段拼接造成的微断口。
- 配色从重红＋粗暗红描边回到柔玫红／珊瑚体系；保留更窄、低饱和的中性隔离边维持石砖与暖色地砖上的对比。旧敌弹与敌方危险仍保持独立珊瑚红／玫红识别，不新增友敌歧义。
- 预览显示不改变命中范围、攻击方向、预警时长、伤害、索敌或随机结果。

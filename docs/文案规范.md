# 文案规范

更新：2026-10-25。本文管玩家可见文字的**写法**：语气、术语、条目结构、数值格式与禁词。规则本身见[游戏设计](游戏设计/README.md)，实现与证据见[功能模块](功能模块.md)。改文案前先读本文；改完跑 `tests/copy_lint.gd`。

## 1. 语气

- 无人称、现在时、陈述句。不写“你”“我们”，不写“可以”“能够”这类空转词。
- 一条只讲一个规则。否定句只写真正的限制，放段末。
- 不解释“我们没暗箱”。概率、保底、排除项各写一次，放在规则页，不塞进每张卡。
- 不用感叹号，不用“请注意”“务必”。

## 2. 三层结构

| 层 | 位置 | 写法 | 长度 |
|---|---|---|---|
| 卡片层 | 选卡、图鉴列表、商店卡 | 一句定位 + 一条核心机制 | ≤ 2 行 |
| 详情层 | 图鉴右栏 | 定位／效果／消耗／限制，一行一条 | ≤ 80 字 |
| 边界层 | 悬停提示、折叠块 | 极端条件、排除项、学派共用规则 | 按需 |

学派共用规则（燃烧、寒霜、导电、风径、构装、契灵）在学派说明里写一次，单卡只写差异。
零值条件不出现：没有邻片就不写“邻片 0 名”。

## 3. 术语表

| 概念 | 使用 | 不再使用 |
|---|---|---|
| 伤害基准 | 攻击力（数值）／攻击（动词） | 攻击当名词、当前攻击力 |
| 冷却 | 冷却缩减、冷却时间 | CDR、冷却缩减率 |
| 法术奖励节点 | 法术书 | 书奖、法术书奖励 |
| 开局三张 | 起始法术 | 起手、起手三选一 |
| 一场战斗结束 | 清场 | 清房、通关房间 |
| 冻结状态 | 冻结；结算时刻 | 窗口、冰裂窗口（“冰裂”只作名词） |
| 局内货币 | 金币；魔尘；精粹 | 钱、尘、精华 |
| 装备 | 触媒、宝石、核心、属性石 | 神器、装备（指宝石时） |
| 宝物 | 宝物、庭印 | 道具、历史职业宝物 |
| 一局 | 本局 | 本场、本关 |

## 4. 数值与标点

- 中文与数字之间空格：`25%`、`140% 攻击力`、`0.8 秒`、`8 米`、`3 层`、`1 级`。
- 百分号紧跟数字，后面空格：`25% 攻击力`；倍率写 `×1.5`；加值写 `+15 攻击力`。
- 变化用箭头，两侧空格：`0.8 → 1.15 米`；多个短项用 ` · ` 分隔。
- 单位只写一次：`0.8 → 1.15 米`，不写 `0.8 → 1.15米`。
- 范围用“至”：`1 至 2 层`；不要用 `1~2`。
- 句末不加句号的条件短句（卡片、按钮、标签）；完整句子加句号。

## 5. 禁词

开发词：空跳数、下跳、返还单体、历史职业宝物、无法术条件、全系列、书奖、清房、起手。

辩护语：不是必出、不保证必出、实际概率、不是固定单卡概率（规则页只保留一次正面表述）。

## 6. 自检清单

1. 每个名词都在术语表里，且全文只有一种写法。
2. 每条效果都有数值、单位、触发条件；没有“更强”“大量”这类模糊词。
3. 没有零值句、没有重复的学派规则。
4. 详情行数 ≤ 5，单行 ≤ 28 字（长规则拆行）。
5. 否定句在段末，且只写一次。
6. `tests/copy_lint.gd` 通过。

## 7. 分层推进

- R1 高频面：准备页、属性面板、HUD、选卡／替换、商店、暂停／结算。
- R2 图鉴：60 术 × 3 级、28 宝物、6 触媒详情。
- R3 子系统：宝石工坊规则、核心状态串、图鉴页脚与空态。

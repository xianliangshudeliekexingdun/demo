# 六系法术抽取

更新：2026-10-21。用户在六系十术完成后授权统一制作。本主题说明当前法术书、六触媒和成长倾向；法术效果看[法术体系](法术体系.md)，账号事务看[局外养成](局外养成.md)。唯一抽取参数为[data/route_spell_sampling.json](../../data/route_spell_sampling.json)，解锁／升级费用与关联ID为[meta_growth_v1.json](../../data/balance_candidates/meta_growth_v1.json)。原总纲12及旧工具保留原阶段，不反向覆盖本版。

## 1. 目标与边界

60房路线含52次法术书，另有一张独立起手选择。目标是在保留六系发现与满槽替换的同时，让玩家已经选中的构筑有合理升级机会；触媒加强一个偏好系，不把任意指定双系同时作为最高等级的优化目标。仍为八槽、每术三级，三张候选、每次选一张，无刷新、固定新学／升级格或新保底。

| 结果 | 本版处理 |
|---|---|
| 新术发现 | 所有已开放学派均可抽到，不要求购买触媒；八槽满仍可抽新术 |
| 已选术成长 | 合法的已持有未满级ID基础权重×2；新术为1，同一ID不会按等级复制多张 |
| 单系倾向 | 触媒1／2／3级的优先强度28%／40%／52%；强度越高越集中本系 |
| 均衡混学 | 可免费卸下触媒；没有触媒时仍保留全局升级权重×2 |
| 起手 | 装备触媒时锁定该系三张基础术；未装备时为六系18张基础术随机三张，可重复学派、不重复法术 |
| 宝物与宝石 | 箱子品质、宝石抽取概率／保底／费用不受法术触媒影响 |

“基础权重×2”不代表升级必出，优先强度也不是固定本系单卡概率。两者都不增加奖励次数或法术伤害。

## 2. 每张卡的实际算法

1. 从运行60术中先过滤未开放、已持有满三级及不满足来源前置的新术。R06需任一R03／R04／R09，S05／S07需任一S02／S03／S04；已学会但后来失去来源仍保留升级资格，释放看实际对象。八槽满不剔除新术。
2. 给剩余各ID基础权重：新术为1，已持有且可升级为2。未装备触媒时直接按这些权重抽。
3. 装备有效触媒时，令M为剩余本系权重和，O为其他系权重和，q=M／(M＋O)，本系概率p=q＋(1－q)×a。a读取触媒等级强度。两组均非空才需要分组；若某组为空，就在仍有合法ID的组内抽，不强造卡或承诺不存在的升级收益。
4. 本系分组内ID概率为p×w／M，其他分组为(1－p)×w／O。抽中后移除该ID，按剩余池重新计算下一张。代码用等价的一次CDF随机数完成每张，三个候选ID不重复。
5. 抽到已学术则原槽升级，新术未满槽学一级，满槽指定旧槽确认一级替换。取消／重开保留原卡及RNG；全新三卡可显式放弃，八术满级也继续提供替换。

自然占比q按**合法权重**而非未过滤总定义数计算。过滤、升级、前置、已移除卡都会改变它；图鉴、快照或概率查询不推进随机数。只有真正生成奖励权益时采样一次，不因取消替换重抽。没有强制某一学派出现的保底。

## 3. 概率基准与取舍

下表只用于可复算的“本系10、其他50全部合法且同权”理论基准，**不代表真实起手后的固定概率**；真实起手已持有一术且部分支持术未解锁，权重和合法池都会不同。

| 触媒 | a | 第一张本系概率 |
|---|---:|---:|
| 无 | 0 | 16.67% |
| 一级 | 28% | 40% |
| 二级 | 40% | 50% |
| 三级 | 52% | 60% |

旧逐ID权重1.5／1.75／2扩展到同一10＋50理论池，满级首张仅约28.57%；本版将“主系一致性”和“已选术升级”作为两个独立参数。原独立首房继续保留历史逐ID权重，不能将它的结果当成正式六系书奖。真实火／冰／雷／风起手一术已持有且合法57时，首张本系约41.66%／51.38%／61.10%；岩R03起手会解锁R06，灵契召唤起手会解锁两项支持术，合法池也各有不同。

高等级触媒对纯系／主系成长更有帮助，但会降低指定副系的相对曝光。固定4＋4策略在高级主系触媒下的副系升级尾部仍可能较慢；这是一项公开取舍，并非“高级触媒加快任何构筑”。偏好均衡混学可卸下触媒，保留×2升级倾向。没有指定副触媒或副系保底。

## 5. 模型、运行证据与限制

持久工具为[六系抽取模型](../../tools/balance/six_school_sampling/README.md)，直接读取正式抽取参数、60个实际ID／等级／前置、52个真实书节点与账号费用／收入；固定多批seed，比较旧逐ID方案、优先强度附近值与升级权重1／1.5／2。模型覆盖主系优先、升级优先、明确4＋4、无触媒、满槽一级替换与合法跳过，不包含战斗胜率、法术实际强度、宝物、真人选卡和完整自然60房。

[原生抽样与事务](<../../../demo 精简/20261026-项目精简/build/qa/six-school-sampling-20261021/sampling/results.json>)核对公式、去重、前置、查询不耗RNG、替换原卡／一次确认；[运行桥](<../../../demo 精简/20261026-项目精简/build/qa/six-school-sampling-20261021/sampling/runtime_bridge.json>)供独立模型逐ID核对，含×2持有升级案例。[六触媒／存档](<../../../demo 精简/20261026-项目精简/build/qa/six-school-sampling-20261021/meta/results.json>)及[UI目录](<../../../demo 精简/20261026-项目精简/build/qa/six-school-sampling-20261021/catalog/results.json>)记录受控范围，主套件与最新模型结果统一见[功能模块](../功能模块.md#5-当前有效验证证据)。

最终核算为126个情境、每情境500条、合计63000条固定种子轨迹。模型不变量／已知案例1186项、真实池回归5项、Godot概率桥171项均0失败。选中参数的[接受与警告](<../../../demo 精简/20261026-项目精简/build/qa/six-school-sampling-20261021/model/final/acceptance.json>)保留6项三级触媒明确4＋4的低尾警告；没有将目标不达标改写成通过。

自动概率与选卡轨迹不代表最终平衡或实机认可。高倾向对指定双系的取舍、合法小池、单系耗尽、满级后替换与低尾长荒必须分别报告；不得将平均数当保底。实机、截图、自然整局、性能和导出继续留待用户后续统一安排。

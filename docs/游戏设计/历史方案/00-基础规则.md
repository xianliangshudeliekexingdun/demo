# 自动构筑首关 · 基础规则

**阅读范围（文档整理）**：本页原文是自动构筑首关的历史目标与首版建议；下文带日期的“当前／下一步”均限定在当时阶段。现行操作、乘区、三级／八槽与计时见[战斗与成长](../战斗与成长.md)，60房及Boss奖励见[关卡与敌人](../关卡与敌人.md)，职业宝物退场以[设计23](23-职业宝物退场与法术成长重构.md)为准。

**设计定位（2026-10-18核对）**：设计目标／初版基线，当前实现以[功能模块](../../功能模块.md)和实际data为准。
本页保存完整首关目标与原建议。当前已实现自动施法、八槽、十火三级、相性、真实拾取和双计时；实际开放范围和奖励节点以功能模块及路线data为准，不能把本页原奖励间隔当当前配置。

日期：2026-10-17。本文记录目标设计；实际实现状态以[功能模块](../../功能模块.md)为准。用户明确给出的规则列为“已确认”，为使首版可制作而补充的细节列为“本稿建议”。

2026-10-18追加：用户明确法术决定玩法，配套道具统一改称“宝物”。法术构成攻击方式、节奏与组合方向；宝物强化相应机制，或成为特定强力构筑成型的关键。该原则不要求所有通关依赖同一件指定宝物，也不改动既有21件效果。新增16—30、31—45房按两个递增难度段推进，具体决策见[历史08](../../历史决策/归档/08-四十五房扩展与宝物定位.md)。

## 1. 玩家操作与自动施法

2026-10-18后续确认：当前45房节奏获得认可，最终完整60房及Boss暂定约30分钟，允许强力构筑明显输出跃升。以后局内道具分通用／职业两种；用户本轮先审详细文档，[设计10](10-通用道具设计.md)的新增效果、数值、迁类与奖励安排尚未成为制作基线。

### 用户已确认

- 玩家只管理移动。移动中持续自动吟唱，技能冷却结束且有目标时自动施放。
- 移除玩家主动瞄准、手动松键释放、切槽施法和闪避操作；移除法力。
- 法术保留各自冷却。玩家通过走位、选法术、选升级和宝物影响战斗。

### 本稿建议

- 吟唱是法术自己的自动前摇。不同主动法术独立判断和计时，不用一个公共吟唱队列堵住八个槽位；被动法术不产生前摇和施放事件。
- 移动不取消吟唱、不减速；受击不沿用旧版要求重新按键的规则。敌人必须能用普通移动躲避，不能把已删除的闪避当作躲攻击前提。
- 成功施放才开始该法术冷却。无合适目标时保持就绪；前摇结束时目标死亡，重新选取合法目标，仍无目标则取消且不进冷却。
- 目标型法术从射程及遮挡规则允许的敌人中选择；最近者优先，同距离按稳定敌人编号。少数法术在自身条目中注明例外。
- 选定方向或落点后，弹体、火雨及光束按该次施放的规则完成，不因目标切换而反复追踪。法术范围不能跨越房间边界。
- 用户已确认按攻击类型区分：光束和直射弹受实体掩体阻挡；火雨与高抛爆弹可落到障碍后的合法地面，爆炸和持续范围伤害可以越过掩体。具体碰撞方法留待工程实现。
- 清场、选奖励、商店、暂停与结算期间停止战斗计时和自动施放；不能在奖励界面等待法术回盾、缩短冷却或继续触发宝物。

## 2. 法术槽位、开局与升级

### 用户已确认

- 最多携带八个法术；开局从随机三个基础法术中选一个，承担初始普通攻击职责。
- 后续选择新法术占一个槽；选择重复法术强化该法术。结合用户“后续规则相同”和拆解案，最高三级。
- 多个有相性的法术触发特殊效果。每个系列的内容目标是十个法术。

### 本稿建议

- 起始选择池只含可独立造成伤害、无需其他法术搭配的基础输出法术；被动精通、护盾恢复和纯辅助不能单独作为开局普通攻击。
- 正式开局从所有已开放系列的基础输出池抽三个不同法术。本轮只设计火系，以焰弹术、赤焰灵契、贯焰光束作为三个可独立测试的火系开局候选；这不等于决定正式版开局必定全是火系。
- 同一法术各等级始终只占一个槽。达到三级后退出该局法术候选池。
- 原首版八槽满时只出已有升级；后续用户已确认持续三选一与一级替换：满槽仍可选新术，指定旧槽再确认，取消回原三卡；满槽全新三卡可放弃奖励保留构筑。当前实现与验证见[历史16](../../历史决策/归档/16-满槽替换与持续法术奖励.md)。
- 同一轮候选不能出现相同法术两次；先过滤资格再抽取。有效池少于三个时展示实际数量；全部满级时明确提示跳过，不静默重抽。
- 本轮不增加法术本身的蓝紫金品质。宝物品质与法术等级分开表达。
- 被动精通、护盾恢复同样占槽、属于对应系列，并参与“不同法术种类”的相性统计；宝物不占八个法术槽。

## 3. 房间与奖励节奏

### 用户已确认

- “关”是独立战斗房间。每房敌人清空，护盾补满。
- 第一次法术奖励需要通过一个房间，第二次需要两个，第三次需要三个，以后每三个房间一次。
- 首关交付包含连续战斗、局内成长、首领和结算。
- 六十房框架先按本轮确认采用：前期1—15房，第15房首领；中期16—45房，第45房首领；后期46—60房，第60房最终首领。
- 精英房位置已确认：6、12、21、30、39、51、57；商店在9、24、33、42、54房清场后出现，不占战斗房号。
- 酒馆沿用商店节点，每店一次免费生命恢复并提高本局生命上限，宝物用金币购买；具体幅度、商品与价格另定。

### 本稿建议

- 开局三选一独立于清房进度；普通奖励出现在累计清房数1、3、6、9、12……。
- 房间清场时锁定结果、停止战斗、补满基础护盾；奖励如已到达节点则先选择，再开放出口。下一房从满基础护盾开始。
- 60个房号用于战斗房、商店插在战斗房之间不占号的节点安排已确认。精英和首领共用清房计数、额外奖励以宝物为主、不额外增加一轮法术选择，以及最终首领后直接结算，仍为本版细则建议。详细状态见[首关流程与场景](03-首关流程与场景.md)。
- 房间总数、15／45／60首领框架、精英／商店位置与本版怪物设计已确认；奖励分配与战后恢复细节继续讨论。旧九场试验与此前未接受的区域方案不替代这个框架。

## 4. 生命、护盾和属性

### 用户已确认

- 生命承担整局消耗，跨房间保留；护盾承担单个房间压力，每个独立战斗房间清场后补满。
- 首领关卡与商店节点提供部分回血，具体时机和额度待细化。
- 本轮确认每店一次免费小额回血、宝物用金币购买；本版建议第15与45房首领战后提供高于单店的部分回血，具体比例待伤害基线确定，第60房战后直接结算。
- 2026-10-17追加确认：F10改为回复护盾，取消法术生命恢复；本次不取消首领与商店的回血。
- 角色属性包括生命、护盾、攻击力、暴击率、暴击伤害、属性伤害。
- 本轮追加确认酒馆免费回血并加本局生命上限，宝物也包含护盾、攻击力、生命上限成长；酒馆仍是原五个商店补给点，不另加新房。

### 本稿建议

| 属性 | 定义 |
|---|---|
| 生命上限／当前生命 | 生命归零失败；普通房间不自动补生命 |
| 护盾上限／当前护盾 | 先承受可被护盾吸收的伤害，剩余部分扣生命；房间内不自然回满 |
| 攻击力 | 所有攻击法术共用的伤害基础，避免再增加一套同义“魔法攻击力” |
| 暴击率 | 攻击造成暴击的概率；额外火系暴击率只加到火系伤害，最终概率限制在有效范围内 |
| 暴击伤害 | 暴击相对普通命中的倍率；普通攻击及法术伤害共用定义 |
| 属性伤害 | 按火、冰等属性分别保存的伤害增益；此处先设计火，不设第二份火系攻击力 |

- 原拆解案和旧原型的初始属性不自动迁入。新基础值、计算顺序、酒馆与属性宝物候选见[首版数值](05-首版数值与验证.md)，唯一调参源在data/balance_candidates；基础源已被现行路线读取；当前实际值还受route运行源与局外快照影响。
- 酒馆先增加生命上限，再按新上限恢复；增加上限本身不另给一份当前生命。该顺序为本版候选，免费回血与上限成长的方向由用户确认；增长均限本局。
- 护盾回复量只由法术等级及明确强化该效果的宝物决定；不受攻击力、暴击与火系增伤放大。攻击力、暴击和火系增伤均不提高推怪距离。
- F10直接回复基础护盾，最多回到当前护盾上限；不创造额外临时护盾、不提高上限，也不把溢出量转成生命。
- 取消旧治疗方案的单房总额度。本稿回盾提案由独立冷却、自动前摇和护盾上限约束；战斗外不施放。这样以回盾提高单房容错，已损失的生命仍需依靠首领／商店节点恢复。
- 临时护盾来源与基础护盾分开，不能通过过房反复增加护盾上限。死亡、清场和进入下一房时移除临时来源。

## 5. 局外成长

### 用户已确认

- 法术触媒提高局内相关法术的获取概率。
- 魔力宝石提供基础属性，使角色开局能力有差异。
- 保留商店、宝物及首领节点的设计需求；本轮先定火系内容。

### 已同意的首版范围与实施边界

- 触媒影响候选抽取权重，不直接赠送法术、不突破八槽或三级上限；先进行合法候选过滤，再应用权重。用户已同意[局外基线](08-局外成长触媒与宝石.md)，当时明确三种火系流派倾向、一个装备槽、三级权重；2026-10-18已切换为火／冰两触媒，见[历史17](../../历史决策/归档/17-火冰触媒切换.md)。不影响开局基础攻击选择或直接提高宝物品质。
- 宝石只改变选定的基础属性；局外基线用生命／盾／攻击三种，一个装备槽、三级总加成。两种系统共用魔尘解锁与升级，首次各免费选一件；获取、换装、升级、本地档和开局快照已实现，真实收益入口边界见功能模块。
- 酒馆一次免费回血与本局生命上限成长、[金币商店基线](07-金币商店与品质.md)已获用户同意。金币只在本局使用，魔尘只在局外成长使用，互不兑换；新增局外收益不是修改已确认金币来源。

## 6. 施放计数与宝物触发

以下为本稿建议，供[宝物设计](02-火系神器.md)使用。

- 一次主动法术从自然冷却就绪、前摇完成到成功释放，记为一次“自然施放”。多弹、火雨多落点、光束多命中、持续区域多跳均不增加次数。
- 被动精通不施放。召唤行为计一次，精灵后续激光攻击不重复计入玩家施放；护盾恢复实际新增护盾后才算成功施放并开始冷却。满盾时不施放、不计数。
- 序列之书、炎冠圣契、精灵协同和终焰爆炸属于宝物附加效果。附加法术保留当前法术等级及静态属性，但不触发任何事件型宝物、不增加施放计数。
- 附加施放不扣减、不重置原法术冷却；受正常目标、房间边界、召唤上限、区域替换和护盾上限约束。护盾已满时，F10不能进入附加施放候选池。
- 单次事件的附加效果数量必须由有限规则决定；不允许“追加施放又给追加施放计数”的循环。
- 同名宝物本局至多持有一件，不重复叠层。唯一宝物获得后的候选过滤、奖励为空和池耗尽行为与法术奖励分开处理。

## 7. 原目标的制作基线与验证边界

角色基础、十法术三级、怪物属性、酒馆成长与恢复采用用户已同意的[首版数值基线](05-首版数值与验证.md)；[21件宝物](06-神器数值与验证.md)、[金币、商店和品质](07-金币商店与品质.md)、[局外获取／装备／升级](08-局外成长触媒与宝石.md)与[普通房数量及节奏](09-普通房配置与难度节奏.md)也获用户同意。数值同意不等于完整60房实机验收：当前已实现十火、宝物与局外，路线runtime另有压力档位；正式首领、商店／酒馆与地刺仍待做。原目标每房最多两批、全部清完才补盾和结算，批次间不补盾／重置CD；[03的历史地图需求](03-首关流程与场景.md#4-横屏地图需求)继续保存多数战斗房地刺只伤玩家等未来目标，当前无地刺的路线不能据此宣称完整首关难度通过。

## 2. 角色与计算顺序

| 初始属性 | 候选值 | 含义 |
|---|---|---|
| 生命上限／当前生命 | 300／300 | 无宝石、无宝物开局 |
| 护盾上限／当前护盾 | 100／100 | 每房清场补满，房内无自然恢复 |
| 攻击力 | 100 | 所有伤害法术的共同基数 |
| 暴击率 | 5% | 本表伤害未预先乘暴击期望 |
| 暴击伤害 | 150% | 暴击造成普通伤害的此倍率 |
| 火属性伤害加成 | 0% | 精通与相性同组相加 |
| 移动速度 | 5米／秒 | 移动不中断、不减慢自动吟唱 |
| 受击保护 | 0.6秒 | 实际受击后统一保护，护盾吸收也触发；没有闪避按键 |

伤害＝攻击力×（1＋法阵攻击增益）×伤害系数×（1＋基础火伤＋精通＋相性）×暴击倍率。每个有效伤害包各自判定暴击，最后四舍五入取整一次；先扣盾，溢出再扣生命。首版敌人无护甲、火抗或火免；持续火伤也可暴击，仍不触发只允许直接伤害的宝物事件。

至少3种火系：火伤＋15%、所有主动法术CD减少10%。例如一级焰弹配一级精通与三火相性，非暴击伤害＝100×（1＋15%＋15%）＝130。

施放间隔＝成功释放后CD×（1－冷却缩减）＋自动前摇。缩CD不缩前摇、精灵射击间隔或宝物触发间隔；最终缩减上限50%，CD至少0.2秒，暴击率上限80%。回盾不受攻击、火伤或暴击增幅。

## 7. 调整依据、未达目标与验收边界

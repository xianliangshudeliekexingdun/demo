## 2. 三项蓝色补强与金色定位

B03保留首落固定锁定位置，并让原有首落伤害＋50%；不是追踪目标，也不增加第七／第九次落火。B04仅延长精灵时长收益很小，因为基础存续与冷却都为12秒，所以增加常规激光伤害10%。B07在初始5%暴击率下仅加暴伤不明显，补中心主爆伤害15%，再加50个百分点中心暴伤。

G01增加15%火伤加成并保留70%弱余响，帮助它与紫色序列之书区分；火伤与精通／三火同组相加。例如三级精通35%＋三火15%＋炎冠15%＝65%，伤害火伤因子1.65，不是三个百分比相乘。G02为独立250%攻击力协同激光；G03为400%攻击力终焰。所有调整仅作用宝物，基础法术与敌人未调。

## 3. 结算与组合边界

- 蓝色的范围、暴击、激光伤害、固定首落、推浪移速与回盾改造，作用于对应自然／附加法术。B05和B09属于法术附带状态，不另外生成伤害或施法计数。
- 序列每3次自然施放追加1次当前等级法术；被动不算，精灵射击不算。排除满盾回盾、满员召唤及无合法近敌的灼浪；无候选就跳过本次，不存次数。附加法术不等前摇、不修改本体CD、不再触发事件型宝物。
- 炎冠只计玩家主动伤害法术，排除精通、召唤与回盾。余响伤害70%，持续／范围／控制保留；法阵余响仍替换原阵，不能叠攻击增益。
- 刻印只由自然直接火伤暴击触发：焰弹、火雨落击、爆弹、玩家光束、灼浪可触发；火雨地表、旋涡、法阵、精灵射击及宝物附加结果不触发。同次自然施放最多1片；重叠对同敌取最高有效伤害，0.5秒内不重复跳。
- 共鸣需同时处于至少两种不同法术区域：火雨、旋涡、法阵；同法术两片不够，刻印与终焰不算新法术种类。20%为敌方额外火伤承受因子，和玩家火伤组分别计算；离开立即取消。
- 协同激光只在精灵存在、目标合法且共享2秒间隔结束时触发；一只或两只精灵都只追加一次，不重置常规射击。继承精灵等级的贯穿资格（三级才贯穿）与射程；伤害使用独立系数，不吃B04仅限常规激光的10%，也不吃B08玩家光束宽度。
- 终焰只认自然区域正常到期，每次施放1次；火雨需三级留地。提前替换法阵、碰撞／清场提前移除与宝物附加区域都不触发。序列、炎冠可能提前替换法阵，减少终焰次数；源泉加速后也可能出现这种取舍。
- 回风25%减速与灼浪三级30%减速取较高者；减速只影响追击／换位，不改变已锁定冲锋或弹速。鼓风15%移速刷新2秒，最高仍15%，不按人数或追加次数叠百分比。
- 每房清场清空序列／炎冠计数与源泉计时；奖励、酒馆、暂停、结算不推进。源泉首轮在进入战斗8秒后，不减自身或其他宝物CD、不减前摇与精灵射击间隔。

## 4. 通用宝物与酒馆

三件无元素／持有法术条件，均限本局、各一件。生命琥珀增加上限本身不补当前生命；未来酒馆20%与首领25%按新上限计算。早拿生命80时，后续每店理论最多多恢复16、每个首领节点最多多恢复20，均受缺血封顶；五店后无其他生命加成的上限为480。

护壁晶核增加盾上限，后续每房按新上限125补满；暖焰护持单次回复量不随盾上限变大。增幅棱晶让攻击100→115，也放大刻印、协同激光、终焰，仍不放大回盾。

酒馆按原流程首次进入先结算免费成长／回血，再购买；当店买到生命宝物不重结算已完成的免费补给。拿宝物占该次奖励或购买机会，不在原9个宝物箱外再赠送。

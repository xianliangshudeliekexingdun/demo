## 1 玩法目标与数值口径

火系提供三条可交叉的构筑方向：连续直射与暴击、铺火覆盖与区域重叠、燃烧传播与引爆复燃。玩家仍通过移动、站位和选卡控制战斗，所有施法、引爆和传播自动完成。

| 设计目标 | 本稿采用的办法 | 需要后续试玩验证什么 |
|---|---|---|
| 三种起手均能独立战斗 | 焰弹稳定、火雨覆盖、光束穿线；不要求先取得其他法术 | 相同前期敌群下的命中可靠性、清敌与受压情况 |
| 三级有可感知变化 | 多段、覆盖、停留、离阵保留、余震、减速、缩短回盾周期或扩大传播 | 玩家能否解释本次升级改变了什么 |
| 燃烧有用但不靠无限叠层 | 单份共享燃烧，刷新不增加同时伤害率；传播扩大覆盖 | 多法术命中同一敌人不重复计算，疏散敌群仍值得传播 |
| 爆弹无前置也能用 | 保留高额主爆；有燃烧时额外兑现未来跳伤 | 未取得燃烧搭配时不成为无效卡；成型时有爆发提升 |
| 宝物推动打法 | 专属蓝强化单术，紫／金改变覆盖或循环 | 不要求所有通关都取得某一件，不设总输出硬上限 |

### 共用计算单位

- 伤害系数均为攻击力百分比；100%表示攻击100时的100点基础伤害。每表的三级是**该等级完整值，不逐级相加**。
- 本页直伤表不含暴击、被动、共鸣、法阵、通用增伤、易伤与职业宝物。燃烧和引爆另列，不能又加进每一跳区域伤害。
- 吟唱与CD分开。自然施法成功释放后开始CD，理论连续周期为 `吟唱 + max(0.2秒，基础CD×(1－有效CDR))`；CDR最高60%，不压缩吟唱，各槽并行。
- 冷却就绪但没有合法目标／F10不缺盾时等待；条件重新满足后仍要完整吟唱，不能因等待或P05减剩余CD跳过吟唱。完成时再查资格，失败不当作一次成功释放。
- 实际等待目标、飞行、落点延迟、移出区域与固定步取整会改变实际结果。P05减少剩余CD属于动态事件，不能当成再加一项面板CDR。
- 八槽三级保留；F02被动占一槽。持有三种不同正式火法术，建议保留火伤＋15%及本系CDR＋10个百分点；与通用CDR同桶，最高仍60%。法术升级不重复计种类。

### 作用范围与取值

F02、三火共鸣、G01等“火系”资格明确指本稿火法术及相应燃烧、引爆和火职业宝物派生，不靠旧全局字段影响已迁灵契的F04。学派迁移、伤害标签与表现需在实施时一起更新；火焰外观不自动取得火职业加成。

F06暂保留原20%临时攻击增益，明确允许支持其他学派，是可选择的跨系辅助；同一法阵不重复叠加，自身区域持续伤害排除自身增益。原直伤／区域对法阵增益的释放快照继续按既有机制说明，P02／G03保留现行不携带该释放攻击快照的行为，不在本轮顺带批准全局属性取值重做。**新燃烧和引爆使用结算当下的攻击、通用增伤、火伤与目标火易伤**；当下站阵增益也生效，不保存首次点火的高攻击快照。

普通直伤与原系数型职业宝物伤害沿用暴击资格。新燃烧、引爆不能暴击；F02三级加的是火系暴击伤害倍率，不是暴击率。GT01的固定附伤仍不重新吃攻击、火伤或暴击。

## 2 燃烧 传播与引爆

### 燃烧：每个敌人一份

| 参数 | 推荐值 |
|---|---|
| 同时份数 | 每敌最多1份火系共享燃烧，多个来源不叠层 |
| 基础时长 | 4秒 |
| 跳伤 | 每0.5秒造成25%当前有效攻击力的基础火伤，共8个计划跳时点 |
| 首跳 | 点燃后0.5秒，不在点燃瞬间额外跳一次 |
| 重复点燃 | 到期时间刷新至本次之后4秒，保留下一跳时刻，不立即补跳 |
| 暴击 | 不可暴击 |
| 状态归因 | 共享燃烧，不把全部后续收益强归给最早那次火弹 |
| P06长燃余烬 | 时长改6秒，最多12个未来跳时点；每跳仍25%，不提高持续伤害率 |

攻击100且无其他增益时，一份完整基础燃烧为200伤害，稳定维持时为50伤害／秒；P06完整一份为300，但维持中的伤害率仍为50／秒。重复点燃主要延长覆盖，并不使七个火法术一起命中时变成七份燃烧。

同一时刻，先结算原本到点的燃烧跳，再处理命中／引爆，最后清理到期状态。恰好第4秒的末跳可正常结算，之后没有可被引爆的旧余量。刷新不得重新启动0.5秒计时而把持续点火的敌人永远推迟到不跳伤。

### 哪些分量点燃

| 法术／来源 | 点燃资格 |
|---|---|
| F01焰弹术 | 主弹与三级次弹的实际伤害命中；每个敌人仍只有共享燃烧 |
| F03流火之雨 | 落火命中；三级留地只造成区域伤害，不反复点燃 |
| F05焰流旋涡 | 同次施法对每个敌人的首次有效区域命中点燃一次，后续跳不刷新 |
| F06炽焰法阵 | 同次施法对每个敌人的首次有效区域命中点燃一次，后续跳不刷新 |
| F08贯焰光束 | 主光束点燃；三级后续脉冲只补直伤 |
| F09灼浪冲击 | 直接波命中点燃 |
| F11引燃之印 | 主目标点燃，并按本术规则传播 |
| F07熔核爆弹 | 主爆与余震均不自行点燃；主爆可引爆旧燃烧 |
| P02／G03伤害 | 不点燃；G04的明确复燃另按其条目处理 |

自然与追加施法都保留白名单中的法术机制。追加倍率只缩放其直接／区域伤害，点燃是施加共享状态，不另外保存一份0.7倍燃烧；所有来源共同受单份燃烧与同一跳频限制。追加F07只可消耗当时仍存在的燃烧，不能复制已经被前一次主爆消费的余量。

### 传播：一次施法 一轮扩散

传播由F11负责。有效主击命中后，在其命中位置进行一轮扩散；主目标仍存活才给它点燃，若本次主击或GT01击杀它，邻敌扩散仍可按命中位置正常发生，避免攻击越高反而失去传播。本次命中前已死亡的目标不构成有效主击。选取范围内尚未燃烧的其他存活敌人，按距起点由近到远、同距按稳定ID决定；检查起点到目标之间无遮挡。

传播**复制完整的新燃烧时长，不移走主目标燃烧**；已有燃烧的邻近敌人不占传播名额，也不额外刷新。新点燃目标不在本次再次传播；不因之后燃烧跳伤、死亡或引爆继续传染。没有合法邻敌时仍有主目标伤害与燃烧，不生成额外爆炸。

### 引爆：兑现未结算的计划跳伤

F07主爆先造成直接伤害并完成现行首次命中／GT01等处理，目标仍存活时才消费该目标**主击前已经存在的燃烧**。若主伤或GT01已击杀，不向尸体引爆、不安排复燃；爆炸中的其他存活目标独立判断。

`引爆基础量 = 未来尚未结算的燃烧跳数N × 每跳系数25% × 当前有效攻击 × 本级引爆倍率`

再让适用的通用增伤、火伤和火易伤各结算一次，不暴击，不再把“已算完的伤害”重新乘攻击。N按未来计划跳时点计数，不用剩余秒数简单向下取整：例如点燃0.2秒后，到第4秒仍有8跳，而不是7跳。基础N最多8，持有P06最多12。

引爆倍率为1／1.25／1.5；消费后旧燃烧清除。满余量、攻击100且无其他增益时，对应200／250／300点引爆伤害；有P06为300／375／450。它发生在每个实际被主爆击中的燃烧目标身上，**不让每个目标再产生一个能伤及邻敌的重叠爆炸圈**。

三级余震不再次引爆。消费未来伤害换来提前兑现与倍率收益，因此燃烧引爆不应把“已经跳过的伤害”也算一遍。G04在成功消费后延迟复燃，是专门的构筑例外。

N为0时不产生引爆、不消费空状态，也不安排G04复燃。

## 3 十法术三级完整方案

### F01 焰弹术

**职责：稳定直射、连续点燃。起手之一。** 自动向最近可直射敌人发射火弹，命中造成小范围爆炸；撞实体障碍不隔墙炸伤敌人。

| 等级 | 完整效果 |
|---|---|
| 1级 | 主弹100%，爆炸半径0.8米；命中后点燃 |
| 2级 | 主弹135%，爆炸半径1米；其余同1级 |
| 3级 | 主弹135%＋次弹75%，两者爆炸半径1米；次弹在释放后0.18秒重新寻找最近可直射敌人 |

吟唱0.15秒，CD1.2秒，射程8米。裸理论周期1.35秒；60%CDR时0.63秒。保留现有按目标距离确定发射速度的飞行方式，不改成即时命中或无限追踪。主、次弹可命中不同目标，各自正常造成伤害和点燃，但同敌燃烧仍不叠层。

升级感受：二级单发更可靠，三级多一发补刀／换目标。对应蓝宝物B01扩大爆炸覆盖；适合暴击直伤，也能给爆弹持续提供燃烧。

### F02 炎法精通

**职责：火系被动。** 占法术槽、计入三火共鸣，不吟唱、不计自然施法。

| 等级 | 完整效果 |
|---|---|
| 1级 | 火系伤害加成＋15% |
| 2级 | 火系伤害加成＋25% |
| 3级 | 火系伤害加成＋35%，火系可暴击伤害的暴击倍率＋0.25 |

例如基础暴击倍率1.5，在三级时火系合格伤害暴击为1.75倍；不是暴击率增加25个百分点。燃烧／引爆受火伤加成，但不因本术变为可暴击。F10回盾不受益。

同桶相加：三级精通35%＋三火15%＝火伤50%；持G01后合计65%，不是1.35×1.15×1.15。对应B02提高火系暴击率，支持直伤／暴击地火方向。

### F03 流火之雨

**职责：固定落点覆盖、持续火区。起手之一。** 释放时锁定目标位置，在半径2.2米的覆盖区持续落火。

| 等级 | 完整效果 |
|---|---|
| 1级 | 共6落：首落100%，固定覆盖中心；后5落各60%，随机落点；落击点燃 |
| 2级 | 共8落：首落100%固定中心；后7落各60%；其余同1级 |
| 3级 | 同2级；最后一落后留下半径2.2米地火，持续3秒，每0.5秒40%，不另点燃 |

吟唱0.4秒，CD6.5秒，射程8米；首落在释放后0.3秒，后续每0.4秒一落。单落实际命中半径0.85米，随机散布半径1.32米；“覆盖2.2米”不等于每落都命中整片区域。首落固定原中心，不追踪已走开的敌人。

裸理论周期6.9秒；60%CDR时3秒。三级地火首跳等待0.5秒，完整最多6跳。全落及完整地火都打中同敌的直伤上界为400%／520%／760%，不是实际平均单体输出。

相对现行改动是**首落固定且由60%改为100%**，改善即时伤害与起手可靠性。攻击100、首落确实命中、其余落击全空且敌人留场时，首落加完整燃烧的基础量为300；静止180生命目标在第四跳、约开局后2.7秒解决，不能据此承诺追击中必杀。B03再改善第二落可靠性，保留总落数。

### F05 焰流旋涡

**职责：移动火区、沿路线持续灼烧。** 承接焚风旋涡，改显示名以避免与风学派混淆，不增加强聚敌。

| 等级 | 完整效果 |
|---|---|
| 1级 | 半径1.2米，每0.5秒40%，移动4秒；同次施法首次烧到各敌时点燃 |
| 2级 | 半径1.5米，每0.5秒60%，移动4秒 |
| 3级 | 同2级，移动结束后在终点额外停留2秒继续跳伤 |

吟唱0.4秒，CD6秒，射程7米；从玩家位置向释放方向移动，速度1.75米／秒，受实体障碍截停移动。裸理论周期6.4秒；60%CDR时2.8秒。完整理想跳数8／8／12，总系数320%／480%／720%，但固定敌人通常不会全程跟随火区。

同法术重叠对同敌每0.5秒只取一次最高有效系数，不按旋涡数量叠跳。B05的减速帮助敌人多留在路径中，G03可在持续火区形成后爆发。

### F06 炽焰法阵

**职责：阵地输出与可离开的增益窗口。** 在玩家脚下生成唯一固定法阵。其他法术可利用20%临时攻击增益，法阵自身区域伤害排除自身增益。

| 等级 | 完整效果 |
|---|---|
| 1级 | 半径2.2米，持续4秒，每0.5秒40%；玩家在阵内时获得20%临时攻击增益 |
| 2级 | 半径2.8米，持续6秒；伤害和增益同1级 |
| 3级 | 同2级，离阵后增益保留1.5秒 |

吟唱0.3秒，CD8秒，需要8米内有合法敌人；裸周期8.3秒，60%CDR时3.5秒。区域首跳0.5秒，对各敌每次施法首次有效跳点燃一次。完整跳数8／12／12，总直伤系数320%／480%／480%。三级增强安全走位与其他输出，不虚写为法阵本身增伤。

重新施放替换旧阵，不叠多个站阵增益；新阵也可改变安全位置。离阵保留只按真实战斗时间推进，不因读面板、暂停或选卡延长；已释放攻击携带的原有快照不在本轮改制。B06扩大覆盖；高CDR与追加法阵可能提前替换旧阵，G03的2秒触发仍需法阵实际存续。

### F07 熔核爆弹

**职责：强敌主爆与燃烧兑现。** 吟唱开始锁定射程内当前生命最高敌人的位置，投弹后不追踪；需要用引怪与走位维持落点价值。

| 等级 | 完整效果 |
|---|---|
| 1级 | 主爆中心500%、外围250%；中心半径0.9米；引爆倍率1 |
| 2级 | 主爆中心650%、外围325%；中心半径1.2米；引爆倍率1.25 |
| 3级 | 同2级主爆；0.6秒后全爆炸范围余震150%；引爆倍率1.5，余震不引爆 |

## 8 数值核验与审查边界

本稿把值明确到可核算，但不将理论输出当真人体验。当前敌人生命随真实路线压力增长：例如基础教学档M01为180，第45档M01为4860、M02为4320、守门变体为23400；类型档位不等于该类型在指定房一定出生。旧05的9000／36000／52000正式Boss生命不是当前关底，也不拿来证明本稿能在30分钟通关。

## 1. 已确认的方向

- 玩家花费魔尘抽取魔法宝石。
- 绿色有1条普通词条，蓝色2条，紫色3条；金色为3条普通词条加1个特殊效果。
- 装备为1个核心槽位加3个副槽位，只有核心槽激活金色特殊效果。
- 金色特效可以改变燃烧、冻结等机制，形成流派能力。
- 用户随后认可下文八种普通词条与八种金色特效的方向，要求继续讨论具体数值；该认可不扩为数值、全部交互或实施授权。
- 同日用户确认第6节首轮数值“先按这版”，继续讨论魔尘消耗、品质概率和保底；数值转为本版设计基线，仍未授权实施。
- 随后用户选择“特效完全随机，主要靠后续分解改良”，不采用心愿、金色三选一或首金自选特效。随后用户“好，可以，接下来，请你制作我们讨论的”通过第7节并明确授权实装。

第6／7节对应首版固定属性实现，随后用户授权重做，当前按第13节接入。运行源为[data/magic_gems_v1.json](../../../data/magic_gems_v1.json)，各品质均可入四槽，同颗普通属性不重复、跨颗可叠加。MG01—03传承和未用免费权益保留；首版随机金色核心直接换为新版效果，不保留原效果分支。此前“各品质都可入槽、金色放副槽只用普通词条”为实施选型，不额外记为本轮用户逐项确认。

## 2. 当前实现与设计边界

当前代码已接入四品质实例、1核心＋3副槽、三档普通词条、新八核心、魔尘抽取与保底、精粹分解与选定位置改良。60房按已清战斗房真实结算，商店不计、强化精英不冒领未来Boss奖金。MG01—03仅作为旧档传承与保留的首次免费权益，不进随机品质池、不再付费升级或分解改良；触媒保持现价和权重。

普通词条提供各学派共享的基础能力；核心特效改变其中一条机制，法术承担实际攻击与施加状态，局内宝物继续强化法术或机制。不通过核心自动赠送指定法术或保证指定宝物；本轮不改路线奖励池。没有金色时，普通词条仍能形成有效的四槽属性组合。

本轮不重定现有基础规则：暴击率无上限，达到100%必暴、没有默认超暴击；冷却缩减最高60%，不缩短吟唱、召唤物攻击或宝物间隔。玩家防御及移动仍遵守现行规则。新核心如需改变某项规则，必须在自身效果中明确讨论，不能隐含为全局改动。

## 3. 通用普通词条：八种方向已认可

用户认可下列八种方向及第6节首轮幅度，作为本版设计基线。使用固定属性加值，概率词条使用百分点、暴伤使用倍率加值，减少难以比较的条件与新的乘区。

| 词条 | 建议作用 | 适用边界 |
|---|---|---|
| 攻击 | 增加固定攻击力 | 支持按攻击系数计算的伤害，不直接提高固定回血／回盾或二次放大固定蓄能 |
| 生命上限 | 增加固定生命上限 | 提高承伤余量；开局满血，战斗中不能换宝石回血 |
| 护盾上限 | 增加固定护盾上限 | 提高可容纳的护盾，不自动提高每次回盾量 |
| 防御 | 增加固定防御 | 按现行承伤规则同时保护生命与护盾，不另造独立减伤乘区 |
| 暴击率 | 增加暴击率百分点 | 仅支持原本允许暴击的伤害，不使燃烧、引爆或派生碎冰默认暴击 |
| 暴击伤害 | 增加暴击伤害倍率 | 与已有同类倍率加值叠加；暴击资格不变 |
| 冷却缩减 | 增加冷却缩减百分点 | 与局内已有同类项合计，沿用60%上限和最短CD规则 |
| 战斗移速 | 增加战斗移动速度加成 | 沿用战斗移动与既有加成边界，不影响清场后的行走 |

本版按同一颗宝石内不重复相同普通词条、不同宝石之间同类叠加；不强制进攻／防御／功能词条配额。普通词条不绑定火冰学派，保留跨流派换装价值。法术范围、持续时间与回复转化等可能改变机制的内容，先在核心或职业宝物中逐项讨论。

品质首先通过词条数量和金色特殊效果区分。已认可的首轮数值为紫／金同档、绿／蓝较低、固定数值。四槽成型有12条普通词条，强度预算按整套装备评估，不能照搬单槽旧宝石强度。

## 4. 金色流派特效：八种方向已认可

用户认可下列八种机制方向及第6节的首轮数值／数量／间隔，作为本版基线；完整运行交互仍需实施时核对。基于当前火冰内容，不把其余四学派设计当作已实施能力。

| 暂名 | 机制方向 | 鼓励的搭配与取舍 |
|---|---|---|
| 棱镜折射 | 可暴击直伤暴击时，将一部分暴击额外伤害从主目标转移给附近其他敌人；没有合法邻敌时不转移 | 高频直伤、暴击和清群；在有邻敌时用主目标爆发换覆盖，不额外复制同一份伤害 |
| 术式交织 | 不同学派的自然伤害法术交替命中同一目标时积累交织，达到条件触发一次冲击；同系连续命中不推进 | 多学派与释放节奏组合；不消费燃烧或寒霜，区别于热冲击 |
| 血晶屏障 | 将部分生命上限转换为护盾上限；战斗中的数值生命回复改为回复护盾 | 护盾、回复与防御构筑；生命缓冲变薄、战斗回血途径改变。商店和清房治疗按其原类型保留 |
| 暴燃核心 | 将一份燃烧的伤害压缩到更短时间结算，完整一份的伤害预算保持，持续时间与跳伤间隔同步缩短 | 频繁点燃、快速兑现；更快消耗燃烧库存，改变F07引爆的时机价值 |
| 层燃核心 | 同一敌人的重复合格点燃可以增加有限燃烧层数，单层伤害率低于基础燃烧 | 集中点燃与维持叠层；起效更慢，转火时需要重新积累 |
| 霜蚀核心 | 满层寒霜不再产生硬冻结，改为冰裂期间的持续冰伤与减速；仍有合法冰裂窗口供I07消费 | 持续施霜与输出；失去硬控安全，提前碎冰也会提前结束剩余侵蚀 |
| 崩晶核心 | 冻结／冰裂窗口自然到期时自动兑现一次较弱的单体碎冰；已经被I07消费的窗口不再次兑现 | 保留控制到自然结束、持续施霜；I07仍可主动提前兑现其原效果，自动兑现不冒充施放I07 |
| 热冲击核心 | 当玩家法术使目标同时具有燃烧与有效冻结／冰裂窗口时，消耗这两份状态，触发一次范围热冲击 | 火冰混搭与状态消费；放弃剩余燃烧和控制窗口，与F07／I07竞争同一份资源 |

其中暴燃与层燃是两种不同的燃烧运行方式；霜蚀与崩晶分别强调放弃硬控换持续输出、保留控制后自动兑现。是否需要每个核心都附带显式负面，仍是讨论项；一个核心槽本身已经存在机会成本。

## 5. 交互边界与实施核对

- **不复制现有宝物。** 当前F11负责一次传播，G04负责F07引爆后复燃；I07负责主动碎冰，IG02强化该次消费。核心应与其形成交互，不直接复刻为同名效果或让指定宝物成为必需品。
- **资源只消费一次。** 按第6节统一层燃层数、F07全部库存消费与G04从1层复燃；霜蚀／崩晶／热冲击都不能重复消费或结算同一份冰裂窗口。
- **派生有限。** 折射、交织、自动碎冰、热冲击不默认再算自然施法或生成同类连锁。目标死亡、没有邻敌、同刻命中与强敌无硬冻结都应有清楚结果。
- **真实回复。** 血晶屏障只按实际缺盾回复，溢出不储存；回复不能反算为失盾、免伤或复活。与GU14／GT01／GT04的关系需要按现有真实损失、真实回复与间隔分别核对。
- **读懂收益。** 特效必须显示正在改变什么、为何未触发；普通词条与核心特效分开描述，副槽中的特效明确为未激活。

## 6. 首轮数值基线（2026-10-19通过）

**用户已认可本节数值并授权按此版实装。** 对应评审参数为[magic-gems-numeric-proposal-20261019-v1](../../../tools/balance/magic_gems/parameters.json)，由[隔离数值工具](../../../tools/balance/magic_gems/README.md)核对；参数中discussion_only标记保留产生评审快照时的设计阶段，不覆盖本轮认可。调整参数后应重算本节评审快照；实际游戏的唯一运行数值在data；以下独立模型结果属于实装前的评审快照，原生验证另见功能模块。

### 6.1 初步目标与假设

| 项目 | 本轮选型锚点 | 适用情景 |
|---|---|---|
| 四槽普通词条输出 | 起步属性下，归一化直伤优化组合约提高25%—40% | 一级F01的伤害期望／含吟唱的周期，固定命中，不是整局DPS |
| 四槽防御组合 | 满血满盾的开场原始承伤容量约提高35%—60% | 不含回血、回盾、无敌、走位及跨房补盾 |
| 暴燃 | 一份基础燃烧总预算不变，持续维持时跳伤率翻倍 | 需要连续点燃；无连续点燃时主要是提前兑现 |
| 层燃 | 满层燃烧跳伤率约为基础的2—2.6倍 | 单层较弱、转火重叠，完整引爆库存另算 |
| 控制与群体 | 分开记录控制秒数、主目标与邻敌伤害、状态消费 | 不把控制、移速、折射与单体DPS强行等值 |

这些区间只用于第一轮选型，不是总输出上限。已有宝物、学派和核心叠加可产生更大跃升，不自动提高怪物生命抵消成长。第6节数值评审阶段未制定抽取费用或毕业时间；后续抽取及真实路线收入统一见第7节。

### 6.2 普通词条具体值

本版先固定数值，随机词条组合。紫色和金色普通词条同档，金色额外价值来自可激活的核心特效；绿色、蓝色同时承担入门到成型的数值过渡。

| 普通词条 | 绿色单条 | 蓝色单条 | 紫／金单条 | 四颗紫／金都带该条时 |
|---|---|---|---|---|
| 攻击 | ＋2 | ＋3 | ＋4 | ＋16攻击 |
| 生命上限 | ＋10 | ＋15 | ＋20 | ＋80生命 |
| 护盾上限 | ＋4 | ＋6 | ＋8 | ＋32护盾 |
| 防御 | ＋2 | ＋3 | ＋4 | ＋16防御 |
| 暴击率 | ＋1.5个百分点 | ＋2个百分点 | ＋3个百分点 | ＋12个百分点 |
| 暴击伤害倍率 | ＋0.05倍 | ＋0.08倍 | ＋0.12倍 | ＋0.48倍 |
| 冷却缩减 | ＋1个百分点 | ＋1.5个百分点 | ＋2个百分点 | ＋8个百分点 |
| 战斗移速 | ＋1% | ＋1.5% | ＋2% | ＋8% |

暴伤是倍率加值：原1.5倍加一条紫色后为1.62倍，加四条为1.98倍。暴击率属性不封顶，100%后仍只有必暴，没有默认超暴击；冷却缩减与局内同桶合计，不突破60%。防御沿现行综合减伤边界，移速加成也不绕过现有规则。

四颗紫／金各三条的全部合法属性计数共有23,940种；这是同数值档、按属性计数合并后的等价组合，不是抽取概率或宝石实例数。起步属性下的最佳归一化F01直伤收益为32.41%：四条攻击、四条CDR、三条暴击率、一条暴伤。已有火系暴击加成的合成情景最优为41.68%，暴击／CDR饱和时最优会避开已无增益的项。

四颗都为生命／护盾／防御时，300生命／100盾变为380／132，防御16，开场原始承伤容量从400变为593.92（＋48.48%）。不计回复、连续100原始伤害的探针中，从第4击死亡变为第6击死亡；这不能替代实际可承受几次敌人攻击的结论。

### 6.3 核心特效具体值

以下系数以当前攻击为基准，100%＝1倍攻击。派生伤害不暴击、不施加额外燃烧／寒霜、不再生成同类核心连锁。按对应学派和通用增益各结算一次，不把燃烧已算过的最终伤害再乘一轮增益。

| 核心 | 首轮数值与规则 |
|---|---|
| 棱镜折射 | 将一次合格暴击的**额外伤害60%**转移给主目标3米内最近最多2个其他存活、无遮挡敌人，均分；主目标保留基础伤害与剩余40%暴击额外伤害。无邻敌不转移，无总伤害复制或额外触发间隔 |
| 术式交织 | 首次自然直伤命中建立目标的学派记录；此后每次不同学派切换加1点，**3次切换**触发一次**120%攻击**的冲击，半径2.5米、含主目标最多4个目标；全局间隔2秒。记录持续6秒，合格命中刷新；同系连续不加点、不清空。间隔中进度最多保留2点，不补发；每次自然施法对同目标最多计一次，沿触发法术的学派结算 |
| 血晶屏障 | 把已计其他永久修正后的生命上限的**25%**转为其**2倍护盾上限**；战斗中的数值生命回复**100%改为回盾**。不满盾才实际回复，不存溢出；商店／清房的原类型治疗保留。开场原300／100变225生命／250盾 |
| 暴燃核心 | 燃烧持续时间与跳伤间隔均×0.5，基础由**4秒／每0.5秒25%攻击**改为**2秒／每0.25秒25%攻击**；仍8跳。P06下6秒改3秒，仍12跳。刷新保留下跳，不即时补跳；F07只消费实际剩余库存 |
| 层燃核心 | 每敌最多**5层**，每层每**0.5秒造成12%攻击**，共享时长4秒（P06下6秒）。每敌每0.5秒最多增1层，其余合格点燃只刷新时长；下跳不重置。F11对新敌从1层开始；F07一次消费全部层数的剩余库存，G04在无燃烧时从1层复燃，已有燃烧按普通点燃处理 |
| 霜蚀核心 | 保留原三层阈值与2.5秒冰裂窗口，取消硬冻结；窗口每**0.5秒造成40%攻击**冰伤，完整5跳共200%。满层减速普通40%／精英25%／固定强敌15%，与其他减速取最强并遵守上限。I10延窗至3秒时为6跳；I07提前消费会取消余下侵蚀 |
| 崩晶核心 | 每份冻结／冰裂窗口自然到期时，单体自动结算**150%攻击**冰伤。I07先消费则不再触发；不产生I07专属邻敌碎片或自然施法资格，不调用IG02的I07专属增幅。原有硬冻结、免控和I07效果保留 |
| 热冲击核心 | 同一存活目标具有燃烧及有效冻结／冰裂时，可消费两者。主目标系数＝**200%攻击＋剩余燃烧基础系数×当前攻击**；3米内最近最多3邻敌各承受主目标该次计划伤害的50%。全局间隔2秒，间隔内状态正常保留／推进，不延长、不补发，后续合格法术命中再尝试。火／冰学派增伤取较高的一项，不叠乘两系；不视为F07或I07，不触发其专属消费奖励 |

折射先分配计划伤害，再按各目标实际生命扣除；主目标死亡不复制、取消或扩大已经分出的份额。合成探针中100基础伤害、2倍暴击分成主目标140、两邻敌各30，总量仍200；固定优先目标为300生命、两个50生命邻敌的必暴探针，清掉全部目标从4次命中变3次。这只是伤害分配情景，未证明真实AOE或精英优先击杀收益。

### 7.2 品质概率

| 品质 | 常态基础概率 | 含本节保底的长期综合概率 |
|---|---|---|
| 绿色 | 50% | 约47.54% |
| 蓝色 | 30% | 约28.52% |
| 紫色 | 16% | 约17.53% |
| 金色 | 4% | 约6.41% |

基础概率用于未触发保底的普通状态；综合概率是持续抽取、跨多个常规金周期的结果，不是每次固定概率，也不是新人前15抽的比例。软保底提高金色时，非金品质按50∶30∶16的原比例缩减；小保底再把该次非金结果提升为紫色。

金色特效建议八种等权，每种在金色内12.5%，允许重复；自然金、新人保底金和常规保底金使用同一池，不额外偏向未持有或特定学派。常态单抽某个指定特效的概率为4%÷8＝0.5%。普通词条也建议在八种中等权、不放回抽够品质对应数量；金色的三条普通词条与特效独立。

### 7.3 品质保底及重置

1. **小保底：**连续9抽没有紫色或金色，第10抽必为紫色或金色；任意紫／金清空小保底计数。
2. **新人首金：**新宝石抽取体系的首颗金色最多10抽。提前出金即完成这次保障，不在总第10抽再送一颗；之后转入常规规则。首金特效依旧随机，不自选。
3. **常规金保底：**上一颗金色后的第1—20抽金率4%；第21抽起每抽提高8个百分点，即12%／20%／28%／36%／44%／52%／60%／68%／76%，第30抽100%。出现任何金色就清空金计数；紫色不清空金计数。
4. **同抽处理：**先判金；若没有金、但小保底到期，则给紫。两种保障同抽到期只给一颗金，不降级、不额外给第二颗。
5. **持续保存：**单抽／连续十次／离开界面／正常重启共用同一组计数；品质保障不因换核心、重复金特效、是否装备或是否分解而重置。当前购买、宝石、计数与RNG状态同事务保存，失败不消耗魔尘或进度。

该方案首金平均8.38抽、中位10抽、最多10抽；常规金平均15.60抽、中位17抽、90%不超过25抽、最多30抽。软保底概率随进度变化，界面应显示当前金率、距保底剩余抽数，并区分基础与综合概率。

| 30房 | 约第1.69次 | 第2次 |

### 9.2 建议的三档数值与品质职责

所有品质使用相同的I／II／III档池，品质决定普通词条数量，金色另外拥有一个核心特效；不再让品质额外决定单条数值或最高档。每条独立取档位，暂以25%／50%／25%试算，偏向中档。为控制整套最大预算，建议直接把现行绿／蓝／紫金数值转为共有的三档：

| 普通词条 | I档 | II档 | III档 |
|---|---|---|---|
| 攻击 | ＋2 | ＋3 | ＋4 |
| 生命上限 | ＋10 | ＋15 | ＋20 |
| 护盾上限 | ＋4 | ＋6 | ＋8 |
| 防御 | ＋2 | ＋3 | ＋4 |
| 暴击率 | ＋1.5个百分点 | ＋2个百分点 | ＋3个百分点 |
| 暴击伤害倍率 | ＋0.05倍 | ＋0.08倍 | ＋0.12倍 |
| 冷却缩减 | ＋1个百分点 | ＋1.5个百分点 | ＋2个百分点 |
| 战斗移速 | ＋1% | ＋1.5% | ＋2% |

高档绿色可提供有用的单项属性，蓝色能同时凑两项，紫／金靠三项形成组合；金色在核心槽另有流派价值。单个属性是否适用仍取决于构筑，不能按总条数认定所有紫色必定替换绿色。

III档不超过原紫／金上限，因此最终满档预算保持；但自然新紫／金的单条平均值约为原固定值的68.75%—75%，这是把一部分属性强度移到后续改良，不能把原固定紫金的期望直接沿用。已有实例不在讨论阶段改写；后续实施前另定兼容规则，保留传承属性。

### 9.3 建议的普通词条改良规则

1. 玩家每次可选任意一条普通词条，属性种类与I／II／III档同时重随机；其他普通词条、品质和金色特效保持。
2. 继续保证同颗不出现重复普通属性。候选池排除其他保留词条的属性，**保留原选中属性作为候选**，允许同属性升档／降档。绿／蓝／紫金分别有8／7／6种候选属性。
3. 建议普通改良也显示旧结果与新候选，由玩家选择；保留旧结果仍消耗本次材料。当前试算允许完全相同的候选，未追加必变、升档保底、递增费用或指定属性权利。
4. 金色核心单独重洗，仍由玩家决定保留旧核心或采用新核心，普通词条保持。是否排除原核心尚是提案；本轮未确定核心改良概率和价格。
5. 未来实现应在候选产生时一并保存费用与候选，重开看到同一个结果；不能关闭界面退材料或刷新结果。该条是后续实现要求，不表示当前已接入。

示例：紫色有攻击I、生命II、冷却缩减III，选择攻击I后可以洗到攻击III，也可以洗到暴击率II；不会出现第二条生命或冷却缩减。采用新结果只替换所选行，保留旧结果则三行不变。

### 9.4 数学节奏、边界与后续定价

[参数](../../../tools/balance/magic_gems/affix_roll_parameters.json)与[离线工具](../../../tools/balance/magic_gems/affix_roll_model.py)读取当前运行数值作档位锚点，结果见[摘要](../../../build/qa/magic-gem-affix-tiers-20261020/summary.md)与[完整报告](../../../build/qa/magic-gem-affix-tiers-20261020/results.json)。

已固定紫／金另外两条、只追最后一条指定属性III档时，单次概率为1／6×25%＝1／24；平均24次，中位17次，90%在55次内，95%在71次内，无有限次数保证。只追III档而不挑属性为平均4次；这两个目标不能混为同一种改良节奏。自然三条全III为1／64，精确指定三属性且全III为1／3584，均为该品质内部概率；不把它们设为通关门槛。

试算III概率20%／25%／40%时，指定末条III的平均次数为30／24／15，90%分位为68／55／34。暂取25%作讨论锚点；成本应按完整种类加档位空间重算，前期鼓励得到合适的两三项，不要求全III。若后续目标是更快尝试构筑，可提高高档概率或降低改良成本，再核材料预算。

## 10. 局外构筑定位复审（2026-10-20，方向未定）

本节记录当时复审阶段；用户后续选择强金色核心与普通三档属性路线，见第12节，不将本节辅助机制推荐叠加为新增实施范围。

### 10.1 用户提出的问题与证据范围

用户认可上轮普通三档改良规则后，质疑核心特效仅金色出现、能同时生效的构筑能力太少，认为当前更像《黑夜君临》的遗物养成，可能从局外构筑之初就存在定位问题。这是重新审视系统目标，未自动取消此前四槽／抽取／特效规则，也未批准下列改造。

本轮按game-design-review的探索审查，聚焦局外准备中的决策与机制组合；画面、关卡、社交、商业化、完整战斗平衡不在审查范围。当前规则已从magic_gems.gd的sample／totals／core_id及route_gem_combat.gd核对：普通词条均为八种基础数值，四槽求和；只有核心槽的一项金色特效进入战斗。三档与重随机尚未实施。

[《黑夜君临》官方玩法介绍](https://nightreign.eldenring.jp/gameplay.html)说明基础遗物配装可装备三枚、每枚最多三个效果，效果包括通用及角色／技能相关项。这里参考的是多个效果可以共同影响配装的思路，不据此断言其所有效果都改变机制，或评价其完整现行版本深度；不把其他作品的完整系统作为本工程已验证方案。

### 10.2 主要诊断

| 观察 | 对玩家决策的影响推断 | 证据状态与优先级 |
|---|---|---|
| 四槽目前只激活一项主要机制，其余提供属性 | 核心选定后，副槽主要优化收益，缺少继续组合触发、资源转化与兑现方式的空间 | 规则已确认；深度不足是与用户目标对照的主要风险，未有新试玩证明 |
| 机制入口绑定金色及随机特效 | 想试一种打法需要先跨过获取门槛，非金阶段主要积累属性；提高出金速度能改善接触时机，不能替代副槽联动 | 规则已确认；获取速度与构筑深度应分开处理 |
| 三档与改良增加的是词条优化路径 | 能增加养成目标，但单独使用时不会产生新的机制关系；继续细化分解价格会在结构未定时锁定经济 | 已认可规则的作用范围；先重定结构再核价格 |

数值配装也可以有策略价值，例如暴击与暴伤的搭配、血晶对生命与治疗价值的改变；不能据此断言只有机制词条才算构筑。当前问题是：用户期待更强的局外机制组合，而本版系统主要承载属性养成加一个流派入口。

### 10.3 三种可比较方向

| 方向 | 主要变化 | 收益与代价 |
|---|---|---|
| A：局外以属性准备为主，机制变化主要留在局内 | 保留当前宝石定位，将其称为数值养成和一个核心选择 | 规则较清楚、局内成长空间较大；不满足用户希望局外多机制组合的目标 |
| B：保留四槽与单一主核心，普通词条池加入辅助机制（推荐先讨论） | 八种数值词条保留，增加围绕暴击、点燃、寒霜、护盾等类别的触发与收益转化；非金色也可获得，副槽生效 | 扩展副槽用途、沿用数量与三档框架；需重审词条池、叠加、触发资格、抽取和改良成本，不是仅加文案 |
| C：多个槽位同时激活现有核心级效果 | 让多项规则改写同时工作 | 直接增加组合空间；暴燃／层燃及冰裂消费等可能竞争同一规则和库存，需要重新定义兼容；可能过早固定局内构筑 |

B中的金色可继续提供全局规则改写；非金辅助机制提供早期可参与的局外构筑。是否进一步让非金拥有主核心基础版，是另一个获取层面的选择，本轮未确定。推荐先检验多个辅助效果的组合价值，不直接增加槽位或把所有核心同时开启。

辅助词条示意：暴击触发一次受限的生命回复，与血晶的治疗转盾形成关系，再搭配回盾后强化下一次施法的效果；暴击／护盾数值词条因而有明确配装理由。这些仅用于解释组合目标，并非已批准内容、固定系数或已排除与现有宝物重复的最终设计。辅助按机制类别起效，法术仍负责实际施法与状态来源，局内宝物仍强化或补齐机制；不要求指定的一件法术／宝物才能开始玩。

### 10.4 最小验证与决策门槛

先用纸面配装卡比较同一主核心的两组辅助：一组偏持续作战与防护，一组偏爆发与清场；普通三档数值先固定，不靠高档或更多总属性制造差异。请用户分别说明两组会优先选择哪些现有法术／宝物，以及舍弃了什么。

若更换辅助组合能让玩家解释不同的选奖优先级、状态使用或生存取舍，才值得继续展开辅助词条；若理由仍只是统一提高输出或生命，先改效果关系。纸面验证只检验预期与理解，实际触发、可读性、强弱及材料等待仍需后续授权后的小规模原生试玩与数值模型；不在本轮定分解／改良价或重做全部运行系统。

## 11. 多辅助机制与强金色核心的比较（2026-10-20，未选定）

本节记录比较阶段；后续用户选择与新八核心候选统一见第12节。

### 11.1 新提案与决策对象

用户认为上轮辅助机制方案“这样也可以”，又提出另一种：金色特效更独特、足以建立流派，例如开放元素反应，或每秒消耗1点生命、自耗最低停在10%、每缺少1%生命提高1%伤害。用户要求比较选择，未将这些示例、数值或新增辅助词条授权实施。

这两个系统方向分别把组合复杂度放在不同位置。主核心数量少不必然缺少构筑；如果一个核心能改变其余普通属性、法术与宝物的相对价值，也能组织出多条配装路径。第10节“单一机制缺少组合空间”的风险需按核心具体内容复核，不能仅靠效果数量判定。

| 比较项 | 普通池加入多种辅助机制 | 金色承担强主核心，普通池先保留八种数值 |
|---|---|---|
| 决策来源 | 多个触发、转化、兑现效果彼此组合 | 主核心改变资源规则，数值属性及局内奖励围绕它取舍 |
| 非金阶段 | 可先尝试辅助机制组合 | 仍以基础属性养成为主；机制入口的获取问题单独存在 |
| 规则与抽取 | 需要扩词条池，重新核改良空间、叠加与循环 | 沿用四槽及普通三档框架，复杂度集中在核心内容；强核心仍须核互交 |
| 对局内的影响 | 可能提前确定多段触发链 | 可能形成很强的起手倾向；应支持一组法术／宝物类别而非固定全套清单 |
| 最小检验 | 同一核心换辅助组合，局内选奖思路是否改变 | 更换主核心后，普通属性和局内选奖是否共同改变；同一核心是否可有不同配装 |

助手本轮倾向**先验证强金色核心路线**，保留八数值与三档改良规则，按具体玩法差异重审原八核心。此建议不等于取消辅助机制方向；若强核心仍不能带动属性与选奖取舍，再决定补充辅助词条。第10节的推荐是当时比较结论，本节增加新的候选后重新取舍，不把先前建议当作已定实现。

### 11.2 两类强核心可以同池存在

元素反应与耗血增伤属于不同的核心内容，可以并列候选。前者鼓励跨学派、状态施加频率与消费时机；后者改变生命、护盾、防御、治疗与输出的关系。选择系统结构与选择池内核心类型是两层决策。

现有热冲击已提供火冰状态共存后消费的反应雏形。若采用“解锁元素反应”，需明确究竟增加哪些交互、何时触发、消耗还是保留原状态，以及如何避免重复兑现；不能仅以名称声称获得新深度。本机只有火冰已接入，暂不把另外四系设想当作实际反应池。法术继续承担施法与施加状态，原有火冰本身的能力不因未装该核心被撤回。

耗血型核心应与单纯常驻增伤区分：护盾能保命而不提高生命比例，回血提高安全但减少缺血收益，生命上限对固定扣血的启动速度有影响，现有GT02低血宝物因此更有针对性。这些是可解释的构筑关系；若最终所有法术都优先选择该核心，则要复核其通用收益、启动与真实生存成本，不能把高伤害本身当作设计失败。

### 11.3 用户耗血示例的一次性核算

按当前基础300生命／100盾、没有敌伤／回复、自耗仅走战斗时间的假设：`自耗到10%的秒数＝最大生命×0.9÷每秒生命消耗`；`缺血增伤＝1－当前生命／最大生命`。1点／秒需要270秒；四条当前紫档生命后为380生命，需要342秒。这个规则会形成跨房预热；若希望更早进入核心状态，可以另测按最大生命比例消耗。比较用1%／2%上限每秒分别为90／45秒，与生命上限无关，均未被选择为正式数值。

自耗到10%时为＋90%伤害；敌伤若进一步把生命压到10%以下，是否继续增加需要明确，本次按原缺血公式继续增加，不擅自新增90%上限。伤害与现有同桶增伤相加或独立结算尚未确定：已有25%同桶增伤时，再加90%同桶增伤的相对提升为72%；独立乘一次则为90%。不将示例直接接入所有直伤、持续伤害及派生伤害，避免同一伤害多次放大。

风险按生命加护盾评估：基础10%血＋满盾是30＋100＝130承伤量，为原满血满盾400的32.5%；四颗当前生命／护盾／防御三条的成型情景，完整原始承伤容量593.92、低血满盾197.20，剩33.20%。这是静态容量，不含回盾、回血、无敌或走位。实际路线每房补满盾，F10、GU11等也能回盾，须验证这些条件下的持续风险；不能把“10%生命”直接等价于只剩10%总生存能力。

若采用该核心，建议自耗视为生命消耗，绕过护盾与减伤、不触发受击回复／受伤无敌；只在战斗推进，避免在安全的奖励或商店阶段等候压血。10%仅限制自耗，敌伤正常致死。这些是待确认边界；战斗中保留小怪等待仍可能改变启动收益，后续试玩需观察，不能声称只限制战斗即可消除等待行为。与血晶是两个互斥的主核心，不默认同时装备。

本次按game-balance-analysis的提案评价做一次性标准输入校核，未创建临时脚本文件；保留[结果](../../../build/qa/magic-gem-core-direction-20261020/results.json)，含57项／0失败、36组生命上限／扣血方式／连续回复代理情景、两组承伤容量及四种增伤叠加对照，5份被读取源SHA不变。连续回复0／0.5／1点每秒仅作边界代理，不冒充实际宝物触发或自然路线。

### 11.4 选择依据与下一步验证

系统方向暂推荐集中式强核心，用户原1点／秒与1比1缺血增伤只作待修订候选，缺少最终强弱结论。下一步先比较一份火冰反应核心配装与一份耗血核心配装，保持普通词条档位和总数一致，分别说明愿意拿什么、舍弃什么。再为耗血核做一组偏盾／防御、一组偏输出／移速的对照，确认同一核心也有取舍。

最小原生验证需要在另获实施授权后进行：观察早期进入核心状态的时机、是否刻意留怪等候、护盾恢复后是否仍有生命风险、两核心是否造成不同选奖优先级。数值模型只支持启动与容量判断，不构成完整TTK、实际清房速度、核心之间强弱排序或用户体验认可。强核心路线也不自动解决金色入口与随机目标特效的获取等待；抽取／分解改良经济待结构选择后重算。

## 12. 独特流派八核心重设计（2026-10-20讨论稿）

### 12.1 已选择的路线与提案边界

用户明确：“好，就按金色提供独特流派核心、普通词条保留三档属性这个方向，接下来重新设计一下8种金色特效，我们继续讨论。”据此，强金色主核心＋八种普通数值三档为已选路线。本轮先设计玩法与取舍，不扩普通词条池为辅助机制，不增加槽位、不同时开启多核心；四槽及核心槽唯一激活继续作为前提。下列八个名称、规则和交互均为新候选，未获逐项认可或实装授权。

本轮使用game-design-review对比原八核心与新候选，按“是否改变普通属性价值、是否改变法术／宝物选择、能否有不同配装路径、玩家能否理解代价”审查。具体伤害、间隔、转化率、层数、范围、候选数值与经济均后续建模，不以本节描述判断已经平衡。未使用新增系别、手动施法键、闪避或法力作为前提。

### 12.2 八个候选

| 候选名称 | 改写的规则与主要能力 | 属性和局内选择倾向 | 取舍与差异 |
|---|---|---|---|
| 万象熔炉 | 开放该核心专有的额外元素反应。本版先做火冰：同一目标的燃烧与冰裂共存时，消费两份状态，形成强力范围热冲击 | 攻击、CDR；火冰状态来源、施加频率及持续时间；在快速小反应与较大库存爆发间配装 | 需要火冰搭配；反应会竞争F07／I07的状态库存。原有点燃、施霜与普通法术能力保持，不以核心解锁它们 |
| 血祭契约 | 战斗中持续消耗生命，自耗在低血停止；当前缺血比例转为显著增伤，生命成为进攻资源 | 护盾、防御、移速与输出属性；低血宝物、回盾与躲避压力的选择 | 回血改善安全却减少增伤，护盾能缓冲风险；固定扣血还是比例扣血、增伤乘区及自耗线均待定，不直接通过上轮示例数字 |
| 血晶屏障 | 将部分生命上限转为更大的护盾池，战斗中的数值生命回复改为回盾，使生命上限与治疗成为扩盾／续盾资源 | 生命、护盾、防御；治疗、回盾、实际回盾触发的宝物；偏大盾容量或偏频繁恢复 | 本体生命缓冲变薄；满盾时治疗不储存，也不以溢出治疗制造实际回盾收益；清房／商店仍按其原恢复类型处理 |
| 灾厄火种 | 点燃从刷新单份燃烧改为连续叠加火势，共享持续时间；高火势产生强持续伤害，停止维持后逐步衰减 | 攻击、CDR与持续作战能力；高频点燃、持续火区、延长燃烧 | 转火需要重新叠层；F07可消费所有真实库存，但会失去当前积累，形成持续维持与提前引爆的取舍；不依赖必须拥有F07 |
| 永霜冰棺 | 冰裂窗口中，将目标受到的一部分法术直伤延后储存在冰棺；窗口结束、目标死亡或合法碎冰消费时，释放一次范围冰爆 | 攻击、CDR；稳定施霜、延长窗口与窗口中的高直伤；自然结束或用I07提前兑现 | 一部分即时伤害被推迟；燃烧等持续伤害不入库存。冰爆兑现已有库存并获得核心自身强化，不能先扣同份伤害再完整兑现一遍 |
| 星裂棱镜 | 法术直伤暴击的额外伤害不在原命中立即结算，转成追踪碎晶，按核心规则在敌人间连锁；无邻敌时回到原目标 | 暴击率、暴伤、攻击；高频直伤产晶或重击高暴伤；单体追击与群体覆盖 | 输出更依赖暴击，兑现有延迟；原命中保留非暴击基础部分，碎晶承接额外部分并有核心强化。派生碎晶不再次暴击或产晶 |
| 双生回响 | 全局CDR不再缩短法术冷却，改为提高回响强度；自然伤害施法会留下延迟影击，再兑现一次该法术的本体伤害形态 | 攻击、暴伤与被转化的CDR；高本体系数或多段区域伤害；防护需兼顾恢复来源 | 失去原CDR带来的施法／控制／防护频率。影击不再施加状态、重复状态消费、回复、赠送宝物触发或制造回响 |
| 行者蓄势 | 有效移动期间暂缓伤害法术自动吟唱，以实际位移积蓄有限能量；停步恢复原施法序列，下一次自然伤害施法消耗蓄势，获得大幅威力与范围强化 | 移速、攻击、暴伤；近身范围爆发或远距离重击；防御帮助停步兑现 | 移动期间失去伤害施法输出；防护术与被动保持常规。玩家通过走停控制节奏，不新增施法按钮，不直接指定或免费重复某个法术 |

这八种分别围绕跨学派状态、低血风险、生命与治疗转盾、点燃积累、冻结蓄伤、暴击形态、冷却价值、移动与施法节奏建立不同取舍。不存在每个核心都必须额外附一条惩罚的要求；条件、状态消费、延迟、机会成本也可以承担代价。是否足以支撑实际流派，仍需用户审查和后续试玩。

### 12.3 本版优先核对的边界

- **万象熔炉：**只把火冰作为当前可制作反应；雷／风／岩／灵契尚未实现，不预支多系反应数量。消费同一份燃烧／冰裂只一次，反应不再次点燃或施霜；不保证奖励池发指定法术，需检验自然奖励下的启动。
- **血祭契约：**自耗只走战斗时间，绕过盾／减伤、不发受击奖励或受伤无敌；低血停止线只限制自耗，敌伤仍能致死。需检验留怪等候、每房满盾与回盾法术是否使代价过低；不将缺血90%参考当输出上限。
- **血晶屏障：**沿用原实际恢复与溢出不储存边界，生命平加和永久修正只转换一次；不与血祭作为两个核心同时装备。恢复转盾须保留GU14／GT04／GT01等真实资格，未来新数值另算。
- **灾厄火种：**有有限层数与增层频率；F07消费真实库存，G04重燃按新的点燃规则起步，不恢复已消耗层数。衰减方式待讨论，不擅自沿用原layers参数为新方案数值。
- **永霜冰棺：**不增加额外硬控或无限延窗，保持原冰裂／免控规则；无法硬冻结但仍有合法冰裂窗口的敌人也有库存。I07保留本身消费效果，核心只释放一份库存，不额外模拟第二次I07。目标早死也结算一次，之后窗口事件不能再兑现。
- **星裂棱镜：**仅原本允许暴击的法术直伤产晶；采用原始一次暴击判定与最终计划量，防止原目标和碎晶重复拿完整暴击额外伤害。超100%暴击率仍遵守既有必暴规则，不自动获得超暴击；多段／多目标产晶量与连锁上限后续核算。
- **双生回响：**转化现有CDR同桶并保留60%上限，不把“堆到上限后无效”变成无限收益；吟唱时长不因此缩短。基础冷却改写、P04附加施法与各种原术多段须另核资格；影击仅记录本体伤害，不复制F07燃烧库存、I07碎冰库存或治疗，防止重复放大。
- **行者蓄势：**只按战斗实际位移蓄势，顶墙／清场行走／商店／暂停无积累；有储量上限，清房清掉蓄势。原冷却照常推进，不能储存数次免费施法；移动再次发生时，尚未完成的伤害吟唱如何暂缓与保留蓄势，须在采用此方向后明确。它直接改变操作节奏，是本轮优先讨论的候选。

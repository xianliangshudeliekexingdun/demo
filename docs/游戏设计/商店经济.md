# 商店经济

现行主题说明，核对日期：2026-10-20。本文归并局内金币、商店、品质抽样与结算规则；运行参数以所列data及core为准，不在文档另存默认值。旧经济模型、数值选择和条件模拟完整保留于[编号设计07](历史方案/07-金币商店与品质.md)，其中原21件、旧首领奖和末房无奖励只代表当时基线。

## 局内资源与购买意图

金币服务本局的宝物选择：前期及时补强，中期比较当下收益与存钱，后期补构筑缺口。金币不带出本局，不兑换魔尘或宝石精粹。击杀数量、召援次数、战斗耗时与受伤情况不影响一房应得收入；避免高输出刷召唤物赚取额外金币，也让承伤压力和购买力能分别调节。

实际清场时，core先把房号加入唯一已清账本，再发对应阶段清房收入；精英、精英护卫和Boss使用同阶段精英加奖。四Boss沿用其原节点收入，不叠编号07保留的额外首领奖或战后回血。清房仍补满护盾，Boss书箱属于独立构筑奖励。结算分别显示取得、消费与剩余，末店以后取得的金币也进入收支记录，但无法再转化为购买力。

经济阶段沿用运行源的前期／中期／后期三档，不能把敌方难度的四阶段直接当作四套价格或收入。普通清房收入、精英加奖、品质权重、统一价格及首店保证归[run_economy_v1.json](../../data/balance_candidates/run_economy_v1.json)。文件名与`status`保留早期候选标记；当前运行已读取其相应字段，不表示整份旧设计或Boss奖金字段都已启用。

## 五间独立商店

第9／24／33／42／54战斗房走门后进入商店，不占战斗房号、不发清房魔尘或追加法术奖励。玩家可绕过柜台直接离开；靠近柜台才领取本店一次免费生命成长与回血，并查看商品。先增加生命上限，再按新上限恢复；上限增加本身不另补当前生命。生命契约与血晶屏障仍走原有上限池换算，商店恢复保持生命恢复类型。

补给和库存由第一次真实柜台接触一起提交。商品根据此刻实际构筑生成并固定，同店最多购买一件；关闭、重开都不刷新库存、不补货、不重复补给或恢复购买额度。购买生命上限宝物不追补已经结算的免费恢复。没有刷新、回售、付费治疗、法术或局外宝石商品。

现行普通池为24件通用宝物。商店先过滤已持有与不满足实际机制条件的条目，再按品质规则生成至多三个不同商品；没有通用／职业陈列配额。32件旧火冰职业已退场，四个Boss庭印仅供对应Boss空金池兜底，不进入商店。具体资格归[宝物](宝物.md)，不得用编号07原21件或后续历史56件的统计替代现池。

## 品质、资格与交易边界

普通箱与商店使用经济源的阶段基础品质权重。一个候选位的品质权重不等于整屏出金概率，也不等于最终持有比例。先检查合法池、持有和零权重品质，再处理节点保证、缺品质重分配与同屏不放回；不足三件按实际数量展示，普通合法池耗尽不靠重复宝物凑数。首店保留蓝色候选保证，具体取值与缺池退路读取同源配置。

15／30／45／60的Boss金箱另走纯金候选：先完成法术书，再按更新后的构筑生成金池；没有合法金色时给本关专用庭印。它不使用旧15房紫色保证，也不把金色加入前期普通箱／商店的零权重池。双奖励与庭印细则见[关卡与敌人](关卡与敌人.md)和[宝物](宝物.md)。

购买请求只带商品ID和当前房间revision，价格由core固定库存决定。只有在有效购物阶段、未暂停且存活、余额足够、商品仍合法且额度未用时才提交；余额不足、过期跨房、伪造价格或重复请求都不扣款、不改持有或RNG。商店行走和购物计入路线总时间，暂停不计，战斗时间不因购物增加。

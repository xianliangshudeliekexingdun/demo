# 宝物

整理核对：2026-10-21。本文归并局内宝物的现行范围、获取和触发规则；不复制整套数值表。实际实现以data和core为准，完整效果保留原设计与历史。局外触媒、魔法宝石属于独立装备系统，不占本局宝物池。

## 定位与范围

法术决定主要玩法，宝物补属性、强化共同机制或成为强力构筑的关键。宝物为局内被动，同ID每局最多一件，不占八个法术槽；当前没有同名叠层、宝物升级、主动使用键、回售或跨局持有。

| 范围 | 当前状态 |
|---|---|
| 普通通用宝物 | 24件，进入合资格普通箱／商店池；含沿用三件、P04／P05迁类及19件新增 |
| Boss专用庭印 | 4件，只在对应Boss金箱无合资格普通金色候选时兜底，不进普通池／商店 |
| 原火／冰职业宝物 | 32件已退场，机制归入火冰三级，残留持有也不再生效 |
| 旧灵契兼容宝物 | B04／P01／G02共3件继续归档，不因保留定义进入路线池 |
| 完整定义 | 63件＝28件可获得＋35件归档；28件不代表每局必定拿齐 |

P04序列之书、P05魔力源泉已属于通用，不能按旧火系文件位置删去。面向玩家统一称“宝物”；旧文件名“神器”、英文artifact API、ID与存档键保留兼容，不批量改写历史。

原32件职业退出箱、店、持有展示和现行图鉴，旧ID与原图片保留来源追溯。迁入等级后的机制不再叠加原道具来源，且部分跨术条件已收拢到明确法术，不能把旧全职业装备表当作现行强度承诺。**没有独立法术专属升级系统**；未来完成法术后统一制作更专精、能强力改变特定法术的专属道具，原每系16件配额停止。

2026-10-21的[雷系成长](雷系法术成长.md#4-旧16项效果的归属)已将原16项来源中的10项适配为本术二／三级机制，6项留作未来专属道具设计来源；后者不代表确定制作6件。不向现行宝物池或图鉴新增雷系职业ID；L09实际回盾可满足GT01能力资格，雷直伤与派生各守事件身份。

风、岩、灵契的旧来源已在[风](风系法术成长.md)／[岩](岩系法术成长.md)／[灵契](灵契法术成长.md)中逐项标明等级承接或未来保留，不新增职业ID。R05、S09是真实回盾；风幕、岩阵、法阵和号令不冒充回盾。契灵普攻／号令派生不触发GT01玩家本体首击或宝石本体链。

## 通用宝物的价值

蓝色提供明确属性、续航或简单条件，紫色连接循环与行为，金色提供有边界的资源转换或明显取舍。“通用”允许护盾恢复、暴击、主动法术等共同机制资格，不要求绑定某一火／冰法术ID；不规定分类配额或某件必出，也不要求通关依赖指定件。

现行24件覆盖生命／盾上限、攻击、防御、CDR、暴击、移动、清房补给、战斗恢复、破盾、实际击杀、站定、无伤、回盾蓄能及血盾取舍。具体条目与当轮取值见[设计10](<../../../demo 精简/20261026-项目精简/docs/游戏设计/历史方案/10-通用道具设计.md>)，运行值由源表读取；该稿旧40件总量、9箱和未制作房间描述属于原实施阶段。

## 获取与Boss必金

普通箱与商店共用实际持有／能力资格过滤，并按阶段品质处理。候选同屏不重复、同ID不能重复获得，库存缓存后不会因离开界面重抽。属性类资格考虑上限后的实际收益；不是仅凭存在于完整定义就能出现。当前路线的12箱、五店和法术书节点归路线data，不恢复旧固定九件库存或额外奖励配额。

15／30／45／60房Boss清场同时出现书与锁定金箱，先完成法术奖励，再生成金箱候选；取消法术替换保留原权益，不能先取箱绕过新法术资格。金箱独立只抽合资格、未持有的金色，少于三件时不填充其他品质；空金池只给本关庭印，不降紫、不跳箱，两份权益完成才开门，第60房相同。

四庭印分别对应四个Boss，使用独立ID、品质为金，各提供常规伤害和生命上限增益；取得不补当前生命／护盾。它们是空金池的确定兜底，不是普通金色候选不足三件时的补位，也不会在后关补发前关庭印。详细奖励时序和设计基线见[设计22](<../../../demo 精简/20261026-项目精简/docs/游戏设计/历史方案/22-四个Boss与必金双奖励方案.md>)。

## 统一事件边界

通用增伤同桶相加；暴击率无属性上限，100%起必暴且无超暴击。常规CDR合计最高60%，不压缩吟唱或道具共享间隔；P05减少剩余CD是动态事件，不另算面板CDR。防御先计算实际承伤，再扣盾与生命，综合减伤上限沿用战斗源。

实际恢复按真正补入值、实际损失按减伤后损失计算，溢出不计。领取、提高上限及清房补盾不当作战斗恢复；无敌／零损失不当作受伤，致死先判死亡，受伤回复不能复活。充能、站定、无伤、周期回复及共享门只走战斗时间，选卡／暂停不推进，本房结束清理临时层数。

P04只累计合资格成功自然释放，追加不再递归累计或生成事件链；派生伤害守原身份与触发权限。GT01获取资格检查可造成伤害及F10、升级I08等真实回盾能力；当前缺盾不是抽取条件，充能只计合格战斗中实际补入的护盾。GU07读取F02的新火系暴击能力，不再依赖退场B02／IG03持有键。燃烧／引爆、碎冰／邻片及宝石核心仍各有伤害与事件边界，不因“常规伤害增益”就变成新的自然命中。

现行公式与固定附伤范围见[战斗与成长](战斗与成长.md)；未来统一命中取值／敌方防御提案保留在[编号设计11](<../../../demo 精简/20261026-项目精简/docs/游戏设计/未来方案/11-战斗系统设计.md>)。本页不扩大已有事件权限或自动批准新承伤规则。

# 局外养成

现行主题，核对日期：2026-10-22。触媒／宝石默认值由data加载；本页说明规则与入口。用户已批准[十核心方案](未来方案/25-新版魔法宝石十核心与养成提案.md)并要求全部制作，授权沿革与旧资产细化见[历史30](../历史决策/归档/30-新版宝石整体规划与十核心提案.md)。旧[设计20](历史方案/20-魔法宝石词条与核心流派.md#gem-keystones-workshop-implementation)只保留八随机核心阶段基线，不覆盖现行十核。

## 资源与出发快照

魔尘用于触媒、核心定向解锁及属性宝石抽取；宝石精粹用于制作／升品／提档／副类型调整；金币只用于本局商店，三者不兑换。出发时固定触媒、一个核心和三枚属性宝石快照，局内不能换装或培养；局外可免费换装，也可不装备。

60房路线按真实run_id与core已清战斗房，在通关、死亡或主动结束时结算。0／15／30／45／60清房分别0／15／45／75／105魔尘；商店、未清房、预览与重复结算无额外收益，Boss不加旧模型未来奖金。强退不续关或补未结算收益。收入源为[magic_gems_v1.json](../../data/magic_gems_v1.json)的route_income，route45存档标识继续兼容。

## 六系触媒

MC04／MC05保留火／冰，新增MC06雷、MC07风、MC08岩、MC09灵契，各关联本系全部正式十术。首次免费仍为账号一次，自动装备；其余20魔尘解锁，一级升二级20、二级升三级40，最高三级。六系起手始终可独立选择，不受购买／装备触媒限制。

正式法术书采用[六系法术抽取](六系法术抽取.md)：先过滤资格，同屏不放回；已持有可升级术基础权重×2，触媒再用28%／40%／52%的优先强度提高本系概率，逐张移除后重算。强度不是固定单卡概率，没有固定新学／升级卡位、必出本系或指定法术保底。高等级更集中本系，均衡混学可卸下；不改变法术强度、宝物品质、宝石抽样或奖励次数。

抽取参数唯一归[route_spell_sampling.json](../../data/route_spell_sampling.json)，费用／关联ID归[meta_growth_v1.json](../../data/balance_candidates/meta_growth_v1.json)，不采用其旧收入／宝石槽位字段覆盖当前系统。旧逐ID权重仅保留独立首房兼容。60房完整105魔尘预算可支付首免触媒升满60，或另五系一级解锁100；据此本轮维持20／20／40而未加价，不承诺真人获得速度。

## 四槽与金色宝石

四个宝石槽不限制品质，可混搭、可留空；同一实例不能重复占槽，出发时锁定。金色宝石＝一个特殊效果＋三条属性，三条属性不分主副、全部按Ⅰ／Ⅱ／Ⅲ档位随机；绿／蓝／紫只有属性、没有效果。同名效果可以同时装备多枚，但只有槽位序号最靠前的一枚生效，其余仍提供属性并在界面上红色提示。

## 属性与抽取

绿为一主、蓝为一主一副、紫为一主两副、金为三条不分主副。主行取主属性档位，副行与金色各行取副属性档位；同颗属性类型不重复，跨颗相加。

| 属性 | 主Ⅰ／Ⅱ／Ⅲ | 副Ⅰ／Ⅱ／Ⅲ（金色各行） |
|---|---|---|
| 攻击 | 4／6／8 | 2／3／4 |
| 生命 | 20／30／40 | 10／15／20 |
| 护盾 | 8／12／16 | 4／6／8 |
| 防御 | 4／6／8 | 2／3／4 |
| 暴击率 | 3／4／6个百分点 | 1.5／2／3个百分点 |
| 暴伤倍率 | 0.10／0.16／0.24 | 0.05／0.08／0.12 |
| 冷却缩减 | 2／3／4个百分点 | 1／1.5／2个百分点 |
| 移速 | 2%／3%／4% | 1%／1.5%／2% |

总CDR60%、战斗移速加成35%与综合减伤45%边界沿用当前战斗规则；不缩短吟唱、宠物普攻或核心内部间隔。三主六副按12份旧词条预算设计，不是每种旧新组合等强证明。

每抽5魔尘，十连50，无额外赠抽；基础绿／蓝／紫／金50%／33%／15%／2%。连续9抽无紫，第10抽必紫；连续49抽无金，第50抽必金；提前出紫或金各自重置对应计数。主行八类等权，其余行不放回；每行档位Ⅰ／Ⅱ／Ⅲ独立60%／30%／10%。RNG与保底跨重启保存。

| 精粹操作 | 成本与保护 |
|---|---|
| 全洗 | 20，效果与三条属性全部重掷 |
| 每锁定一项 | +15，锁定项保持原值 |
| 最多锁定 | 3项；锁满全部内容时不可提交 |
| 分解 | 绿／蓝／紫／金得1／3／10／10 |

锁定项可以是特殊效果或任意一条属性；非金色宝石没有效果可锁。重洗先同事务保存费用／RNG／唯一候选，再显示旧新比较；跨页面与重启保持，不重抽或重扣。已装备或锁定的宝石不能分解。

账号累计真实结算清房15／30各赠12精粹，总24一次性；多次短局可累计，未结算／预览／重复结算不计。补给与清房收益同事务保存，失败不推进累计或领取标记。

# 局外养成

现行主题，核对日期：2026-10-22。触媒／宝石默认值由data加载；本页说明规则与入口。用户已批准[十核心方案](未来方案/25-新版魔法宝石十核心与养成提案.md)并要求全部制作，授权沿革与旧资产细化见[历史30](../历史决策/归档/30-新版宝石整体规划与十核心提案.md)。旧[设计20](历史方案/20-魔法宝石词条与核心流派.md#gem-keystones-workshop-implementation)只保留八随机核心阶段基线，不覆盖现行十核。

## 资源与出发快照

魔尘用于触媒、核心定向解锁及属性宝石抽取；宝石精粹用于制作／升品／提档／副类型调整；金币只用于本局商店，三者不兑换。出发时固定触媒、一个核心和三枚属性宝石快照，局内不能换装或培养；局外可免费换装，也可不装备。

60房路线按真实run_id与core已清战斗房，在通关、死亡或主动结束时结算。0／15／30／45／60清房分别0／15／45／75／105魔尘；商店、未清房、预览与重复结算无额外收益，Boss不加旧模型未来奖金。强退不续关或补未结算收益。收入源为[magic_gems_v1.json](../../data/magic_gems_v1.json)的route_income，route45存档标识继续兼容。

## 六系触媒

MC04／MC05保留火／冰，新增MC06雷、MC07风、MC08岩、MC09灵契，各关联本系全部正式十术。首次免费仍为账号一次，自动装备；其余20魔尘解锁，一级升二级20、二级升三级40，最高三级。六系起手始终可独立选择，不受购买／装备触媒限制。

正式法术书采用[六系法术抽取](六系法术抽取.md)：先过滤资格，同屏不放回；已持有可升级术基础权重×2，触媒再用28%／40%／52%的优先强度提高本系概率，逐张移除后重算。强度不是固定单卡概率，没有固定新学／升级卡位、必出本系或指定法术保底。高等级更集中本系，均衡混学可卸下；不改变法术强度、宝物品质、宝石抽样或奖励次数。

抽取参数唯一归[route_spell_sampling.json](../../data/route_spell_sampling.json)，费用／关联ID归[meta_growth_v1.json](../../data/balance_candidates/meta_growth_v1.json)，不采用其旧收入／宝石槽位字段覆盖当前系统。旧逐ID权重仅保留独立首房兼容。60房完整105魔尘预算可支付首免触媒升满60，或另五系一级解锁100；据此本轮维持20／20／40而未加价，不承诺真人获得速度。

## 十核心与三枚属性宝石

装备分为一个固定核心槽与三个属性槽。核心无等级、无普通词条、无随机品质倍率，金色只标识核心类别；属性宝石最高紫色。同一属性实例不能重复占槽，核心不能塞属性槽，属性石不能放核心槽。首次免费自选任意核心；其余各30魔尘定向永久解锁，核心不进随机池，也没有重复品、核心重洗或升星。

## 属性石与培养

首次自选三枚绿Ⅰ属性石，允许同主类型。绿为一主、蓝为一主一副、紫为一主两副；品质决定行数，每行Ⅰ／Ⅱ／Ⅲ决定数值。主类型固定，想换主方向可制作新石；同颗副类型排除主及另一副，跨颗相加。

| 属性 | 主Ⅰ／Ⅱ／Ⅲ | 副Ⅰ／Ⅱ／Ⅲ |
|---|---|---|
| 攻击 | 4／6／8 | 2／3／4 |
| 生命 | 20／30／40 | 10／15／20 |
| 护盾 | 8／12／16 | 4／6／8 |
| 防御 | 4／6／8 | 2／3／4 |
| 暴击率 | 3／4／6个百分点 | 1.5／2／3个百分点 |
| 暴伤倍率 | 0.10／0.16／0.24 | 0.05／0.08／0.12 |
| 冷却缩减 | 2／3／4个百分点 | 1／1.5／2个百分点 |
| 移速 | 2%／3%／4% | 1%／1.5%／2% |

总CDR60%、战斗移速加成35%与综合减伤45%边界沿用当前战斗规则；不缩短吟唱、宠物普攻或核心内部间隔。三主六副按12份旧词条预算设计，不是每种旧新组合等强证明。

属性石每抽5魔尘，十连50，无额外赠抽；基础绿／蓝／紫60%／30%／10%，连续9抽无紫，第10抽必紫，提前出紫重置。主类型八类等权，副类型不放回；每行档位Ⅰ／Ⅱ／Ⅲ独立60%／30%／10%。RNG与保底跨重启保存，制作／培养不推进保底。

| 精粹操作 | 成本与保护 |
|---|---|
| 制作绿／蓝／紫 | 3／10／30，自选主类型，全部行初始Ⅰ档，副类型随机 |
| 绿升蓝／蓝升紫 | 8／20，100%成功，保留原类型及档位，新增随机副类型Ⅰ档 |

| 定向副类型重塑 | 25，保档，选择合法类型，确认前可预览结果 |
| 分解绿／蓝／紫 | 得1／3／10，只按品质，不额外返还培养投入 |

账号累计真实结算清房15／30各赠12精粹，总24一次性；多次短局可累计，未结算／预览／重复结算不计。补给与清房收益同事务保存，失败不推进累计或领取标记。起始24材料足够三赠绿升蓝，玩家可自由使用，不强制代花。

已装、锁定或传承石不能分解；锁定也阻止培养／转换。分解必须预览确认，批量仅闲置未锁绿蓝。随机重铸先同事务保存费用／RNG／唯一候选，再显示旧新比较；跨页面与重启保持，不重抽或重扣。现代待选可携原装备出发，局内不能采用候选；其他宝石操作先处理待选。核心解锁不参与分解或随机培养。

## 旧资产、迁移与保存

存档v6／宝石schema3严格兼容合法v1—v5，旧触媒／MG01—03的既有合并退款与传承规则保留；旧文件读取不自动写回，下一成功事务才保存，损坏档报错并保原字节。原MG传承不进新池，不付费升级／分解／改良，未领旧免费权益继续兼容。

旧金拆出核心永久解锁，原普通属性／档位／ID／锁保持为过渡石；六方向映射新核，reactor／stride每种首件给1次自选权益，不抵扣新核心首免。重复同旧方向返20精粹，原属性石不删除。原核心槽属性若三槽已满仍留背包，迁移凭证保存原四槽关系。过渡石可继续装备，也可在培养页预览后自愿免费选原有一行作主属性，该行翻倍，其余行／档保留，不强制删行或换类型。

旧金保底按30×未出次数／原保障长度向下取整折魔尘一次，原保障长度为首金10或常规30；旧紫计数保留到新十抽计数。迁移凭证记录原计数和补偿，重启不重复。已付费旧核心／词条候选原样保留，先选定再幂等继承，不能带未迁移旧核心出发。现代新候选按前述原装备快照规则处理。

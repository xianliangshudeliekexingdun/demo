现行主题说明，核对日期：2026-10-20。本文归并触媒、宝石、材料与存档边界；数值与采样以data为准。[编号设计08](历史方案/08-局外成长触媒与宝石.md)保留原三触媒／单槽固定宝石及未来收入模型；[编号设计20第13节](历史方案/20-魔法宝石词条与核心流派.md#gem-keystones-workshop-implementation)保留新版八核心、三档词条与工坊实施基线，其前文讨论不会覆盖后续授权。

## 资源与开局快照

魔尘用于触媒解锁／升级与随机宝石抽取，宝石精粹用于分解后的改良闭环；金币只在局内商店使用，三者没有兑换。局外换装免费，可不装备；开始本局时固定触媒、普通属性及唯一核心快照，战斗内不能抽取、换装或采用改良候选。

60房路线按真实run_id和core已清战斗房账本，在通关、死亡或主动结束时结算魔尘；未清房、商店与界面预览不发收益，Boss不叠历史模型中的未来奖金。强退不续关、不补未结算收益；独立首房保留其真实清房结算。重复打开结算不会再次入账。路线收入唯一归[magic_gems_v1.json](../../data/magic_gems_v1.json)的`route_income`；存档内`route45`标识保留兼容，实际范围读取该源，不代表仍限45房。

## 火冰两触媒

MC04火法术触媒与MC05冰法术触媒各关联本系正式十术。新档首个触媒免费自选并自动装备，其余魔尘解锁，最高三级；触媒只提高后续奖励中关联法术的权重，包含已有术升级，不改变起手三选、法术强度、宝物品质或奖励次数。合法法术先过滤，再同屏不放回抽样；满槽替换仍按[法术体系](法术体系.md)处理。

当前仍使用每张关联法术的旧等级乘数，不等于本系必出或获得概率直接翻倍。[正式体系总纲12](未来方案/12-正式触媒与法术体系.md)的多系概率公式、价格重算与其余四系触媒尚未切换。等级、关联ID、费用与权重唯一归[meta_growth_v1.json](../../data/balance_candidates/meta_growth_v1.json)，不复制其旧宝石槽位或旧收入字段为当前规则。

## 四槽宝石与唯一核心

装备为一个核心槽加三个副槽；所有随机品质均可入任一槽，同一实例不能占两槽。绿／蓝／紫／金分别有1／2／3／3条普通词条，金色另有一种核心特效，只有放核心槽才激活；副槽金色只贡献普通属性。

普通属性共有攻击、生命、护盾、防御、暴击率、暴伤、冷却缩减、战斗移速八类。所有随机品质共享三个数值档位，品质决定条数；同颗类型不重复，跨颗同类相加。暴击资格、减伤与移速边界沿用战斗规则，冷却缩减仍有全局上限，不缩短吟唱或宝物共享间隔。

| 唯一核心 | 职责与必须保留的边界 |
|---|---|
| 万象熔炉 | 消费同一目标一份真实燃烧与合法冰裂窗口，形成火冰范围反应；所有目标共用玩家反应间隔，不重演F07／I07消费奖励 |
| 血祭契约 | 战斗中消耗生命并按实际缺血独立增伤；自耗绕过盾和减伤，不触发受击事件，自耗停止线不保护敌伤致死 |
| 血晶屏障 | 生命上限转盾，战斗数值治疗改为真实回盾；永久上限修正只转换一次、满盾不储存溢出，清房／商店恢复仍保留原类型 |
| 灾厄火种 | 重复点燃累积有限火势并随停止维持衰减；F07消费实际未来库存，重燃从初层开始，不凭空恢复旧层数 |
| 永霜冰棺 | 合法冰裂窗口暂存部分法术本体计划伤害；上限外立即结算，到期／死亡／合法消费按窗口token只兑现一次，派生伤害不入库 |
| 星裂棱镜 | 原直伤只留非暴击基础段，暴击额外段延迟化为有限连锁碎晶；孤立目标仍可承接首枚，同链不重访，不重复暴击或触发状态／宝物命中 |
| 双生回响 | CDR改为有限回响供能，失去缩短冷却的用途；延迟按本体基础几何重放，可打空，不复制状态、治疗、库存消费、条件追加或施法／命中回调 |
| 行者蓄势 | 战斗实际位移蓄势，移动暂缓并保留伤害吟唱，冷却继续；停步后下一次完成的自然伤害施法消耗一次，防护／被动照常，顶墙不充能、清房清空 |

单核心结构使八种改写互斥，不能把血祭与血晶或回响与行者同时叠加。核心时钟、延迟队列与状态窗口跟随战斗／暂停，不靠界面计时；共享门和一次兑现不能因多段、多目标或派生回调重复触发。完整系数、F07／I07本体与条件追加限制见设计20第13节；普通法术与通用宝物自身的共享门继续有效。

## 抽取、分解与改良

单抽与十次使用同一采样器，十次不附带另一次优惠抽样。首金保障、紫或金保障、常规金色软／硬保底和RNG一起持久化，跨离开／重启续计；金色核心等权随机，无心愿、首金自选、重复保护或指定核心硬保底。费用、概率与保障值归宝石源的`draw_cost`、`base_weights`、`pity`，不以第6节旧固定属性替代当前三档。

分解先预览再提交，只产生精粹，不返魔尘或推进抽取保底。已装、锁定或传承宝石不可分解；批量只列闲置未锁绿蓝，紫金逐枚预览。锁定也阻止改良；已装但未锁的随机宝石可改良并保留槽位。

普通改良选择一行，类型与档位一起重抽，保留其他行和核心；排除与保留行重复的类型及完整相同结果。核心改良只从其余七种等权抽取。旧新可选，保留旧结果也照扣费用，不支持合成升品或指定兑换。费用、RNG及唯一候选标识在展示前同事务保存，选择时不再收费或采样。待选候选跨页面／重启保留，先处理后才允许其他宝石操作；可带原装备开局，战斗中不能选结果。

# 法术体系

整理核对：2026-10-20。本文合并现行法术职责、成长和选奖规则；具体运行数值读data，编号设计保留完整方案与形成过程。实现及验证范围见[功能模块](../功能模块.md)，结算公式与事件通则见[战斗与成长](战斗与成长.md)。

## 玩法与成长

玩家以移动、站位和选卡影响自动施法；没有手动攻击、手动碎冰、冲刺或法力条。法术决定主要玩法，宝物强化机制或构成强力组合的关键。连续路线当前开放十火、十冰，最多八槽，每术三级；被动也占一槽，同一法术升级不增加学派种类。

三级属于同一套重复选卡成长：一级保留独立战斗职责，二级强化伤害、覆盖或循环，三级带来更强机制。原火冰32件职业宝物的效果已按职责并入等级，承载范围有明确收拢，不承诺逐项复制旧全装备组合。允许成型构筑明显跃升，不以自动提高敌人生命抵消升级。**没有独立的“法术专属升级”系统**；未来通过专属道具给特定法术强大效果，原每系16件职业配额已取消。

三种不同火术触发火系共鸣，三种不同冰术触发冰系共鸣；两者按各自学派生效，可以同时成立。升级不重复计数，替换后按实际持有重算，被动计种类。伤害与冷却加成读对应data；同桶相加，通用CDR与本系CDR合计最高60%，不缩吟唱或独立触发间隔。

## 两系职责

| 学派 | 法术与职责 | 升级强化方向 |
|---|---|---|
| 火系直击 | F01焰弹、F03火雨、F08光束 | 爆破／固定落点／穿线，分别加入自然暴击留火、落火覆盖、本术自然释放回响 |
| 火系区域 | F05旋涡、F06法阵 | 沿路灼烧与阵地经营；减速、自然区域重叠和法阵成熟爆发支持真实走位 |
| 火系燃烧 | F07爆弹、F11引燃之印 | 主爆兑现已有燃烧，传播扩大覆盖；高等级强化引爆／有限复燃与全局燃烧保存 |
| 火系辅助 | F02精通、F09灼浪、F10护持 | 火系属性、近身解围与回盾；精通仅火系，护持不回复生命 |
| 冰系起手 | I01霜弹、I02穿刺、I03寒星 | 连续施霜／穿线／落点控制，高等级补霜各有主段与次数边界 |
| 冰系覆盖 | I04霜环、I05领域、I06风暴 | 近域解围、追击路线与固定条带，多段不绕过共享施霜门 |
| 冰系兑现 | I07碎冰、I08冰棺 | 自动消费旧窗口换输出，或建立新窗口；升级提供有限邻片施霜、留霜与真实回盾 |
| 冰系辅助 | I09护体、I10研习 | 短时防御／受伤反霜与冰系增伤／普通寒霜保存，不把控制延长变成永久硬冻 |

火系围绕直击、铺火与燃烧兑现交叉构筑；F06阵内攻击增益可以支持跨系，其区域与成熟爆发不递归继承自身增益。冰系在保留安全窗口和较早碎冰输出间取舍；I07提前结束剩余冻结，不能同时免费保留全部控制与兑现收益。

## 选奖与替换

准备页选择火／冰起手学派，入局从对应三个独立起手中选一；后续清房书开放火冰混搭，按实际触媒权重抽取。满级术排除，同屏不放回；未持有术不因八槽满而被排除。

| 选择情况 | 当前处理 |
|---|---|
| 未满槽选新术 | 学习一级 |
| 选已持有且未满级术 | 原槽升级 |
| 满槽选新术 | 先指定旧槽再确认，新术一级，不继承旧等级／冷却 |
| 取消替换或按Esc | 返回原三卡，不重抽、不消费奖励或改变库存 |
| 满槽且本次三卡全新 | 可放弃该书，保留构筑 |
| 八术全部三级 | 仍提供未持有术；仅实际合法池为空才防御性处理空书 |

确认替换才原子消费本次奖励，其他七槽保留；暂停、旧请求、跨房或重复提交不能二次领取。选卡／替换只走路线计时，人物、敌人和冷却冻结。完整权益及请求边界见[历史16](../历史决策/归档/16-满槽替换与持续法术奖励.md)。

## 状态与触发边界

自然释放各自完整吟唱、成功释放后开始本术CD，各槽并行；无合法目标或不满足回盾条件时等待。自然、追加与派生身份保持区别，追加不反向累计自然释放或递归产生事件链。

每敌只保存一份燃烧；刷新不叠独立伤害、不重置下跳，短刷新不截断已有长燃烧。F11只传播一轮；F07消费实际剩余燃烧一次，只有符合条件的自然主爆可安排有限延迟复燃。燃烧、引爆不暴击，留火、成熟爆发与回响各守自己的释放／逐敌次数。

每敌只保存一份寒霜；满层进入冻结／冰裂，窗口不续层、不续窗。碎冰消费命中前唯一旧token；主冰裂与邻片不暴击、不递归，邻片施霜不回填主目标。冻结暂停本体行为与接触，已离体攻击继续；Boss硬冻系数为0，仍可形成冰裂窗口。I08仅自然新窗口按实际缺盾回盾，I09反霜仅在护体内实际受伤且存活后触发。

等级、几何、段数及本术触发参数随释放快照，替换不改写已释放对象；持有被动按当前法术重算。火系既有部分快照与冰系命中取属性边界继续保留，不以未来五系共通稿自动统一。暂停冻结战斗时钟，清场／死亡／重开清理相应临时对象与计数。

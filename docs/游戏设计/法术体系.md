# 法术体系

整理核对：2026-10-27。本文合并现行法术职责、成长和选奖规则；具体运行数值读data，编号设计保留完整方案与形成过程。实现及验证范围见[功能模块](../功能模块.md)，结算公式与事件通则见[战斗与成长](战斗与成长.md)。

## 玩法与成长

玩家以移动、站位和选卡影响自动施法；没有手动攻击、手动碎冰、冲刺或法力条。法术决定主要玩法，宝物强化机制或构成强力组合的关键。连续路线当前开放火、冰、雷、风、岩、灵契各十术，共60术，最多八槽，每术三级；被动也占一槽，同一法术升级不增加学派种类。

三级属于同一套重复选卡成长：一级保留独立战斗职责，二级强化伤害、覆盖或循环，三级带来更强机制。原火冰32件职业宝物的效果已按职责并入等级，承载范围有明确收拢，不承诺逐项复制旧全装备组合。允许成型构筑明显跃升，不以自动提高敌人生命抵消升级。**没有独立的“法术专属升级”系统**；未来通过专属道具给特定法术强大效果，原每系16件职业配额已取消。

三种不同本系法术触发对应六系共鸣；各自按本系生效，可以同时成立。升级不重复计数，替换后按实际持有重算，被动计种类。伤害与冷却加成读对应data；同桶相加，通用CDR与本系CDR合计最高60%，不缩吟唱或独立触发间隔。

## 状态与触发边界

自然释放各自完整吟唱、成功释放后开始本术CD，各槽并行；无合法目标或不满足回盾条件时等待。自然、追加与派生身份保持区别，追加不反向累计自然释放或递归产生事件链。

每敌只保存一份燃烧；刷新不叠独立伤害、不重置下跳，短刷新不截断已有长燃烧。F11只传播一轮；F07消费实际剩余燃烧一次，只有符合条件的自然主爆可安排有限延迟复燃。燃烧、引爆不暴击，留火、成熟爆发与回响各守自己的释放／逐敌次数。

每敌只保存一份寒霜；满层进入冻结／冰裂，窗口不续层、不续窗。碎冰消费命中前唯一旧token；主冰裂与邻片不暴击、不递归，邻片施霜不回填主目标。冻结暂停本体行为与接触，已离体攻击继续；Boss硬冻系数为0，仍可形成冰裂窗口。I08仅自然新窗口按实际缺盾回盾，I09反霜仅在护体内实际受伤且存活后触发。

等级、几何、段数及本术触发参数随释放快照，替换不改写已释放对象；持有被动按当前法术重算。火系既有部分快照与新五系命中取属性边界继续保留，不以未来五系共通稿自动统一。暂停冻结战斗时钟，清场／死亡／重开清理相应临时对象与计数。

**等级与层级。** 一级是一次干净重爆，二级按实际中心／外围几何强化分区，三级按原等级增加余震与符合资格时的复燃链路。火核随等级适度饱满，强化不扩大原判定。中心瞬间最亮，外围火浪迅速回落，余震更克制，附着最弱；多弹交叠时仅限制装饰亮度，保留实际身份／位置／阶段。友方效果始终低于敌方预警与飞弹。F01、F03、F08及魔法飞弹已认可资源保持原字节，尾迹复用原焰弹Shader；不新增图片、字体、模型或全局Glow。

**只读事实与验证。** fire_bomb_facts在原释放／结算／事件之后记录实际飞行、主爆与余震；fire_bomb_status_facts在原燃烧兑现／成功复燃之后记录目标局部事实，两者有界、有限保留并深拷贝。原pending、伤害context、玩法事件／event_seq和RNG保持。旧入口仅在新模块可用且两日志能力齐备时让出F07及其来源状态；无spell_id的旧兑现事件按真实cast_id与actor_id精确交接，其他兑现保留原绘制。暂停冻结，减少动态保留真实曲线／阶段，回退时钟、清场／换房清理。

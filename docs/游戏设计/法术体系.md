# 法术体系

整理核对：2026-10-26。本文合并现行法术职责、成长和选奖规则；具体运行数值读data，编号设计保留完整方案与形成过程。实现及验证范围见[功能模块](../功能模块.md)，结算公式与事件通则见[战斗与成长](战斗与成长.md)。

## 玩法与成长

玩家以移动、站位和选卡影响自动施法；没有手动攻击、手动碎冰、冲刺或法力条。法术决定主要玩法，宝物强化机制或构成强力组合的关键。连续路线当前开放火、冰、雷、风、岩、灵契各十术，共60术，最多八槽，每术三级；被动也占一槽，同一法术升级不增加学派种类。

三级属于同一套重复选卡成长：一级保留独立战斗职责，二级强化伤害、覆盖或循环，三级带来更强机制。原火冰32件职业宝物的效果已按职责并入等级，承载范围有明确收拢，不承诺逐项复制旧全装备组合。允许成型构筑明显跃升，不以自动提高敌人生命抵消升级。**没有独立的“法术专属升级”系统**；未来通过专属道具给特定法术强大效果，原每系16件职业配额已取消。

三种不同本系法术触发对应六系共鸣；各自按本系生效，可以同时成立。升级不重复计数，替换后按实际持有重算，被动计种类。伤害与冷却加成读对应data；同桶相加，通用CDR与本系CDR合计最高60%，不缩吟唱或独立触发间隔。

## 风、岩、灵契三级成长

2026-10-21用户授权继续逐系制作，风→岩→灵契均已接入十术三级及独立起手，当前规则分别见[风系法术成长](风系法术成长.md)、[岩系法术成长](岩系法术成长.md)、[灵契法术成长](灵契法术成长.md)。正式运行源分别为[wind](../../data/wind_spells_v1.json)、[earth](../../data/earth_spells_v1.json)、[spirit](../../data/spirit_spells_v1.json)，图鉴同源读取。

- 风系以有限贯穿、推拉、实际走位风径和静态风幕改变空间；敌弹减速只影响飞行位移，不能延后预警、吟唱或伤害时钟。风径不累计顶墙输入或传送。
- 岩系以非阻挡构装、有限脉冲／共振、一次消费和岩甲经营阵地。构装不占敌人名额、没有生命，不承受敌伤；终止按消费／替换／到期唯一处理。防御与冰系、通用共用综合减伤上限。
- 灵契以S02远程、S03近战、S04灵鹰建立总量最多4只的契灵，号令不重置普攻，归灵只消费一次，法阵每只契灵的延寿有限。F04仍为旧兼容定义，S02承接新正式远程召唤；召唤普攻与玩家本体事件分开。

旧职业表仅作为等级机制及未来专属道具来源，具体归属见各成长主题；没有新增职业宝物或独立升级系统。六系制作完成不等于最终平衡或实机验收，抽取已按[统一方案](六系法术抽取.md)完成首版，体验仍待统一实机。

## 选奖与替换

准备页确认本局学派：已装备触媒时锁定该系，入局从该系三个独立起手中选一；未装备触媒时从六系18张基础术随机三张。后续清房书开放六系混搭，先过滤满级／前置，合法已持有升级ID基础权重×2，六触媒再按本系优先分量抽取，移除后重算；三张不重复。未持有术不因八槽满而被排除；无触媒也保留升级权重×2。具体概率与费用看[六系抽取](六系法术抽取.md)。

| 选择情况 | 当前处理 |
|---|---|
| 未满槽选新术 | 学习一级 |
| 选已持有且未满级术 | 原槽升级 |
| 满槽选新术 | 先指定旧槽再确认，新术一级，不继承旧等级／冷却 |
| 取消替换或按Esc | 返回原三卡，不重抽、不消费奖励或改变库存 |
| 满槽且本次三卡全新 | 可放弃该书，保留构筑 |
| 八术全部三级 | 仍提供未持有术；仅实际合法池为空才防御性处理空书 |

R06须持有R03／R04／R09中的任一构装来源，S05／S07须持有S02／S03／S04中的任一召唤来源，未满足时不抽到新术；已学会但后来替掉来源时保留法术，释放按场上实际对象等待。初始无来源时合法池57术，60是正式活跃定义总数。

确认替换才原子消费本次奖励，其他七槽保留；暂停、旧请求、跨房或重复提交不能二次领取。选卡／替换只走路线计时，人物、敌人和冷却冻结。完整权益及请求边界见[历史16](../历史决策/归档/16-满槽替换与持续法术奖励.md)。

## 状态与触发边界

自然释放各自完整吟唱、成功释放后开始本术CD，各槽并行；无合法目标或不满足回盾条件时等待。自然、追加与派生身份保持区别，追加不反向累计自然释放或递归产生事件链。

每敌只保存一份燃烧；刷新不叠独立伤害、不重置下跳，短刷新不截断已有长燃烧。F11只传播一轮；F07消费实际剩余燃烧一次，只有符合条件的自然主爆可安排有限延迟复燃。燃烧、引爆不暴击，留火、成熟爆发与回响各守自己的释放／逐敌次数。

每敌只保存一份寒霜；满层进入冻结／冰裂，窗口不续层、不续窗。碎冰消费命中前唯一旧token；主冰裂与邻片不暴击、不递归，邻片施霜不回填主目标。冻结暂停本体行为与接触，已离体攻击继续；Boss硬冻系数为0，仍可形成冰裂窗口。I08仅自然新窗口按实际缺盾回盾，I09反霜仅在护体内实际受伤且存活后触发。

等级、几何、段数及本术触发参数随释放快照，替换不改写已释放对象；持有被动按当前法术重算。火系既有部分快照与新五系命中取属性边界继续保留，不以未来五系共通稿自动统一。暂停冻结战斗时钟，清场／死亡／重开清理相应临时对象与计数。

2026-10-22这一轮完善只改表现，不调整法术数值、等级机制或抽取。原引擎解析／只读快照检查和真实像素、遮挡可读性、体验验收分别记录；本轮画面仍待用户后续统一实机，见[历史29](../历史决策/归档/29-新四系图标与特效完善.md)。

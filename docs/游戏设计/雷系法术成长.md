## 2. 学派与共通规则

### 核心体验

雷系围绕敌人之间的连接关系：雷矢快速换目标，雷枪和裁决处理强敌，连锁利用邻接，导电让连接更可靠。敌人分散、障碍断边或只剩一敌时，群体收益会下降。导电不造成持续伤害，不叠电荷、不附送麻痹／眩晕，也不自动与火冰产生元素反应。

L01／L02／L03是三个起手；L10是唯一被动且占一个槽。所有主动法术都有独立可用的基础部分，不要求先持有L04；L08没有旧网络时仍能施放主击。持有三种不同雷术触发雷系共鸣，沿用原稿雷伤＋10%、雷系主动冷却缩减＋10个百分点；升级不重复计种类，L10计种类，替换后按实际持有重算。

### 时钟、伤害与事件

- 表内伤害百分比是攻击力系数，表内冷却为基础CD；吟唱另计。`有效CD=max(0.2秒，基础CD×[1−min(总冷却缩减，60%)])`，成功释放后开始计CD；各槽并行，移动不打断吟唱。失去合法目标重新等待完整吟唱，不空记自然释放。
- 雷伤、L10与雷共鸣在同一个雷伤桶内相加；L05雷易伤在目标雷易伤桶内相加。直接伤害及自然云团落雷可暴击，暴击率达到100%后必暴，无超暴击层数。L07条件附伤／邻弧、L08电网边不暴击。
- 自然、追加与派生身份分开。一次施法只计一次自然次数；连锁每跳、后脉冲、落雷和布点不生成新施法。GT01沿用每次施法唯一首次合资格命中检查。非暴击派生不再触发普通命中、GT01或追加链，但可以产生一次真实击杀。
- 追加保留本等级的基础几何、主伤与明确的基础机制；不获得标明“仅自然”的L05易伤、L07邻弧和L08强化过载。伤害型追加倍率缩放伤害，不缩放护盾恢复。
- 雷系采用“释放固定等级、几何、系数及追加倍率；命中读取当前攻击、增伤、雷易伤与暴击”。L10雷伤按命中时当前持有读取；本次连接加距在释放时取值，导电延长在实际施加／刷新时读取当时L10。雷系接入不修改火冰现有混合取值。
- 暂停／选卡冻结战斗时钟；清场、死亡、重开清理临时网络与队列。升级／换槽不回写已释放对象的等级、几何与次数；已经施加的导电或易伤不因换槽补时。

### 导电与合法连接

每敌一份导电，通常4秒，L01三级与L04为6秒，再加当时L10的延长。刷新将到期时间设为“本次时刻＋本次期限”，不叠层；不中断的最初建立时间保留，真正到期、死亡或离战才清除年龄。新刷新不产生额外命中。

普通连锁每边最长3.5米；该边两端在对应命中前已有导电时为4.5米，L10三级可至5米。每边分别检查距离、遮挡与活体。优先导电邻敌，再距离、稳定ID；本次施法共用visited，主目标也在其中，每敌至多访问一次。空余目标、断边与剩余强化次数不回填主目标，不保存到下一次。

本链有效命中杀死当前敌人，仍可从其有效命中点继续下一条边；目标若在本跳命中前被其他来源杀死，则不计本跳命中，可从上个有效起点重选一次合法邻敌。不能利用尸体重建网络。下一边判双端导电时，起点保留其该次命中前的导电资格，终点读取本跳发生前状态；本次新导电不能倒算本跳增距。

## 3. 十法术完整三级

各表为该等级完整效果，不是叠加前一级的增量。未在表内变化的吟唱、射程与选择规则对三级共用。

### L01 雷矢术：快速直射与首次布点

吟唱0.1秒，CD1.05秒，射程8米；最近可直射活敌。每次释放一矢，发射锁方向，碰实体障碍或首敌后消失，不无限追踪。

| 等级 | 完整效果 |
|---|---|
| 一级 | 主击100%；弹速18米／秒，半径0.16米；存活命中者导电4秒 |
| 二级 | 主击140%；命中前未导电时主击再＋20个百分点，即160%；弹速22米／秒，半径0.18米；存活命中者导电4秒 |
| 三级 | 主击180%；命中前未导电时主击再＋30个百分点，即210%；弹速22米／秒，半径0.18米；存活命中者导电6秒 |

成长重点是更快命中与更有效的初次布点。未导电增幅直接并入本次主击，可随主击暴击，不另打一段；先判断旧状态，再伤害、再布点。

### L02 贯雷枪：孤立强敌与有限穿线

吟唱0.3秒，CD2.4秒，射程9米；当前生命最高的可直射活敌为主目标，同分按距离／ID。释放时即时沿方向贯穿，障碍截断；主目标与沿线其他目标伤害互斥，次目标按前后顺序取有限名额。

| 等级 | 完整效果 |
|---|---|
| 一级 | 主击220%；全宽0.4米，最多1名其他沿线目标80%；各存活受击者导电4秒 |
| 二级 | 主击290%；主目标命中前2米内无其他活敌时仅主击×1.1，即319%；全宽0.55米，最多2名其他沿线目标各100%；存活者导电4秒 |
| 三级 | 主击360%；主目标命中前2米内无其他活敌时仅主击×1.2，即432%；全宽0.55米，最多2名其他沿线目标各120%；存活者导电4秒 |

“孤立”检查主目标周围的活敌，不要求整房只有一敌；不放大次目标，不把未用穿线名额返还主击。

### L03 连锁闪电：提高尾段效率

吟唱0.2秒，CD3秒，首目标射程8米，最近可视活敌。首击即时，之后每0.08秒至多走一边；所有有效受击后存活者导电4秒。

| 二级 | 首击180%；含主目标最多4敌；后跳改为180%×0.8^j |
| 三级 | 首击220%；含主目标最多5敌；后跳改为220%×0.85^j |

后跳是本术直接分量，可分别暴击，共用同一施法身份。无需先导电也可走3.5米基础连接；导电改善选中与增距。三级改善尾段，不另外追加第六敌或派生尾弧。

### L04 导电印记：一轮建立更大网络

吟唱0.2秒，CD5.5秒，射程8米；最近可视活敌即时主击。主伤／GT01后给存活主目标导电，再从有效命中点向3.5米内未导电活邻敌布点，分别检查该点到邻敌的遮挡，按距离／ID选择。

| 等级 | 完整效果 |
|---|---|
| 一级 | 主击80%；主目标及最多1名未导电邻敌导电6秒 |
| 二级 | 主击110%；主目标及最多3名未导电邻敌导电6秒 |
| 三级 | 主击140%；主目标及最多5名未导电邻敌导电6秒 |

邻敌布点不造成即时伤害，只布一轮，不从新节点递归；已导电邻敌不占名额，也不被本次刷新。主目标被本次主伤／GT01杀死仍可从有效命中点完成这一轮布置。没有邻敌仍有主击；不把布点失败转为伤害。

### L05 雷暴云团：持续点名与雷系输出窗口

吟唱0.4秒，CD8秒，射程8米。锁定起吟时最近可视目标的位置，完成时原目标仍须存活、在射程内且可视；失效则取消并重新等待完整吟唱。合法释放后云中心仍为起吟时锁定位置。**每次施法建立独立、有限寿命的云团，后施不替换旧云，也不取消旧云已经排定的落雷。** 各次落雷重新选择圈内当前生命最高、距离中心最近、ID最小的活敌，中心到目标需无遮挡。

| 等级 | 完整效果 |
|---|---|
| 一级 | 半径2米，持续4.2秒；释放后0.4／1.8／3.2秒共3次落雷；每次最多2敌，各90%；存活者导电4秒 |
| 二级 | 半径2.5米，持续4.2秒；同样3次，每次最多3敌，各120%；存活者导电4秒 |
| 三级 | 半径2.5米，持续5.6秒；在0.4／1.8／3.2／4.6秒共4次，每次最多3敌，各120%；存活者导电4秒；仅自然云团对每敌首次有效落雷后，存活者获得雷易伤＋15%，持续3秒 |

三级雷易伤不要求另持L08；当前首次落雷不倒算受益，后续雷伤可受益。每cast每敌只建立一次，同类仅刷新不叠多份；追加云团不施加此易伤。已存在的目标易伤可按剩余时间继续作用。

空圈该次空落，不存次数。每个云团每一波对同一敌人至多一次，各波原本间隔1.4秒；**不同cast不再争用跨云1.4秒伤害门**。每份云独立保存释放等级、落点、伤害倍率、波次及逐敌首次有效命中集合。追加云按其倍率独立结算，不覆盖自然云参数，也不获得自然三级易伤资格。到期／清场按生命周期移除，不产生递归云团。

初稿的“唯一云替换＋跨云共享门”会在50%→55%CDR时减少落雷；尝试连续刷新时钟也会因追加改变落雷相位，故未采用。正式版保留各级原有3／3／4次落雷和伤害系数，以完整保留每次有限排程解决问题。自然施法在60%CDR的周期为3.6秒，最长5.6秒云团通常最多同时2份；追加带来独立有限云，不代表固定取得或无限递归。

吟唱0.15秒，CD4.5秒；本级半径内有可视活敌才起吟。释放以玩家当前位置为中心，每敌分别检查遮挡，无击退或麻痹。

吟唱0.6秒，CD7秒，射程10米。优先导电者，其次精英身份、当前生命、距离、ID；无导电目标仍从合法活敌选择。释放锁主目标当时位置，0.25秒后半径0.8米检测，只攻击该主目标；不追踪，也不把邻敌作为主击范围伤害。

|---|---|
| 一级 | 主击480%；命中前已导电且主伤／GT01后仍活，追加160%非暴击条件雷伤；存活主目标刷新导电4秒 |
| 二级 | 主击620%；旧导电条件附伤200%；存活主目标刷新导电4秒 |
| 三级 | 主击720%；旧导电条件附伤240%；存活主目标刷新导电4秒；仅自然释放，若命中前导电已连续存在至少1.5秒，且主伤／GT01／条件附伤后主目标仍活，从主目标位置向4米内最多2名旧导电活邻敌各放180%非暴击邻弧 |

三级邻弧取消“另持L04”的外部资格，但保留成熟导电、主目标存活与有限邻敌条件。旧导电指本次命中前已经存在；刷新不会重置连续年龄，本次新布点不能自供资格。邻弧分别检查遮挡，按距离／ID选取，排除主目标，每cast一轮、不重访、不递归、不刷新邻敌导电。

提前击杀主目标时没有邻弧，这是保留的兑现限制；不能在模型或卡牌中写成每次必定多打两敌。单敌不补偿邻弧，追加裁决仍有基础旧导电附伤，但没有自然邻弧。

## 5. 数值目标与验证

本版是情境型比较：保留雷枪的对单优势、连锁的邻接清群优势、布点的网络支持和回盾的生存价值，不按所有法术同DPS设计。沿用旧一级作锚，二／三级迁入选择后的旧效果，暂不为了追平火冰而提高全体系伤害。

| 目标 | 判断口径 | 范围与限制 |

| 三起手可以独立开局 | 100攻击、无暴击、无遮挡2米、180生命，首次命中不晚于0.5秒、击杀不晚于4秒 | 固定目标算例，不代表实际敌人TTK或新手命中率 |

# 项目架构

更新：2026-10-22。本文负责代码分工、数据归属、技术边界和验证入口。实现状态与最新证据见[功能模块](功能模块.md)，玩法语义见[设计主题](游戏设计/README.md)，变更原因见[历史决策](历史决策/README.md)。

## 1. 工程与调用方向

独立根目录D:/demo；Godot 4.7.2、GDScript、GL Compatibility。[project.godot](../project.godot)加载[main.tscn](../scenes/main.tscn)，逻辑画布1600×900，初始1280×720，canvas_items＋keep。D:/taptap不参与新工程运行或开发。

~~~mermaid
flowchart LR
    Input[键盘与UI请求] --> Main[main控制器]
    Main --> Core[core规则与固定步]
    Data[data唯一参数] --> Core
    Core --> View[presentation只读快照]
    Core --> UI[ui只读状态]
    Main --> Meta[局外事务与存档]
~~~

core使用米制Vector2(x,z)，正z朝北门，1/120秒固定步；单帧最多积累0.1秒。3D镜头、骨轨、shader和UI只消费快照／事件，不反写战斗、随机数或领取资格。

### 路线生命周期

choosing → combat → pickup → reward或artifact → exit → 下一房；商店节点在exit后插入shop／shopping，不增加战斗房号。Boss书／箱是独立权益：书先处理，书后生成并缓存纯金候选，两项完成才开门，末房同样领取后结束。
开局池在configure时由出发快照的已装备触媒推导；无触媒时用独立随机流从六系18张基础术抽取三张，不消耗奖励采样流，快照暴露`opening_school`／`opening_source`。
清场结算合格回复再补盾，保留构筑与剩余冷却；选卡只走路线计时。完整路线time包含行走／领奖／商店，combat_time只计战斗；起始选择、暂停／失焦和结束停止计时。

替换pending是reward子状态；确认／取消／放弃、领取与商店购买均由core验证阶段、room_revision和请求标识后原子提交。取消保留原卡／RNG；失败不改变库存、余额或权益。松键门与UI翻牌仅限制输入／显示，不推进规则或重抽候选。

### 局外事务

main只向meta提交真实run_id和core已清数组；装备／核心快照在出发时锁定。内部route45等标识保留兼容，预览与真实收益路径分开，商店不计清房。
存档user://meta_progression_v1.json采用临时写入、刷新／读回和替换；失败不提交，损坏档保留报错。run_serial／结算token保证幂等。当前v7／宝石schema4，四个槽位不限制品质，金色宝石自带效果与三条属性；本版不设旧档迁移，任何版本不符的存档由core返回incompatible_version且不改字节，由main显式调用quarantine_incompatible_save改名为`.版本.bak-时间戳`后新建当前版账号。战斗层从快照的gem_cores按效果集合配置，`route_gem_combat`只认效果集合，`route_gem_school_router`为雷／风／岩／灵各持一份独立学派状态机；同名效果在账号层已去重，战斗层不再二次判断。

宝石实例ID、精粹、锁定、RNG、保底与待选候选同事务保存；候选先提交再选择旧／新，跨关闭／重启保持，本局装备锁定。累计清房及一次性精粹补给随真实结算原子提交。现代待选允许携原装备出发，局内禁止采用；旧待选须先选择完成继承。强退不续关或补发未结算收益；显示偏好独立存于user://display.cfg。具体迁移与工坊规则见[局外养成](游戏设计/局外养成.md)。

## 4. 角色、画面与资源管线

莉奈既有正式GLB／骨轨与头像来自已批准制作源；待机／跑动／分段施法已接入，动作不驱动位移或伤害。制作源art/lina由.gdignore隔离；Quaternius模板CC0不扩为角色模型许可，新动作按[协作约束](../AGENTS.md)执行。

庭院与角色使用批准资源和程序几何；墙外不可走。所有危险形状与特效共用相机投影，core快照提供位置、范围、寿命／状态与战斗时钟；暂停／选择／清场不产生新的攻击。友方美术不得遮蔽敌方预警，减少动态效果只影响显示。十核心与八属性图标由gem_icon生成，核心VFX由route_gem_vfx单768线段批次读取真实gems／schools快照与兑现事件，旧法术VFX不重复处理这些事件。

法术／宝物／触媒图按ID引用；归档图与兼容ID不意味着仍进池。卡牌AtlasTexture只选择显示区域，不改原PNG像素；非方图保持比例，空槽清除旧图。雷／风／岩／灵契40术与四触媒由arcane_icon原生绘制，使用各ID独立轮廓、适配尺寸的描边与明暗层次，不新增图片或字体。六系特效采用缓存批次与独立只读子模块；雷独立有限批次，风／岩／灵契共用有限批次，几何丰富度与减动态设置不改变对象有效期、实际范围或状态资格。

来源、提示词、原图／最终路径、透明处理与哈希由[assets.json](assets.json)和其指向的生成记录保存；字体保留[OFL](../assets/fonts/OFL.txt)。历次素材与像素证据见[验证归档](历史决策/归档/20261020-历轮验证与素材索引.md)，不在架构复制轮次清单。

## 模型做什么

- 按实际档位与一次生命补偿计算非Boss及相邻精英参照，比较四个占位房的原总生命。
- 用可改的有效Boss伤害与离散伤害包计算条件用时，含偏弱／普通假设／强／极强输入、零输出与致死先于换阶段的边界。
- 以离散事件循环90秒的每套阶段招式，整轮先预约、逐颗释放，按5秒／15米移除；不计算墙／玩家消弹，最终Boss后两阶段加一只始终存活的M02作为保守容量上界。不复制玩家法术或AI。
- 在当前四个房间几何上用0.5米四邻接格检查入口、奖励前庭和身体外霜环攻击位置；局部预警只核算单威胁、开阔直线离开与0.25秒反应假设。
- 比较0.8／1.0／1.2生命因子；固定种子做5000次金色候选采样，核对少量／空池、唯一持有、建议庭印兜底、先书后箱、固定候选与重复领取。

## 首版结果与限制

149项／0失败。假设有效DPS400／700／1100／1600时，离散条件用时60／69／73／81.5秒；2.5倍输出为24／27.5／29.25／32.5秒。有效DPS是设计输入，不是已经测出的构筑强度；不据此宣称真实Boss用时或整局约30分钟已通过。

金色采样只测试给定合资格金池中的候选分布与非空性，不模拟整个构筑的资格形成、玩家选择效用或全局获金概率。新庭印是明确待审兜底，不是现有宝物效果。

# 其余五系候选数值核验

这是设计工具，读取本目录待审参数，不向`data`、脚本、存档或游戏写入值。冰、雷、风、岩、灵契文档按游戏设计14—18阅读；跨系约束和审查见设计19。火系已通过规则仍以当前data与历史13为准。

```powershell
Set-Location D:/demo
python tools/balance/five_schools/run.py
python tools/balance/five_schools/audit.py
```

默认输出`build/qa/five-schools-design-20261018/results.json`、`starter_scenarios.csv`、`report.md`。可用`--output`指定独立目录；不要覆盖旧火系评审。`parameters.json`保存场景、判据；五份学派JSON保存可编辑候选数值，不是第二套运行默认值。

`audit.py`另读取任务开头的`runtime_guard_before.json`，核对现行源／素材／引擎未变、没有新增运行文件，各稿的状态、10／16条目及本地引用；输出`document_audit.json`。条目／引用和数学检查分开，不相加成玩法验收计数。

模型先核对已知吟唱＋释放后CD算例、.2秒CD下限／60%CDR、100%以上暴击无超暴、同桶增伤、末次召唤攻击先于到期、容量等待再完整吟唱、连锁逐边遮挡与不重访、散片不重复伤主目标、构造唯一终结、真实位移排除顶墙／传送，再读候选起手。每次运行保存输入哈希。

起手按三级、30／60秒、0／30／60%CDR、单敌／六个合法敌人、100%／65%命中期望运行。伤害事件发生在吟唱完成后指定延迟，观察结束后的伤害不提前算入；召唤按容量与有限寿命调度，CD不直接加快普攻。相同时间先旧普攻、再到期，再等空位启动完整吟唱。

单敌180生命的TTK按攻击100、无暴击、全中逐事件累加；不将六目标总伤害算回一只，也不以平均伤害除生命替代离散击杀。DPS另使用当前基础5%／1.5倍暴击的数学期望。65%命中是线性期望近似，没有模拟随机触发或把它叫真人能力。六目标值是明列几何条件下的可达覆盖包络，不是实战命中率。前置机制、职业宝物、控制／护盾生存和整局长度需要另外验证，不能由该表推断。

本轮不执行Godot、不修改运行、不生成素材、不导出。角色真正的命中、召唤追击、敌方攻击、玩家行为、掉落及完整60房Boss仍是模型外内容。

模型1.1补充合法瞄准最远点与逐跳拉距可达检查。首轮只有近处起手包络，不能发现风环选敌8米但飞行仅5.5／6.5米、一级双翼偏置程长不足，或WB05四跳各最多0.6米无法兑现2.75米总预算。最小拒绝对照保留在`geometry_baseline.json`：先补模型守卫，再采用5.5／6.5／6.5米合法选敌，以及仅WB05下每跳最多0.7米；未以增加伤害补模型错误。中心可达守卫是保守设计保证，不代替真实碰撞体边缘、墙或逐敌飞行。

# 新版核心宝石：火／冰／雷详细提案 r2

日期：2026-10-22。**仅为设计提案与离线事件核算，未获游戏实施授权，未改data、scripts、存档或实际法术。** 本文供十核心总方案合并；唯一提案参数文件为[fire_ice_lightning_parameters.json](fire_ice_lightning_parameters.json)，核算工具为[fire_ice_lightning_model.py](fire_ice_lightning_model.py)。本轮规则事实来自现行data/core；旧模型不代替实现。

## 共通口径

- 一枚固定机制核心＋三枚属性宝石；核心没有随机词条或等级，一局只激活一个核心，无手动核心按钮。
- 所有时间是实际战斗时间。暂停／选卡不推进，清场／死亡／换房清库存、充荷、门、token和未兑现队列，不带入下房。
- 系数1为100%攻击；示例锚点攻击100、无暴击、生命300／盾100。核心派生伤害不得重新引发核心、状态、GT01、追加施法、普通命中回调。
- 下述库存已经来自一次完成取值的伤害，兑现不再乘攻击、学派增伤、通用增伤、目标易伤或暴击第二次。生命损失仍经唯一受伤／死亡事务。
- 库存容量的攻击预算在该轮积累开始时记录，刷新既有窗口／燃烧／电荷不重算容量。例子中的攻击始终100；模型没有模拟临时攻击变化。
- 邻敌始终是活体、有限半径、当前可视且逐边无遮挡的实际目标；主目标不占邻敌名额。无邻敌没有空名额补偿。不因表现粒子重复结算。

## 1. 火：余烬炉心

**一句话：维持真实燃烧与自然火术命中，将已经打出的火伤积成余烬，每四次真实燃烧跳集中爆燃。**

| 参数 | 推荐提案 |
|---|---:|
| 有效燃烧跳伤入余烬 | 60% |
| 命中前已有真实燃烧的自然火术本体入余烬 | 本次实际伤害15%，每cast每敌仅首个有效本体命中 |
| 集中爆燃要求 | 同一燃烧token累计4次有效燃烧跳 |
| 主目标兑现 | 100%余烬 |
| 邻敌兑现 | 2米，最多2名，各35%余烬 |
| 每敌库存上限 | 本轮攻击预算×3，即攻击100时300 |

详细次序：先结算已经到点的旧燃烧跳，再按该跳真实扣除的生命积余烬与计数；主目标仍活且计数到4时，一次清空该敌余烬和四跳计数，再打主目标和有限邻伤。爆燃不会消费未来燃烧，燃烧自己的后续跳、到期和刷新仍按原规则继续。自然到期同刻的合法末跳先完成，若恰好是第四跳可兑现，随后终结旧token；残余不足四跳的余烬消失。

自然火术本体命中只有在**命中前**存在有效燃烧、该击确实造成伤害且敌人仍活时才积15%；这15%是额外库存，不从原击扣除。F01次弹／同cast多雨点不能对同敌重复拿这笔15%；自然F03／F05／F06的首个本体分量可以记录，后续区域重复跳只正常伤害。F01暴击留火、F06成熟爆发等派生不记录。火状态燃烧本身另按60%入口记录。

**F07本体、引爆和后震均不入余烬。F07消费燃烧时同时丢弃该token余烬及四跳计数。** F07三级复燃是新token、从0余烬0计数开始；不能既拿引爆的未来燃烧库存，又把未满四跳余烬另兑现。主目标被其他伤害杀死不产生额外死亡爆燃，余烬清除，保留快杀与持续经营的取舍。

手算：四次各25点有效燃烧跳产生60余烬，主目标爆燃60，两名合格邻敌各21，总爆燃102。若期间还发生一击100点合格自然火术，则额外存15，主75、邻各26.25。所有这些库存量不再次吃暴击与火增伤。

推荐搭配：

- **一级起手：F01焰弹术或F08贯焰光束**。单术能维持燃烧，长时间单体可自行完成四跳；180生命普通敌通常在成核前已死，属于明确弱情境。
- **持续铺火：F01＋F05焰流旋涡＋F06炽焰法阵＋F11引燃之印**。靠不同覆盖方式维持活敌燃烧，F11扩大可持续对象与燃烧维持时间；每个敌人的余烬仍独立。
- **走位覆盖：F03流火之雨＋F05焰流旋涡＋F08贯焰光束＋F09灼浪**。在怪群聚集时邻伤有价值，移动出范围会降低后续本体与维持机会。
- **稳定输出补位：F02精通、F10护持**。精通只通过原合格伤害影响入库，护持不直接制造余烬。
- **F07并非优先搭配**。可以保留应急／重击，但较频繁消费会打断炉心的持续循环；不增加隐藏保留库存补偿。

初版只有“60%真实燃烧伤害入库”，起手约+24%，三级F01＋F08单体仅+7.5%；因此r2加入15%合格自然本体信用。此次是参数／机制修订，没有通过提高所有基本燃烧倍率掩盖成长偏差。

## 2. 冰：晶封之心

**一句话：冰系先建立合法冰裂窗口，随后六系合格法术本体可协作储伤；保留窗口至到期得到更高兑现，提前碎冰则较早拿回较低倍率库存。**

| 参数 | 推荐提案 |
|---|---:|
| 有效旧冰裂窗口内计划本体伤害暂存 | 40%，即时段保留60% |
| 每token库存上限 | 窗口攻击预算×8，即攻击100时800 |
| 自然到期主目标兑现 | 库存×1.8 |
| I07等合法提前消费兑现 | 库存×1.45 |
| 死亡处理 | 库存×1.0，仅向邻敌兑现，不打尸体 |
| 邻敌 | 3米，最多2名，各为本次兑现量30% |
| 额外硬冻／延长窗口 | 0 |

“合格本体”明确包括六系法术本体直接／区域分量，必须在本击前已有合法冰裂token。形成新窗的那次伤害不入新窗；契灵普攻、号令、燃烧、F07状态引爆、I07碎冰派生、岩回响／裂隙等非本体及所有宝石派生均不入库。同一token只允许一种终结原因兑现一次。

到达容量后的超出部分立即正常结算，不丢伤害，也不创建第二个库存。窗口内一次伤害先预存40%合格计划伤害，再打即时段；若即时段杀死主目标，走死亡终结×1.0邻伤并清账，后续同击I07消费或到期不能再领一次。若主目标仍活且I07合法消费旧窗，则库存按×1.45兑现，I07自己的碎冰与邻片仍走原机制，不能把其派生再入库。自然到期按×1.8兑现后清除旧窗库存；同刻到期后的新命中不能再存旧窗。

主目标死亡时不把本来应返还主目标的库存变成新的全额邻爆；只有原规则的30%邻伤。清场不作死亡兑现，切房队列直接清理。

手算：有效窗口内累计400点合格本体计划伤害，存160、即时240；自然到期主目标288，总528（该窗口这部分伤害+32%）；提前消费主目标232，总472（+18%）。两者都付出了即时段减少40%的代价。这里的+32%／+18%是**合格窗口输入**的结果，不是整局总输出提升；窗口稀少或容量饱和时总收益会更低。

Boss硬冻系数仍为0，但合法冰裂窗口有效，因此Boss储伤不依赖把Boss冻结。此核心不生成新窗口、不改变施霜门、不延长控场、不绕过窗口token。

推荐搭配：

- **一级起手：I01霜弹／I02穿刺／I03寒星**均能逐步施霜成窗。首个窗前没有收益，短寿命小怪可能看不到核心兑现。
- **稳定储伤：I01＋I05领域＋I08冰棺＋I10研习**。I08确保窗口来源，I10原有窗口延长有助于承载更多实际命中。
- **范围持续：I02＋I03＋I05＋I06风暴**。多敌分别储伤，真正聚集才得到有限交叉邻伤；不能把远端敌人当作必然命中。
- **混合重击：I01／I08＋F08光束或L02雷枪／L07裁决**。其他学派本体可进入冰窗，但仍保留各自学派取值与身份。
- **I07为提前兑现选择，非本核心首推伤害组合**。早点结束控制换本术碎冰与较早返还；不能同时免费获得自然到期×1.8。
- **纯契灵队不是储伤来源**；若只配I08与S02／03／04，窗口有了也不会把宠物普攻装入库存。

## 3. 雷：雷暴回路

**一句话：自然雷术反复命中已有导电主靶积四荷，下一次主动伤害雷术先抽走一小片旧导电，再落雷兑现；成熟导电网络与强放电有真实竞争。**

| 参数 | 推荐提案 |
|---|---:|
| 一次充荷资格 | 自然雷术每cast首个有效本体命中，且该击命中前已导电 |
| 全局充荷门 | 0.6秒 |
| 储雷量 | 合格该击实际伤害40%，原击不扣伤 |
| 充满 | 4荷 |
| 库存上限 | 本轮攻击预算×8，即攻击100时800 |
| 无合格事件散失 | 6秒，清荷与库存 |
| 放电消费 | 主靶旧导电＋其3.5米内最多2个可视旧导电 |
| 定点落雷 | 0.15秒后；主100%库存、两邻各30%库存 |
| 每个落雷资格 | 该已锁活体仍在其旧落点0.8米内且LOS合法 |

每cast只检查首个有效本体命中；若此击命中前没导电，本cast后续多弹、多段、连锁或云波不能补领充荷。L03只看第一主击，L05看第一波第一有效主靶，L06按稳定次序第一有效主靶，L08只看主击；额外网络边不计。L07只存可暴主段的实际伤害，导电附伤／成熟邻弧不存。首次新导电不能自供同击充荷。

四荷满后不再继续加库存或刷新闲置时限。下一个成功完成的**自然主动伤害雷术L01—L08**若有合法可消费导电主靶，则先锁主靶和至多两邻、原子移除这些旧导电，再让原法术读取旧态／网络成员并释放，最后安排核心落雷。L06以其伤害圈内最近合法旧导电为主，L05以其锁定目标范围内合法旧导电为主；没有合法导电时原术正常释放、四荷保留至闲置到期。L09防护、L10被动、追加施法既不消费也不充荷。

**消费必须发生在L07导电条件和L08网络成员捕获之前。** 这次L07不能用已经消费的主导电领取条件附伤或成熟年龄；L08不能把已消费成员算作原旧网络，后续原术重新施加的导电是新年龄。即使放电cast的其他段后来命中尚有旧导电的敌人，也不回收该cast的伤害作为下一轮充荷。

落雷是独立有限派生，锁定每个已消费对象及旧落点，不追人、不在目标死后自动补选。未消耗到的邻名额、落空或死亡目标没有主靶补偿；Boss只有一名就只兑现主落雷。库存已经取过伤害值，不再吃攻击、暴击或雷易伤第二次。

手算：四次各100点合格主击存160，下一次放电主160；若确实另外消耗两个可视旧导电，二者各48，总256。空场、未导电或只有一次新施标无法产生库存。

推荐搭配：

- **一级起手L01雷矢**能自行施标后循环充荷，单Boss可独立兑现；起手L02／L03也能运作，但较慢自然频率会延后成核。
- **主推直击循环：L01＋L02＋L04＋L10**。L01维持频率，L02提供较高单次合格主段，L04布置可消费邻导电。
- **延迟区域：L01＋L04＋L05＋L06**。云与雷环可以配合；每cast仍只有一个充荷检查，不会按每波／每敌叠荷。
- **L07裁决可以混用，但有真实损失**。消费时本次成熟／旧导电收益减少；用L01／L02支撑频率比L07单术合理。
- **L04＋L08成熟网络不是本核心首推**。它们更依赖保存旧网络，可能牺牲多条派生边来换一次落雷；不把低适配强行补到同一收益线。
- **L09只能布置状态和防护**，没有单靠回盾堆充荷的路线。

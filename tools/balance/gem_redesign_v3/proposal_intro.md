# 新版魔法宝石：十核心与获取养成提案

日期：2026-10-22。提案版本：gem-redesign-v3-r3。**用户批准的是整体设计方向，并要求先看详细方案；尚未授权制作。所有机制、数值、获取费用与迁移规则均为待评审提案，未写入运行data、脚本、场景或存档。**

## 1. 结构与职责

装备为一枚固定机制核心＋三枚属性宝石。核心没有普通词条、随机数值或升级等级，解锁即完整可用，同一局只有一个核心。属性宝石有确定主属性和0／1／2条不同类型副属性，绿／蓝／紫分别1／2／3行；金色标识独立的核心类别，不表示属性石上还有一档金色品质。

法术与三级成长决定攻击／控制／防护方式，触媒影响法术抽取倾向，局内宝物在冒险中改变构筑，宝石在出发前决定战斗方法并承担长期属性养成。学派核心允许混学；具体单术的强专属效果仍留给未来专属宝物，不另建独立法术专属升级系统。

十核心按六系玩法和四种通用选择组织：余烬炉心、晶封之心、雷暴回路、流岚之心、镇岳基石、协奏契印、星裂棱镜、双生镜心、血祭红晶、血晶屏障。没有额外主动键，装备与养成只在局外操作，出发后固定。

## 2. 证据与首轮目标

### 已确认的现行锚点

实际基础源为攻击100、生命300、盾100、暴击5%、暴伤1.5倍、移速5米／秒；六系各十术三级、八个法术槽；法术CDR合计最多60%，不缩短吟唱、契灵普通攻击间隔或核心内部间隔。当前60战斗房的魔尘预算为105，清15／30／45房分别15／45／75魔尘；它们是清房账本收入，不包含未来Boss额外奖励，也不等于真人获得速度。

### 暂定设计目标

| 要观察的结果 | 首轮锚点 | 判断方式 |
|---|---|---|
| 开局可使用核心与三属性槽 | 首次1核心＋3枚自选主属性绿石 | 不依赖先抽到某核心才能试玩法 |
| 第二个指定核心 | 30魔尘即可确定获得 | 约清23房已有31尘；与触媒／抽取竞争，不能承诺第23房一定购买 |
| 合理配套的核心输出 | 常用受影响通道约＋20%—45%作为调参锚点 | 按单体／群体／站位／寿命分别报告，允许有条件更高或低适配更低，不设总输出硬上限 |
| 三蓝属性石 | 平衡消费、完整105尘预算样本p90不晚于2次结算为初始目标 | 若模型未达则保留警告，不改文字假装通过 |
| 三紫属性石 | 同样口径p90不晚于4次结算 | 只代表品质可用，不代表指定属性或毕业 |
| 指定主副类型且全III三紫 | 同样口径p90不晚于12次结算 | 明确是保留升级／定向重铸政策下的离线分布 |

核心比较属于情境型；不同生命风险、延迟、控制消费、走位和阵地条件不能折成一个无条件强度排名。属性档位和制作成本属于递进关系；获取／消费政策为两者混合。计量锚点不是最终验收标准。

## 3. 十核心共通边界

- 所有蓄量、成熟、闲置失效和队列使用战斗时间，暂停／选卡冻结；清场、死亡、换房清临时资源，不能隔房囤爆发。
- 核心只作用于文中明确列出的合格来源；契灵普攻、号令、本体、燃烧、状态引爆与固定附伤不能因为都显示伤害数字就互认。
- 核心派生不暴击、不施状态、不触发普通命中、GT01释放、P04自然追加或新核心事件；已积累伤害兑现不再乘第二遍攻击／暴击／学派或易伤。星裂接收的是原本允许暴击的本体额外段。
- 核心不会提高契灵数量／寿命／容量，不新增构装来源／碰撞／仇恨，不把风幕改成实体墙，不改变Boss硬冻或控制分类上限。
- 有限邻伤必须在真实范围、存活、视线与目标上限内，空名额不折回主目标；表现对象不增加结算次数。
- 三级强化与追加的资格逐分量保持；法术改等级／替换不会改写已释放对象。提案没有顺带统一所有伤害的取值时点。

# 搭配、显示与评审边界

## 属性石的配套方向

下列为配装建议，不是第二套强制起手，也未声称已穷举所有六系组合。主属性可重复；已有临时／永久属性接近上限时，优先换成仍有收益的类型。

| 核心 | 三主属性起步建议 | 副属性重点与取舍 |
|---|---|---|
| 余烬炉心 | 攻击／攻击／冷却 | 护盾与防御保证燃烧经营；暴击不让燃烧跳自己暴击 |
| 晶封之心 | 攻击／冷却／护盾 | 需要等窗口兑现；高伤频已触库存上限时，继续堆伤未必提高核心占比 |
| 雷暴回路 | 攻击／冷却／暴击 | 暴伤、护盾补位；0.6秒充荷门不会随CDR缩短 |
| 流岚之心 | 攻击／冷却／移速 | 护盾／暴击；移速帮助真实路径与脱险，不直接提高每层12%倍率 |
| 镇岳基石 | 攻击／护盾／防御 | 生命或移速支持驻阵／转阵；CDR帮助原岩术，不缩短3秒脉冲 |
| 协奏契印 | 攻击／攻击／护盾 | 暴击提升原普通攻击，合奏额外段不暴击；CDR影响召唤续接，不缩短宠物普攻间隔 |
| 星裂棱镜 | 暴击／暴伤／攻击 | 冷却与护盾；基础5%暴击时先获得其他核心通常更直接 |
| 双生镜心 | 攻击／冷却／护盾 | 暴击仍提升主击，但非暴击副击不复制暴伤；命中稳定性比盲目堆延迟收益更关键 |
| 血祭红晶 | 攻击／护盾／防御 | 生命与冷却按构筑补；堆生命同时提高每秒绝对自耗，不改变百分比停止线 |
| 血晶屏障 | 生命／护盾／防御 | 生命III主＋40在本核心下成为＋28生命／＋26.4盾；盾III主＋16直接加盾，仍要比较实际恢复来源 |

## 图标与反馈设计意向

这里只定义辨识方向，没有生成图片、制作图标或接入特效。所有视觉读真实状态，不用粒子数量控制规则。

| 核心 | 轮廓／材质意向 | 必须读出的状态 |
|---|---|---|
| 余烬炉心 | 炉膛状红橙晶核、四条熔缝 | 当前目标四跳进度、库存与消费清空；爆燃时短促内爆后外圈热浪 |
| 晶封之心 | 冷白六棱晶体、中心封存裂隙 | 合法冰裂窗口与暂存条分开；自然到期／提前碎冰用不同收束速度 |
| 雷暴回路 | 深蓝四节点菱晶、金白回路 | 四荷逐节点亮起、满荷待释放；被抽走的导电立即灭去，落点0.15秒预告 |
| 流岚之心 | 青绿偏斜长晶、三道弧脊 | 三层风势、气流有效、散失预告；不常亮伪造碰撞范围 |
| 镇岳基石 | 琥珀方晶与岩座、低重心 | 唯一锚实例、驻留成熟、下次脉冲；短离宽限与失源需明确区分 |
| 协奏契印 | 紫青三瓣结晶、中心契纹 | 三点协同、上一族小标记、满额后下一普攻兑现；不让号令误点亮 |
| 星裂棱镜 | 银紫分叉棱晶、折射断面 | 暴击额外段转移与最多两跳；链结束后即灭，不向空敌补跳 |
| 双生镜心 | 两片错位镜晶、前实后虚 | 主击与0.6秒副击区分；副击是淡镜影，不画成第二个完整控制法术 |
| 血祭红晶 | 暗红心形棱晶、向内血线 | 当前缺血增伤、自耗与35%停止线；停止线不显示成免死护罩 |
| 血晶屏障 | 深红晶盾、银白包边 | 转换后的真实生命／盾上限、治疗转盾；满盾溢出不出现可积存读数 |

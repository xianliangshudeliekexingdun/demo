# 新版宝石：风、岩、灵契三核心详细提案

版本：2026-10-22 r2；**仅设计与独立离线核算，未接入游戏。** 本稿是十核心总提案的分项输入，实际运行值仍以data和core为准。普通属性、获取／养成与四个通用核心由总提案统一，不在本稿设第二套规则。

## 共通口径

- 一次出发只有一个核心，核心无普通词条、无随机品质倍率、无等级；没有新增按键或手动激活。
- 全部计时使用战斗时间，暂停／选奖冻结；清场、换房、死亡、结束清除层数、来源、队列。跨房走路不预充。伤害仍经统一真实受伤／死亡事务。
- 新核心派生不暴击、不触发普通命中、GT01、自然施法计数、P04/P05、宝石回响或自身再次蓄能；不制造新点燃、施霜、导电或契印。风核对既有自然本体分量的倍率调整不额外制造一次命中，其原资格不变。
- “攻击系数2.0”表示在攻击100、无其余增幅时为200伤害；之后按该学派当前攻击、临时攻击、通用／本系增伤与合格易伤各应用一次。不是固定附伤再重复乘一遍攻击。
- 20%—45%只是首次设计的普通配套通道收益锚点，不是游戏输出上限，也不要求不同空间／生存条件的核心同伤害。

## 1. 流岚之心：持续移动与施法共同维持顺风

**简短说明：** 实际走位积累风势，持续施法维持气流。风势越高，后续自然风术越强、部分伤害形状越宽；停步或久不施法会散失。

| 参数 | r2建议 |
|---|---:|
| 成功自然进攻风术保持气流 | 最近2.5秒 |
| 每层风势所需真实自主路径 | 1.5米 |
| 最大层数 | 3层 |
| 每层自然风术本体倍率 | ＋12%，最多＋36% |
| 每层合格宽度／半径倍率 | ＋4%，最多＋12% |
| 停步或气流断开后的首次掉层 | 0.5秒后失1层 |
| 后续衰减 | 每0.5秒再失1层 |
| 自然风术释放时是否消费风势 | 不消费 |

规则顺序：

1. 首次成功自然释放W01—W08中的进攻法术，开启2.5秒气流；后续同类成功释放刷新气流。没有实际命中也算成功施法，但无资格／取消吟唱不算。W09防护、W10被动不刷新。
2. 气流有效时，只有碰撞裁剪后的真实自主路程蓄风；顶墙、传送、击退和领奖移动不计。每满1.5米增加1层，最多3层。满层后不囤额外路径，也不按敌人数或多段次数蓄风。
3. 自然风术开始释放时，固定当时风势层数和倍率；这次释放先固定倍率，再刷新气流。追加法术不刷新、不享受风势本体倍率，也不改变层数。已释放区域／风径在后续掉层时保留自己的释放快照。
4. r2层数不被施法消费；停步或气流失效才进入散风。失效连续0.5秒先掉1层，再每0.5秒掉1层；开始掉层时丢弃不足1.5米的尾数。只要重新真实移动且气流有效，停止衰减。气流断开但仍走动，同样按时衰减，不能只跑不施法永久保留。
5. 伤害增幅只作用本次自然风术原本体分量；W06补压、W07交剪等已有派生不额外放大。没有新增暴击／状态事件。

合格几何清单必须逐项列出：W01／W02／W03／W07只放大命中宽度，W06放大本体爆炸半径（中心额外区、补压仍各守原规则），W08只放大已生成短段伤害半径。W04锥形推散、W05聚风控制区、W09风幕尺寸不变。所有射程、飞行弧长、转角、风径录制预算、持续时间、间距、穿透名额、单敌次数、共享命中门、推拉距离／分类上限均不变。

搭配建议：

- 一级起手：W01风刃术或W03逐风矢；一术也能一边移动一边维持。W02回旋风环仍须经营真实归航位置，核心不会让回程追人。
- 移动贯穿：W01＋W02＋W03＋W10，侧向移动维持层数，利用弹路覆盖。不是把每一发都变成无限贯穿。
- 轨迹覆盖：W01／W03＋W07剪风双翼＋W08留风之径＋W10；移动同时满足风径和研习条件，风径原次数预算不扩大。
- 群怪：加W05聚风涡改善真实聚拢、W06真空爆兑现覆盖；核心不会额外拉Boss。
- 生存补位：W09风幕或跨系护盾可以正常使用，但它们不单独维持气流；长期只带W09／W10没有核心进攻收益。

代价是移动约束与气流中断。窄地形、必须驻足、隔墙空等施法时收益下降；不会暂停移动中的正常吟唱，区别于旧“行者蓄势”的走停爆发。

## 2. 镇岳基石：围绕一个真实构装经营成熟阵地

**简短说明：** 靠近自己的一座构装扎根，成熟后周期性震击周围敌人。换阵或消费构装会失去积累。

| 参数 | r2建议 |
|---|---:|
| 可作为锚的来源 | 实际存续R03支点／R04石柱／R09石碑 |
| 同时锚定 | 1个真实实例 |
| 玩家到锚的距离／视线 | 3米以内，必须可视 |
| 累计有效驻留成熟时间 | 1.5秒 |
| 首次脉冲 | 成熟立即结算 |
| 后续脉冲间隔 | 3秒 |
| 脉冲系数／半径 | 2.0攻击系数／2.4米 |
| 每脉冲敌人上限 | 4名，按距离／稳定ID |
| 离阵保留时间 | 0.5秒，期间不成熟、不伤害 |

规则顺序：

1. 玩家进入合格构装3米内时，选择最近可视实例；距离相同按出生ID。**选中后锁住实例**，只要仍有效且在有效覆盖中，不因另一个构装更近而每帧跳源。
2. 累计有效驻留1.5秒后立即发第一次脉冲；以后每3秒发一次。脉冲中心是构装真实位置，不跟随玩家或敌人；逐敌检查2.4米、存活与从锚点到敌人的视线，最多4名，孤立Boss只打一份200%系数。
3. 走出3米或丢失视线时暂停成熟，短离期间不累计有效驻留，保留原来源与进度至多0.5秒；其间到点脉冲不造成伤害，也不囤一次返回补发。0.5秒内回到同一来源可继续，否则清空并重新选源／成熟。
4. 来源到期、被替换或被R06消费，立即取消锚与成熟；没有离阵宽限、爆炸、退款或最后补击。新的同位置构装是新实例，不能继承旧锚。既有同刻构装结算与注销次序继续尊重，已经被移除的来源绝不补发。
5. 岩脉冲是独立核心岩系派生，不暴击、无硬控，不触发R07回响、R06消费奖励或普通命中。不会增加构装数量／寿命／碰撞／生命／仇恨，也不提供R06选奖前置。

搭配建议：

- 起手可直接选R03岩棱坠击：主落完成后有真实支点，玩家靠近后开始成熟。R01／R02起手在没有构装前无收益，装备页应明确提示，不能凭核心空造支点。
- 稳定阵地：R03＋R04地脉石柱＋R09护阵石碑＋R05岩甲术＋R10岩法研习，经营锚点与承伤空间。
- 阵地进攻：R04／R09＋R01碎岩矢＋R02震地波＋R08山崩落击；其他岩术正常输出，核心只增加唯一锚点脉冲。
- 借源路线：R03／R04＋R07地脉共振，R07保留原有限来源与取消条件；三座构装不会让核心同时震三次。
- 消费路线：R03／R04＋R06坍岩令＋R08，主动消费换本体爆发，但真正放弃该来源后续成熟脉冲；核心不给消费反向补偿。

这是有意保留的情境差异：少法术长战的固定脉冲占比高，多法术或高CDR构筑中占比会稀释；强迫移动、换源、敌人离圈时明显失效。不将其包装成常驻全局增伤。

## 3. 协奏契印：实际普通攻击形成合奏，单宠也能运作

**简短说明：** 契灵普通攻击命中会蓄协同，轮换不同类型蓄得更快；满额后的下一次普通攻击兑现一次合奏。

| 参数 | r2建议 |
|---|---:|
| 协同上限／蓄满阈值 | 3点 |
| 成功普通攻击动作 | ＋1点 |
| 与上一次成功动作不同族 | 额外＋1点 |
| 合奏额外伤害 | 原合法命中集合，各加本次非暴击计划伤害的120% |
| 合奏额外段是否暴击 | 否；原普通攻击照常判暴击 |
| 合奏动作是否再蓄能 | 否 |
| 无成功普通攻击清空 | 连续3秒 |
| 场上全部进攻契灵离场 | 立即清空 |

规则顺序：

1. 族群只有远程契灵S02、持剑侍从S03、灵鹰S04三种。两个S02属于同族，不因实例ID不同领取换族额外点。
2. 一个普通攻击动作至少对一名合法敌人结算正伤害，才记一次。穿透、扇斩、扫掠的多敌命中都不多蓄；丢失目标、追击、重定位、动作被取消不计。
3. 未蓄满时，该动作在原伤害后取得1点；若与上次成功动作不同族再加1点，封顶3。**本次刚蓄满不立即兑现**。
4. 已蓄满时，下一次具有实际正伤害接触的契灵普通攻击消费全部点数。这整个动作原本合法、有限的命中集合分别获得120%非暴击计划额外段；不扩大目标集合、射程或名额，不重放攻击、不产生新召唤／号令。原本体和额外段共享真实受伤／唯一死亡结算，额外段不暴击、不重新应用契印／物品命中／核心蓄能。
5. 计划基数包含该原普通攻击当下合法的攻击、本系／通用增伤及原契印普通条件加成，各只算一次；不把原本体的暴击倍率复制给额外段。
6. 合奏动作仍更新“上一次成功族群”，但不蓄点。S05号令、S01／S06／S08本体、S07法阵、S09回盾和任何派生均不蓄也不消费；不能靠号令四份协同瞬间反复满额。
7. 连续3秒无成功普通攻击，或全队进攻契灵已离场，清空点数／待兑现和上族记录。已经蓄满但下一动作打空不消费。原有到期同刻末击先结算再注销，核心不延寿或补攻击。

搭配建议：

- 单宠起手S02或S03即可：同族每三次普通命中蓄满，第四次普通攻击兑现；不要求先拿S05或集齐三族。
- 双族合奏：S02＋S03＋S01契印灵矢＋S09护主灵，兼顾远程、近战与标记集火。额外点来自真实轮换，不来自“同时持有两系”的常亮加成。
- 三族协同：S02＋S03＋S04＋S10灵契研习，攻击时点自然交错，提升换族频率；仍受总4只与各同名容量限制。
- 延续合奏：S02／S03＋S07契约法阵＋S08灵缚锁链＋S10，利用正常续存与减速维持真实攻击机会，核心不另给寿命。
- 号令与消费取舍：S05可以照常独立输出，但不推进合奏；S06消费活宠会丢失该宠后续动作，全部宠离场更会清协同，不能同时白拿全部普通收益。

Boss单体不需要邻敌，合奏完整作用于同一个合法目标；群怪只增强该次普通攻击原可命中的对象，不将单体S02变成额外范围攻击。S01单独起手在未学召唤前没有本核收益，装备页需如实提示。

## 5. 修订、敏感性与保留警告

- r1采用风术消费所有层，普通仅＋13.48%、高CDR多术进一步摊薄；r2改为持续气流维持，不再消费，保留移动／施法中断代价与最大36%／12%。
- r1岩脉冲0.8，双术普通仅约＋6.78%；r2选2.0作为温和脉冲，而非更强的2.4。2.4会使普通约＋20.34%、优化约＋32.43%，但R03独术长战约＋109.09%。不为统一锚点而继续加伤或引入一套储脉冲系统。
- r1灵契4点，一级S02有限寿命内经常来不及兑现下一轮，30秒约＋11.15%；r2阈值3，使单宠也有稳定基础收益，保留不同族群轮换的节奏价值。
- 调参前先修模型：r1模拟给锚初选额外多计一个1/120秒驻留。模型1.1已去除，加入“.65秒实际落点＋1.5秒驻留＝2.15秒首脉冲”的保真回归；最终模型1.2保留该回归。r1参数、模型源、结果和报告原样保留在输出目录的 `r1-before-final/`。
- 参数扫描：风每层10%／12%／14%；岩脉冲0.8／2.0／2.4；灵契额外段100%／120%／140%。未采用最大候选；参数均可外置调整后重跑。

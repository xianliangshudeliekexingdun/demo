# 通用道具静态数值预算

这是持续保留、可调参数的**静态预算工具**，不是完整战斗模拟器。24件已通过并获实施授权；工具本身只读运行源，不改规则、不启动Godot。原生事件与路线证据另见本轮实现报告。

在 `D:/demo` 执行：

```powershell
python tools/balance/generic_items/budget.py
```

可编辑 [proposal.json](proposal.json) 后用 `--proposal <path>`、`--out <path>` 留存不同候选。结果默认写入 [budget.md](../../../build/qa/generic-items-implementation-20261018/static-budget/budget.md) 与 [budget.json](../../../build/qa/generic-items-implementation-20261018/static-budget/budget.json)。后者记录参数、实际运行源的SHA256、工具版本、手算与边界检查、全部场景和设计参考对照。旧设计阶段报告保留原输入哈希。无随机过程，不填写假随机试验。

模型读取当前core实际加载的基础角色／法术／U01—U03数据，覆盖三火冷却相性、CD上限60%与下限、吟唱周期、暴击率不封顶但概率100%封顶、F02三级暴击倍率、F10三级CD覆盖。枚举F01/F07/F10的1级与3级，既有5%/20%暴击率、1.5/1.75暴击倍率、条件伤害覆盖0/50/100%，输出基线／4件混合／6件输出；另含6件防御的满资源潜力和领取当刻不补资源两口径，以及CDR4/6/8个百分点、防御10/15/20敏感性。

边界检查包括负值、零值、暴击概率与CD／减伤边界、先减伤再护盾、已知手算和等级CD；暴击属性可以超过100%，实际概率最多100%，不产生超暴。工具不调整候选数字来掩盖计算结果。混合输出10%—30%与指定6件输出90%现只保留为设计对照，**不是用户硬要求、伤害上限或通过门槛**。另枚举8种输出候选任取6件的满条件边界，保留最高121.32%的强构筑参考；用户已接受明显输出跃升，不因此标平衡warning或阻止完整候选库。首批12中的全部5件输出项另有独立上界。新暴伤候选按常驻有效暴击率≥10%检查静态资格，未模拟领取顺序。

最终体验目标是**60房含正式Boss通关约30分钟**；当前仍只实现45房，另15房和Boss待设计。不能把P04/P05动态、实际回盾、条件覆盖率、胜率或最终整局时长当成本工具已验证的结论。事件效果不得递归触发事件效果属于未来实施约束，本静态模型没有执行事件链，不冒充已验证该动态规则。

候选正式实施前，至少执行真实core固定种子的普通／优化／短视野构筑，记录伤害条件覆盖率、有效恢复、弹丸伤害占比与旧宝物连锁，并由用户试玩审查。数值预算通过不自动授权实施。

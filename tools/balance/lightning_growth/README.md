# 雷系十术三级成长提案核算

## 当前L05正式规则派生核算

雷系接入后，L05改为**每次施法独立的有限云团**：保留原3／3／4波，后施不取消旧排程，取消跨cast的1.4秒同敌门；每cast每波同敌去重。当前规则与参数只读[正式data](../../../data/lightning_spells_v1.json)，不在工具里维护第二套运行默认值。

```powershell
python -X utf8 tools/balance/lightning_growth/cloud_fix.py
```

`cloud_fix.py`模型`lightning-cloud-fix-2.0`默认输出`build/qa/lightning-cloud-fix-20261021/`。`results.json`记录输入哈希、严格检查和窗口敏感性警告；`cdr_sweep.csv`覆盖三级、30／60／300秒、0—60%CDR逐百分点、单体／密集六敌、自然／追加单独及固定弱追加混合，共3294条预算。静态目标永生、全中、攻击100、基础暴击期望；不含AI、完整构筑、真人难度或性能。

修复目标是自然／追加单独CDR预算不反降、混合各档不少于同档自然单独、原始波数与本体系数不减；不能把短易伤对另一来源固定到达时点的覆盖移动，扩张为“任意多来源条件收益总量对每个百分点CDR都严格单调”。这些小幅混合窗口波动如实列为warning。自然常规冷却峰值最多2云；额外注入是有限施法压力探针，每次仍有限波、不递归，不是实际可取得的施放率。

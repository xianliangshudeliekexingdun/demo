# 雷系十术三级成长提案核算

## 当前L05正式规则派生核算

雷系接入后，L05改为**每次施法独立的有限云团**：保留原3／3／4波，后施不取消旧排程，取消跨cast的1.4秒同敌门；每cast每波同敌去重。当前规则与参数只读[正式data](../../../data/lightning_spells_v1.json)，不在工具里维护第二套运行默认值。

```powershell
python -X utf8 tools/balance/lightning_growth/cloud_fix.py
```

`cloud_fix.py`模型`lightning-cloud-fix-2.0`默认输出`build/qa/lightning-cloud-fix-20261021/`。`results.json`记录输入哈希、严格检查和窗口敏感性警告；`cdr_sweep.csv`覆盖三级、30／60／300秒、0—60%CDR逐百分点、单体／密集六敌、自然／追加单独及固定弱追加混合，共3294条预算。静态目标永生、全中、攻击100、基础暴击期望；不含AI、完整构筑、真人难度或性能。

修复目标是自然／追加单独CDR预算不反降、混合各档不少于同档自然单独、原始波数与本体系数不减；不能把短易伤对另一来源固定到达时点的覆盖移动，扩张为“任意多来源条件收益总量对每个百分点CDR都严格单调”。这些小幅混合窗口波动如实列为warning。自然常规冷却峰值最多2云；额外注入是有限施法压力探针，每次仍有限波、不递归，不是实际可取得的施放率。

## 原v1提案复现范围

本目录是持续可编辑的离线设计工具，由`.gdignore`隔离，不参与游戏加载。规则说明见[雷系成长提案](../../../docs/游戏设计/雷系法术成长.md)。`proposal_v1.json`是有版本的提案，**不是运行默认值，也不是已实施或最终平衡结果**。原[lightning.json](../five_schools/lightning.json)保持原字节，作为原稿基线读取；旧16职业表不参与本版预算。

下列`run.py`／`model.py`保留原唯一云及共享门的v1提案模型，用于历史复现，**其L05不代表当前正式data**。原提案和原`build/qa/lightning-growth-design-20261021/`冻结结果保留，不覆盖；重跑请显式输出新目录。

在`D:/demo`执行：

## 模型契约

- `model.py`执行静态几何上的独立施法时序，`run.py`负责加载、已知案例、情境扫描与输出。`scenarios.json`保存攻击、基础暴击、时间、CDR、目标布局与命中期望输入；`proposal_v1.json`保存完整十术三等级候选。
- 所有目标静止、生命无限；模型计算伤害机会预算，不模拟敌人AI、移动、死亡移除、逐帧碰撞、路径寻找、玩家生存、自然选卡或完整八槽配装。三起手另记录180生命单体无暴击全中离散TTK；不把群体总伤害压回一只。
- 同情境比较原稿与候选，覆盖三级、30／60秒、0／30%／60%CDR、单体／密集／分散／遮挡、仅本术自身导电与外部维持旧导电、全中／65%线性伤害期望。密集几何是明确可达覆盖，不是自然房间命中率。
- “外部维持旧导电”在每次事件都满足既有标记且年龄至少2秒，供给法术的伤害／槽位／成本未计，是设置上界；不能据此宣称L07每次都能邻弧，或L08单术必定保持网络。无外部布点的预算执行本术导电刷新与到期。
- 吟唱完成释放后才计CD。L01飞行延迟按静止测距；L03每跳0.08秒、L08每边0.18秒，逐次实际时刻重查终点导电／距离／遮挡；起点保留上次有效命中前资格，共享visited不重访。L08用完整既有导电连通体判断过载，真正伤害仍沿有限合法路径兑现。
- L05唯一云、后施替换，旧云未到的波次被取消。所有云对同敌共享1.4秒门；先按本次名额选择目标，门挡后不补选，不产生命中／导电／首次易伤资格。相同时间先结算旧波、后替换新云。新云的首次实际命中才建立该cast该敌的自然三级易伤，首击不倒算收益。
- L07标准预算目标始终存活；“本次击杀主目标”是单次分量门控探针，没有条件附伤、邻弧和死目标导电刷新，不代表实现了后续死亡移除与重选。追加L07无自然邻弧；追加三级L08保留原2条边×1.5。
- L09预算只恢复真实缺盾，标准行初始缺100盾、无后续受伤。另核满盾、缺10盾与显式持续5盾／秒流失，缺盾上限100。持续流失仅用于供给边界，不是敌人伤害、存活率或整局回复承诺；没有把GT01转伤列入输出。
- L10无伤害、施法或自然计数。独立核雷伤桶、导电期限与连接范围；另有三级研习＋三雷共鸣、60%CDR和180%暴击属性边界，同条件比较基线／候选。增距只用于L03／L08，不扩大L04／L07／L09的独立范围。
- 65%值只对最终伤害预算作线性缩放，状态轨迹仍按全中机会执行，不是逐跳随机命中或真人水平。暴击使用概率上限100%的数学期望，不抽样，不存在随机种子；非暴击派生保持原身份。
- 本体±10%只缩直接本体及明确直接后段系数，不缩非暴击条件附伤／电网边／成熟邻弧、护盾或状态期限。本版没有为了抬数值加入L03尾弧、L07额外80个百分点、L09额外10盾或L10更高伤害。

## 验证与警告

已知案例先对照原五系模型的三个起手（首击、施法数、单体伤害），再核几何级数、延迟末端裁切、逐边过期、完整分叉连通体、有限过载、击杀不出邻弧、真实回复、同桶增益与导电增距。原一级保持不变，同情境升级不反降；雷枪对单、连锁密集群体的优势分别保留。检查通过只说明工具在这些输入与约束下自洽。

L05另扫45／50／55／60%CDR，**保留“CDR提高但输出下降”的阈值警告**。50%→55%时，唯一替换周期与跨云门发生冲突；本工具如实记录，不通过增加伤害或重置共享门隐藏问题。这是接入前需要收口的循环风险，不能用0／30%／60%三点扫描宣称所有CDR单调。

工具不调用Godot，不运行玩法测试、实机、截图、性能、导出或远端操作。抽取概率、触媒倾向和价格依用户安排留到六系法术制作完成后统一处理；本工具完全不采样奖励。

## 模型契约

- 普通词条枚举所有每条最多出现四次、总数十二且能分配到四颗各三条不重复词条的组合。用F01一级的攻击、暴击期望、实际CD加吟唱比较普通／已有火系属性／暴击与CDR饱和情景。归一化直伤收益不等于整局DPS。
- 防御使用当前防御函数与综合减伤上限；EHP仅表示开场满血满盾可承受的原始伤害，不包括回复、无敌、走位或每房补盾。血晶先转换上限，战斗治疗只按实际缺盾回复。
- 燃烧为单份共享时钟，刷新不重置下跳；到点旧跳先结算，末跳后清理；引爆只消费尚未结算的库存。暴燃同步缩短时间与间隔；层燃有层数与增层间隔限制，消费后复燃从一层开始。
- 寒霜为三层、唯一冻结／冰裂窗口、硬控后免控；窗口内不续层或延长。窗口到期前的霜蚀末跳先结算，再自然到期；这条新增派生结算顺序是讨论提案。主动碎冰消费后不再自动兑现。
- 交织只接受自然施法每次对主靶的一次有效直伤，记录六秒；热冲击按同一个靶子的燃烧与冰裂库存消费。二者均有全局间隔，派生不制造新施法／点燃／施霜。混合热冲击的学派增伤取火冰较大一项，交织沿触发法术学派，均不双吃两系。
- 事件目标固定命中；邻敌数量代表“已满足距离、遮挡、存活条件”的假设，不模拟实际位置。自然F01/I01节奏只作为压力输入，不冒充完整八法术构筑。
- TTK从第一次命中开始，一级F01单术、真实原参数的吟唱加CD／暴击／燃烧，固定种子20261019，每情景2500次；不包含飞行、移动、转火或45房流程。

## 校准与边界

先核原300生命／100盾／100攻击、200点完整燃烧、P06下300、P06＋三级F07/G04满库存1050、冻结1.2／0.42／0秒、I07碎冰200，再比较候选。模型失败时先修模型并保留回归案例，再调参数；参数目标未达不改动源数据弥补。

报告扫描普通词条幅度、折射份额、转换比例、燃烧时间、层燃系数、交织／霜蚀／崩晶／热冲击系数。数值目标只是本轮选型锚点，不是总输出上限。强构筑完整战斗、实际移速收益、真实护盾回复闭环和完整宝物交互仍需后续原生实现与试玩。

### 选择顺序与计数

先按金色未出次数／新人状态确定金率；未出金时，若连续九次无紫／金则给紫，否则将非金概率按基础比例分配。出金清空两个计数并结束新人保障，出紫只清小保底；金色特效始终八种等权、可重复，不提供心愿或选择。单抽和连续十次执行同一序列，计数保存后继续。模型存取一致性是离线数据测试，不代表真实Godot存档已接入。

精确模型以出金重置为更新点，得到周期长度和各品质数量，再求长期综合概率；新人首金单独计算。指定特效／八种全收集为吸收状态，依金周期与重复概率推进，分别与几何等待／集券期望交叉核对。品质保底不产生指定特效的硬上限。普通词条只核组合数，不将获得任意金等价为完美装备。

### 预算与验证

预算读取当时的魔尘设计表和触媒现价；模型产生时45房75尘为待接入投影，随后运行已按真实已清战斗房实现，本工具参数保留产生评审快照时的状态。正常失败保留已清收入；每次结算后决定消费，余额跨局积累。比较每局都抽、先升满首触媒、先升满两触媒三种政策；未来完整60房含Boss150尘只作为原模型敏感性参照。没有假设分解返尘、初始赠抽或旧存档返还。

精确案例涵盖概率总和、零自然金仍在硬保底结束、两种保底同抽、金／紫计数重置、新人提前出金、单抽与十连／计数存取一致性、跨局余额守恒。Monte Carlo用三个独立种子，每批6000账号各150抽；对比有限150抽精确比例，避免把新人样本直接与稳态概率比较。

1.0初次采样变量错误已修正；1.1保留零概率端点、单抽／批次／存取、有限期品质比例的回归。后续若真实Godot结果不同，先核模型与事件／计数规则，再改概率，不用调参数掩盖模型缺陷。

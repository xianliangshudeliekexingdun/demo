# 六系法术书抽取核算

本工具是六系统一抽取的持久数值模型。默认值唯一读取正式 `data/route_spell_sampling.json`，法术ID、学派、前置、三起手读取真实六系源，52书节点读取 `data/courtyard_route.json`。不模拟敌人、伤害、死亡、宝物或自然60房；不证明真人构筑选择、成型时长或最终平衡。

## 模型与输入

- `model.py`：逐张条件概率、有限不放回采样、四类精确DP、真实前置与选卡轨迹，不读写存档。
- `run.py`：加载运行源、执行不变量／已知案例、旧基线对照、固定seed轨迹与扫描。
- `scenarios.json`：种子、批次、选卡策略、扫描值和暂定体验目标。`proposal_*`仅供缺少正式源的离线提案回放，游戏不加载本目录。
- `baseline_v1.json`：变更前旧每ID ×1.5／1.75／2 与持有权重1的派生冻结快照。旧运行只有火／冰触媒，其他四系套用旧倍率是对照实验，不冒充历史已开放触媒。
- `report.py`：Godot原生概率桥独立核对、分布CSV、目标／警告、费用预算与报告。

固定8槽、最高3级作为模型契约，运行源变更会失败并要求修订模型，不静默使用旧上限。一级起手不计书奖；52次书奖从第1房到第60房，15／30／45房对应第13／26／39本。R06、S05、S07只在来源持有后作为新学候选；已持有支持术失去来源后仍可升级。满槽未持有术保留，替换只移除一个旧槽、得到新术一级；全新三卡才可跳书。有合格升级的混合屏不能凭模型偏好跳过。

## 概率与选择

每个剩余合法ID的基础权重，新术1、已有可升级术×正式 `owned_upgrade_weight`。本系权重占比q决定本张本系概率 `p=q+(1-q)×a`；分组内按基础权重分配，抽掉ID后重新计算。无触媒a=0，空分组回退；没有强制槽位、重抽或保底。Python和Godot的RNG不同，模型核对条件分布，不声称逐seed随机流相同。

三个可复现选卡策略代表受控偏好，法术被视为同阶同类效用，不是实测真人行为：

1. `main_priority`：优先升级已有主系，再补主系；满槽可用主系替换最低等级跨系术，不在八主系之间为了新ID反复洗牌。
2. `upgrade_priority`：任何已持有候选优先，二级先于一级；不足8槽时才补新术，满槽全新屏保持构筑。
3. `dual_four_four`：目标为指定主系＋循环下一个指定副系各4种，先补缺额，满槽只以目标缺额替换外系或超额同系；组成后优先升级，合法全新屏可跳过。副系不是“任意四个外系”数量。

无触媒也执行这些选择偏好，隔离玩家选择与触媒概率。最长“无升级屏”只在持有未满级术时计数，统计没有任一合法已有升级的连续书数；不是获得某张特定ID的保底，也不保证有限上界。

## 复现

```powershell
python tools/balance/six_school_sampling/run.py --trials 125 --out build/qa/six-school-sampling-20261021/model/final
python tools/balance/six_school_sampling/report.py
```

正式批次4个固定seed，每情境500条；6主系×3选择策略×无触媒／旧3档／新3档，共126情境63000条轨迹。可以 `--schools fire --trials 125 --compact-sweep` 运行升级权重1／1.5／2及倾向0／.28／.40／.52对照；`--sweep`覆盖更宽的a周边。`--validation-only`只执行模型已知案例与不变量。输出绑定输入哈希并保存原始正式参数，旧结果不作当前默认值。

v2修正初稿精确表的R03池数（58而非59）并增加×2已有／新学四类精确枚举。真实轨迹从一开始就使用实际前置；原始调参输出保留其阶段范围。接受结果同时标明参数目标中的警告；高等级触媒更集中主系，不能承诺所有双系策略同时更快成型。免费卸下触媒提供偏均衡的选择；同一已升级触媒没有降档功能。没有实机、截图、性能、最终难度或付费随机承诺。
